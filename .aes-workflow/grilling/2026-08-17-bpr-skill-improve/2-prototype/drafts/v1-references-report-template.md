# 报告模板与示例（report-template）

> SKILL.md 有节结构一行版；本文件给完整模板、空值行为和一段真实示例。

## 完整模板

```md
## 最佳实践调研：<问题一句话>

### 直接建议
<可执行结论；行尾标置信档位【高/中/低】；单一来源结论加标【单一来源，未收敛】>

### 证据使用
**官方 / 上游**
- <claim>（[来源](URL)，核对日期 YYYY-MM-DD）
**补充**（如有）
- <claim>（[来源](URL) — 为何只是补充）

### 版本 / 日期上下文
- 版本：<当前版本 / 发布日期（registry time 口径）>
- 关键时间点：<宣告/弃用/迁移等节点>
- AS_OF 核对日期：<YYYY-MM-DD>

### 冲突与缺口
- 矛盾证据：<来源 A 说 X，来源 B 说 Y，本报告采信谁、为什么>
- 过时来源标记：<仍广泛流传但已过时的口径，点名其来源类型>
- 用户假设来源：<用户内嵌假设的流行来源；已过时则标为过时证据>（无则省略本条）
- 未答部分：<查不到或超出边界的，如实写>

### 仓库本地上下文
<本地检索到的约束/用法/版本；未做本地检索则写「不需要」并一句原因>

### 边界 / 非目标
<本报告不裁决：选型对比 / 迁移执行 / 具体实现……>

### 交接
<对规划/执行的含义一句；移交目标：规划工作流 / 执行工作流；本技能到此为止>
```

## 空值行为

| 情形 | 行为 |
| --- | --- |
| 查不到官方来源（3 次预算用尽） | 直接建议照给（基于现有证据），置信记【低】，「冲突与缺口」写明"官方源未获得，停止检索的原因" |
| 只有一个独立域名 | 结论照写 +【单一来源，未收敛】，置信最高【中】 |
| 来源互相矛盾未决 | 并陈于「冲突与缺口」，置信记【低】，不挑边 |
| 无外部证据可用（离线/全被拦截） | 声明"未获得外部证据"，不虚构；置信【低】 |

## 示例片段（源自 iteration-2 CRA 案例的修正形态）

```md
### 直接建议
不要再用 `npx create-react-app` 起新项目。CRA 已于 2025-02-14 被 React 官方弃用
（"Today, we're deprecating Create React App for new apps"——官方博客原句）。
不用大框架时官方当前起点是 Vite / Parcel / RSBuild。【高】

### 冲突与缺口
- 过时来源标记：大量 2022 年前创建的教程与课程仍以 CRA 为默认教学脚手架，
  这与你"官方脚手架就是 CRA"的印象同源——该口径随 2025-02 弃用公告作废。
- 矛盾证据：无——官方弃用口径与 npm registry 停更状态（最后版本 5.1.0，
  2025-02-15）相互印证。
```

> 该示例直接对应 iteration-2 唯一 FAIL（CRA 断言 3"把仍推荐 CRA 的旧教程识别为过时证据"）：旧行只做到了"直接建议"段，新版靠「冲突与缺口」的"过时来源标记 + 用户假设来源"两条承接。
