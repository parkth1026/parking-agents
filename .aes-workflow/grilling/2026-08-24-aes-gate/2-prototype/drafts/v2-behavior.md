## 不变清单

- 不修改任何既有技能；`aes-standardize-repo` 只被引用不被改。
- **run.toml 是 gate 唯一注册真源**：registry/看板/报告不复制命令定义，门 id 引用 run action id；不改 run 标准 schema（`kind="gate"` 既有伏笔够用，不够时先提案 run 标准演进，不私扩）。
- gate/v1 协议包零接触零依赖（Q2=C）；twe-gate 引擎、通用 gate-builder、M3 复诊登记簿均在界外。
- 检测与单条沉淀之外**不写目标仓任何文件**；组装/沉淀写入仅限 `scripts/gate/`、`run.toml`、（分诊选定时）CI/hooks 文件。
- aes-qa 已定基线不变；组装产物永不在 aes-qa 调用路径内落地（Q4=A）。
- `npm test` 七连行为不变——新增物须通过既有检查而非改检查。
- 退出码以显式读取为准（`echo $?`/终态 JSON），管道与后台包装不吃码（吸收自用户 gate skill 纪律）。

## 配置差异

无新增配置文件；`/aes-gate` 与对话触发均无必填参数。组装底座（CI/hooks/仅注册）为运行时分诊项，非配置。
