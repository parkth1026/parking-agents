## 已锁定的约定

- 盘点表五字段固定：门 id / 类型 / 命令或位置 / 证据 / 状态——状态枚举：绿·红·缺失·疑似过时（与运行态矛盾时标，出自 map #15 gate 联动基线）。
- 缺口清单六字段固定：缺口 / 风险等级（P0–P2）/ 建议归属 / AC 锚点 / 可组装标记；「可组装」只标最小集四件对应模式，其余标 ✗ 归通用 builder。
- 空表必须带表头出现（结局 2）；异常时不产出表格（结局 3）——两者都是显式结论不是失败。
- 报文为 markdown 结构（技能间人可读接口），不引入 JSON schema（Q2=C 不做协议对齐的推论）——此条若被质疑可改。
- 六维评分摘要只在显式会话报告里给全表；被调用回传只给一行总分+档位（精简路径）。
