# GPT-4

OpenAI's flagship large language model released in March 2023. A multimodal
model capable of processing both text and images.

## Key Facts
- Released: March 2023 by OpenAI
- Multimodal: accepts text and image inputs, produces text outputs
- Trained with [[RLHF]] and Constitutional AI techniques
- Substantially more capable than GPT-3.5 on reasoning benchmarks
- Parameter count not publicly disclosed ("undisclosed architecture")

## Significance
GPT-4 demonstrated that scaling and alignment techniques (RLHF) together produce
models with broad capability jumps. Referenced in Karpathy's lecture as an example
of a fully fine-tuned assistant model built on top of large-scale [[Pretraining]].
