# workflow-interview 自主权修订与验证

日期：2026-10-21。范围：需求访谈技能族、脚本门禁、Web 发布与档案、相关评测和 ADR 补充。

本轮按用户确认的方案修改。目标是给 Agent 留出方法选择空间，同时保留用户授权、
验收含义和证据有效性。没有修改真实旧任务，没有宣称已证明强模型任务成功率提高。

## 修改前后

| 事项 | 修改前 | 修改后 |
| --- | --- | --- |
| 决策归属 | 成熟路径存在成本差异就交用户裁决，选路写进强约束 | 授权内的调查、实现和验证取舍由 Agent 决定；自主边界重点写例外限制 |
| 提问 | 80% 分档，单选 pct 必填且加和 100±2 | 不要求偏好概率；需要决定、授权或关键输入时再问，历史 pct 保真 |
| 表达 | 固定三段、固定每批题数、先长文本再工具收答 | 按问题选择表达和工具，避免无用重复 |
| 过程材料 | context、五维评分、七面表与独立原型齐套 | 过程材料按需；已有记录存在则验证，实际声明引用仍需可取得 |
| 对照物 | 架构变化强制 diagram.html，界面口径按 mock 文件名触发提问 | 载体与文件名不代替内容判断；复用已有授权，不擅自缩窄成功标准 |
| AC | 上限七条，要求连续编号 | 数量不作拆分门槛；编号唯一且稳定，允许合法缺号 |
| 验证 | 前端绑定 spec，统一三次通过，部分不稳定结果不许继续修 | 工具与重复方式按任务需要选择；允许诊断修复，不以隔离消除验收义务 |
| 测试维护 | 文件不可修改 | 验收含义不得被削弱；可说明等价的工具维护可进行 |
| 状态 | finalize 可能直接 ready；rebuild 扫文件恢复 confirmed | 机器校验与内容对齐声明分开；不从文件存在恢复丢失确认 |
| 版本有效性 | 主要按 mtime 判断 | 新校验绑定契约内容摘要；旧记录保留 ran_at 兼容路径，不批量迁移 |
| 档案 | valid 可能使未经再次校验的正文投影为正式契约 | 与 CLI 共享有效性判断；历史 Web final 保留为预览，不冒充当前正式契约 |
| 人验 | 转长时程执行时提示移出同步判定 | 保留待人验义务；真实凭证、会话交接或如实阻塞，不自动改变完成定义 |

三职责仍保留，但可以交错、合并和复用。未设置轻重模式、评分表、固定审查人数或新问答轮数。
ADR-0004 只补充本轮替代范围，保留 story／票级边界、派发前 finalize、digest 与单一写入者。

## 旧任务与上下游

- 没有修改 .aes-workflow 下的旧契约、manifest、问答或确认版材料；Git 状态与 diff 均无该目录改动。
- 技能明确要求：新流程不自动解除旧任务中用户确认的技术、工具、精度、验证深度和交付要求。
- 保留旧字段与历史数值。不重算 pct，不改写用户原话，不把缺少新字段视为必须迁移。
- 保留契约 digest、candidate SHA、QA 回执和人工决定权。复用工作不等于复用失配的机器回执。
- Web 保留持久提交、幂等吸收、恢复窗口、附件边界和人工续接协议。
- 本机 workflow-interview 与 workflow-interview-web 安装入口是指向本仓库的 junction，无需另拷贝安装。

全仓失败与本次改动分开核对：

- 技能发现报告的 17 个文件，与 HEAD 逐文件比对一致。
- 工具命名报告涉及 35 个文件，与 HEAD 逐文件比对一致。
- 版本审计的两个 github-trending-weekly fixture 与 HEAD 一致；另两个是 HEAD 未跟踪的既有 eval 路径，不能用 HEAD 证明其历史内容。本轮未改动这些路径。
- 未为消除全仓旧失败修改无关技能、测试阈值或版本登记。

本轮规则发生变化，旧的固定概率、七面表和图文件名断言也随之改写；137/137 不是与旧 130/130 可直接比较的质量分。
保留并新增的反向用例检查：坏记录、缺失引用、重复 AC、无效契约、失效摘要、未确认恢复、人验义务和旧约束保真。

## 对抗审查及修复

三个独立 subagent 分别审查授权边界、运行代码和文档一致性。初轮发现以下问题，均已修复并复核关闭。

| 发现 | 修复 | 验证 |
| --- | --- | --- |
| 新模板普通段落被旧 bullet 门禁拒收 | 可选节接受有效正文 | 新模板直接校验及段落回归 PASS；审查者复跑 16/16 |
| 修改契约后直接导出仍可能标为正式契约 | CLI 与档案共享内容有效性判断 | 同秒改正文并恢复旧 mtime，正式投影失效；审查者独立复现关闭 |
| 人验移出完成条件的旧提示残留 | 改为保留待人验义务，不按执行工具自动移节 | 纯人验反例 PASS；最后一处遗留提示经再次复核关闭 |
| 非命令证据被整体贬为自陈 | 只说明 finalize 不执行这些检查，按约定复核实际证据 | 文档与运行时一致性复核关闭 |
| 两份设计文档对投影是否共享说法冲突 | 统一为共享交付语义、分别维护适配 | 只读复核关闭 |

最终未留未处理的本轮审查 finding。测试只覆盖列明行为；用户意图与语义等价仍需 Agent 基于证据判断，
不能由状态码或文件存在性代替。改动保留在当前工作区，未创建 worktree，未提交 commit。
