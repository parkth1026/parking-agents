# Goal Contract 的 AC 定位：修改对照与验证

日期：2026-10-21。范围：本轮 AC 定位修订。前一轮自主权修订仍保留在工作区，未覆盖或撤销。

## 结论

契约围绕原始背景、本次想做成的样子、AC 与验证依据组织。AC 补充重要的成功差异，
Verify 提供判断依据。验证者读取目标与必要上下文，按证据价值、实际影响和总时间成本选择方法。
命令全绿不能覆盖已观察到的目标偏差，通用 QA 惯例也不能变成新目标。

本轮没有新增评分表、成本台账、固定验证次数或统一验证顺序。已有任务确认的目标、范围、
技术限制、Verify、证据档位、人工决定权及仓库门禁继续有效。

## 修改前后

| 位置 | 修改前 | 修改后 |
| --- | --- | --- |
| goal-contract 技能、形态说明、示例 | 偏重把例子整理成 AC，再逐条验证 | 先理解背景和期望完成形态；AC 补充有区分力的成功结果及相关下限，不追求通用质量齐全 |
| AC 与 Verify | 容易将测试命令或易测指标当作目标 | 区分期望结果与判断依据；合法 JSON 等代理检查只证明相应部分，不能代替下游可用性 |
| 时间取舍 | 缺少总时间成本的明确依据 | 综合准备、执行、误报诊断与维护成本；复用适用证据，允许廉价现成全量入口，不逐条新造测试 |
| 目标格式门禁 | 禁止列表，超过 600 字拒收 | 保留有实质内容的检查；允许必要段落、列表和例子 |
| 交接模板与实际生成器 | 目标只取首行；完成标准偏向全部 Verify 通过 | 多段目标完整进入指令，引用完整契约，明确目标偏差不能被绿色命令覆盖 |
| 长目标交接 | 超过本地 4000 字符限制会使 finalize 失败，并要求压缩契约目标 | 自动给出会话式交接并提示，不截断或删减契约，不因执行工具限制改变完成条件 |
| worker 的工单 | 已有摘要覆盖 goal，但工单只传 AC 等字段，漏传 goal | 增加 goal；有正文时附带可选 sourceBody，背景与范围可随单取得，不强求新增网络权限 |
| 独立 QA 输入 | 只读 AC、工作树路径和命令 | 读取理解目标所需的背景、目标、范围、必要例子及 AC；隔离实现者自证叙述 |
| QA 方法 | 容易按改动类型机械加档 | 按需要证明的结果与实际影响选择方法；实际采用的证据协议及既定档位仍绑定 |
| worker 范围路由 | IN_CURRENT_SCOPE 只指当前 AC | 覆盖已确认目标、范围、约束或 AC，且不新增用户承诺；相应阻塞依赖也围绕已确认交付 |
| 业务验收配方 | 最低模型成本与固定顺序易压过目标 | 明确总成本包含时间；保留真实效果、身份、凭据与回执要求，不统一规定其余验证顺序 |
| 工程门禁 | merge 后全量回归容易被视为每项 AC 的模板 | 保留已有集成门禁，明确它不是生成任务 AC 的清单，不能借任务验证精简跳过 |
| 术语与入口 | AC 曾被称为 QA 唯一判定依据 | CONTEXT、技能和入口描述同步为目标的可验证补充，已确认内容仍是判定依据 |

主要文件位于 skills/workflow/aes-goal-contract、aes-qa、aes-issue-worker、
aes-worktree-board 与 workflow-interview。Web UI 本轮未改；核心档案导出回归覆盖目标投影。

## 对抗审查与修复

三组只读 subagent 分别审查文档语义、运行链和护栏。审查不是对初稿投票，以下反例实际改变了实现。

| 发现 | 反例与后果 | 修复与复核 |
| --- | --- | --- |
| P2：范围路由仍只认 AC | AC 只测 JSON 可解析，目标要求下游可用；缺必要字段的修复可能被当成范围外 | 路由依据改为已确认目标、范围、约束及 AC；语义审查者复核关闭 |
| P1：新增正文上下文未被摘要绑定 | 仅改范围或实体 ID 强约束，goal 与 AC 不变，摘要仍相同 | 新工单摘要绑定实际传递的 sourceBody，builder 使用同一解析快照；两位审查者独立复现关闭 |
| P1：新摘要可能使旧 Issue 出现第二个 owner | 旧有正文任务升级后再次 claim，新摘要对应不同 jobId | claim 先识别同仓库同 Issue 的活跃 job，保留旧任务并返回恢复指引；新增临时 Git 场景通过，运行审查者独立复跑关闭 |
| 非阻断：最低成本可能被理解为最低单次调用价 | 低单价可能增加准备或诊断时间 | 明确使用总时间成本；语义审查者复核关闭 |

审查后未留未处理的本轮阻断 finding。没有借修复增加验收评分或通用 QA 套件。

## 存量任务与交付边界

没有对真实 .aes-workflow 或 .aes-worktree-board 任务执行迁移、校验写回或摘要重算。
旧已存工单、job、回执和已确认约束保留；新可选字段不要求旧工单补齐。

新生成且带正文的工单使用包含正文快照的新摘要。绑定正文是证据完整性措施，
不表示正文中的建议、历史叙述或未确认偏好全部升级为 AC。
同一 Issue 仍有活跃旧 job 时不会新建第二个 owner；按原 job 恢复，契约修订与重派走既有生命周期。
已确认的结果或验证要求需要改变时，仍须相应授权，时间不足不能记成 PASS。

改动留在当前工作区，未新建 worktree，未提交 commit。
