## 1. 现状与问题

脚本现有行为:读取脚本同目录 `logs/*.log`,按正则解析 `(timestamp, level, message)`,固定写到脚本同目录 `export.csv`(UTF-8、总是覆盖),解析失败的行静默跳过。

用户痛点(按优先级):
1. **无法按日期过滤**——每次全量导出,又慢文件又大。
2. **输出路径写死**——无法把结果导到别处;但默认输出被其他脚本依赖,不能改默认。
3. **坏行静默丢弃**——解析失败的行无声消失,用户对数据完整性没底。

## 2. 目标(Goals)

在保持现有默认行为 100% 兼容的前提下,为脚本增加:

1. `--from YYYY-MM-DD` / `--to YYYY-MM-DD` 日期范围过滤(两端含当天,可单独或同时使用)。
2. `--output PATH` 指定输出文件路径。
3. 结束时将"解析失败被跳过的行数"统计打印到 **stderr**(为 0 也打印)。
4. `--help` 显示用法说明。

## 3. 非目标(Non-Goals / 明确范围外)

本次**不做**(用户明确裁决,勿顺手实现):

- 按日志级别过滤(以后再说)
- 压缩输出、自动上传
- GUI、配置文件
- 日志目录参数化(固定读脚本同目录 `logs/*.log`)
- 处理轮转文件(`*.log.1`、`*.gz`)
- 多行日志条目(堆栈等)的解析——保持现状(按行匹配,匹配不上即跳过)
- 输出格式变更:不加 JSON、不加 BOM、不加"来源文件"列、不改排序

## 4. 兼容性红线(违反任意一条即验收失败)

- **默认输出不变**:不传 `--output` 时,输出路径、文件名(脚本同目录 `export.csv`)、覆盖行为一个字都不能变——有其他脚本依赖。
- **CSV 契约不变**:编码 UTF-8(无 BOM);表头与列顺序固定为 `timestamp,level,message`——下游按列位置解析。
- **stdout 契约不变**:保留 `exported N rows -> <路径>` 输出行——有下游脚本解析这行。
- 行解析规则、行排序行为保持现状。

## 5. 接口规格

```
python export_logs.py [--from YYYY-MM-DD] [--to YYYY-MM-DD] [--output PATH] [--help]
```

| 参数 | 必填 | 语义 |
|---|---|---|
| `--from` | 否 | 只导出时间戳日期部分 >= 该日期的行(含当天);单独使用表示"从该日起到最后" |
| `--to` | 否 | 只导出时间戳日期部分 <= 该日期的行(含当天);单独使用表示"从最早到该日为止" |
| `--output` | 否 | CSV 输出路径;缺省时为脚本同目录 `export.csv` |

**日期比较口径(用户特别强调)**:取日志行时间戳的**日期部分**(前 10 个字符 `YYYY-MM-DD`)与参数做比较,不得转换成 `00:00:00` 的完整时间比较,否则会把当天数据比丢。

**错误处理**:以下情况打印错误到 stderr、以非零退出码退出、且**不写出/不覆盖**输出文件:
- 日期参数格式非法(如 `2026/08/01`)
- `--from` 晚于 `--to`(不得生成只有表头的空文件)

**统计口径**:stderr 的跳过统计只计"格式解析失败"的行;被日期范围过滤掉的行**不**计入。

## 6. 验收标准(经用户逐条裁决的最终版)

- **AC1** 不带任何参数运行时,行为与现有脚本完全一致:读取脚本同目录 `logs/*.log`,输出到脚本同目录 `export.csv`,UTF-8 无 BOM,总是覆盖,表头与列顺序为 `timestamp,level,message`。
- **AC2**(用户改写措辞)`--from YYYY-MM-DD`:按日志行时间戳的日期部分(前 10 个字符 `YYYY-MM-DD`)与参数比较,`日期部分 >= from` 的行才导出;不得按完整时间戳比较。
- **AC3** `--to YYYY-MM-DD`:同 AC2 口径,按日期部分比较,`日期部分 <= to` 的行才导出。
- **AC4** `--from` 与 `--to` 可单独或同时使用;同时使用时导出两端闭区间内的行。
- **AC5** `--output PATH` 将 CSV 写到指定路径;不传时默认路径、文件名与覆盖行为完全不变。
- **AC6** 脚本结束时将解析失败被跳过的行数打印到 stderr;为 0 也要打印;只统计解析失败的行,不含被日期过滤掉的行。
- **AC7** 日期参数格式非法、或 `--from` 晚于 `--to` 时:打印错误信息到 stderr,非零退出码退出,不写出/不覆盖输出文件。
- **AC8** 仍为单文件脚本,仅使用 Python 标准库(Python 3.8+);`--help` 显示用法说明。
- **AC9**(用户补充)stdout 保留 `exported N rows -> <路径>` 输出行:N 为过滤后实际写入的行数;路径为实际输出路径(传了 `--output` 则显示该路径)。
