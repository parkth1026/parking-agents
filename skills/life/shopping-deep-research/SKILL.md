# 硬证据选购调研

先找到目标市场实际卖的东西，再证明它是否适合。把**商品发现、事实核验、推荐判断**分开：商家和社区可以提供候选，推荐则需绑定具体规格、场景和可追溯证据。

## 1. 接续需求，建立指标

读已有需求卡、交接与用户纠正，区分用户硬要求、暂定方案、旧推断和未验证项；已确认答案不重问。只续查某个部件时沿用整套场景，不重做全品类访谈与榜单。支撑面、安装方式、预算等前提改变时，重查依赖该前提的淘汰理由；保留仍有效的限制，不擅自切换已定方案。

先做一轮指标摸底：从标准、比较试验和技术资料找核心指标，解释**含义、体验影响、读数方向/量级**，分为体验决定性、重要、次要、营销虚指标。标准描述测量方法，不等于候选通过测试；数值与经验公式注明适用条件。

再用用户答得了的场景问题锁定重要性，一组不超过5问；只问会改变取舍的缺口：

- 使用者、身体参数与同时使用组合；环境、尺寸、安装和搬运限制。
- 已有设备与兼容要求；含配件、运费和安装的预算上限。
- 采购地区、收货城市（影响大件或定制报价时）；保修、退换及品牌偏好。
- 不满足就绝对不买的条件。

收敛后回读需求卡：使用者/场景/已有设备/采购地区与预算/指标分级/一票否决/加分项/待定项。新需求请用户纠偏；已确认卡不重复确认。信息缺失且用户不在线时标“未经确认，按分支推进”，不编答案。尺寸公式只作推算，用实际姿态、设备或安装条件校准。

**完成条件**：硬要求能逐条核对，未知项不会被悄悄当成满足。

## 2. 建立检索路线

中国采购在第一轮商品搜索前读 [中国数据源与入口](references/china-sources.md)；查价格、销量、评价或API字段时回该文件核口径。其他地区用对应当地交易和消费信息渠道，不默认套中国市场。

先写精简检索表放工作记录；关键转向向用户解释，不必展示全部原始结果：

| 要解决的缺口 | 查询词 | 首选渠道/工具 | 预期证据 | 实际结果与下一步 |
|---|---|---|---|---|
| 商品发现/在售/性能/口碑/交付中的一项 | 品类或型号及一个区分词 | 能回答该问题的入口 | 商品链接、规格、报价或原始测试 | 相关候选/噪声/受限/无结果 |

分步构造查询词，不把所有限制塞进一条长句：

1. **名称展开**：消费俗称、行业名、材料名、功能名；从相关商品标题与说明书补同义词。
2. **形态拆分**：成品/配件/原材料，标准品/定制品，以及混称的安装方式。名称相似不等于可互换。
3. **先宽后窄**：先用“品类＋一个关键形态”发现商品，再用“型号＋规格/参数/问题”核验。每批选最有区分力的2–4条，不一次穷举。
4. **选择入口**：标准品先商城和导购；非标材料增加供货平台与本地渠道；安装/故障看实录；测量与安全看原始技术资料、比较试验或监管。

商品发现与指标摸底可并行。海外官网没有合适型号，不代表采购地没有商品；缺官网参数先记未知，不在发现阶段直接淘汰。

## 3. 执行搜索，按结果纠偏

第一轮覆盖两个有差异的交易渠道和一个导购或内容渠道；非标品另查供货/定制渠道。这是覆盖起点，不是凑次数：指定独家渠道或来源不可达时记录理由，转用可行入口。

看返回内容，不只看命中总数。默认抽查前10条（不足则全看），统计相关且不同的候选：

| 观察 | 下一动作 |
|---|---|
| 过半无关、混入其他品类 | 加品类/形态限定，换同义词或平台类目；确认接口真的接收查询词，必要时移除有误的过滤器 |
| 大量同款重复爆料、同店多规格 | 按商品身份去重，保留不同规格；追具体商品和其他渠道，重复条数不算覆盖 |
| 零结果但可能有别名 | 换行业名/用途名，暂去掉非硬性的品牌或宣传词，再查站内搜索 |
| 只剩海外产品、软文或不合适的批发起订量 | 转采购地商城/经销商/单件加工，不继续扩搜同类官网 |
| 登录、验证码、无权限、频控 | 标访问受限；用允许的公开页或已授权工具，必要时索取用户可提供的页面，不绕过限制 |
| 两批有效搜索无新候选或证据 | 查遗漏形态和渠道并换路线；覆盖后仍无增量则停止，限定“本次未找到”的范围 |

10条、过半和两批是初始工作阈值，不是统计标准；规模不适合时调整并说明。找到候选后沿链接追具体规格、卖家和原始资料，不只停在摘要页；访问失败保留缺口。

**完成条件**：关键缺口已补齐，或已尝试合理替代入口并明确限制。区分“未搜索”“访问受限”“已搜无结果”“找到但不符合”“待核验”，不得从有限搜索推出市场不存在。

## 4. 建候选表，按事实核验证据

候选身份保留：品牌/制造商、型号或材料牌号、规格版本、卖家、原始链接、采集日期；附硬要求匹配、价格条件、口碑线索和缺口。

- **已核验候选**：当前具体规格可购买，关键硬要求有依据。
- **待核验线索**：仅历史爆料、聚合页、报价待询、关键参数不明；可列出，不冒充达标。
- **已淘汰**：指出违反的要求、证据和成立前提。

在售以当前具体商品页/可选规格或有效卖家报价核验；零评论新品仍可能在售，旧评论不证明当前有货。定制品查数量、裁切、有效尺寸、包装、运费及质量问题退换。组合采购分别核部件规格与整体兼容/安装，单件合格不等于组合已验证。

**证据按要证明的事实分级，不按网站一刀切**：

| 证据类型 | 可用于什么 | 限制 |
|---|---|---|
| A：标准、监管、法定披露 | 测量定义、监管结论、披露事项 | 不外推未覆盖型号/批次；企业自述仍标公司口径 |
| B：有方法与样本范围的市场研究 | 指定期间、渠道和品类的市场判断 | 区分监测/推算、出货/零售，不等于个人适配 |
| C：可追溯的比较试验、专业或用户实测 | 条件内的性能与体验 | 分清独立机构/商业评测/个体实录，标方法与样本；知名度不是充分依据 |
| 交易/公司一手记录 | 商品页报价、规格、说明书、保修承诺 | 证明该主体当时的展示或承诺，不自动证明性能属实 |
| D：榜单、聚合摘要、营销推荐 | 发现商品与待验证主张 | 排名本身不作优劣证据；沿链接找原始事实 |

事实旁带来源与适用条件；只读摘要就标摘要。证据冲突时并列并追原文，不简单“以商品页为准”。推算与现场验证分开，不用自行估计的余量证明安全。

## 5. 分开比较价格、市场信号与口碑

- **价格**：对应型号规格、卖家与日期，注明券、会员、地区补贴、起订量、运费、安装。爆料价不是当前价或连续历史最低价。
- **销量**：字段定义、期间、单位、渠道、商品范围可比才排序。评论数默认称评价规模/热度线索；爆料数、点赞、联盟引单量不当全站销量。不混算跨店、跨规格或跨平台指标。
- **口碑**：查型号＋具体问题/长期使用，归纳优缺点与重复模式；分开订单评价、独立实录、商业合作和转述。记录日期、样本数、抽样方式，非全量分析明说。
- **风险**：投诉查经营者/型号/问题与处理状态；无可靠销售分母不算投诉率，不按绝对量排质量。未查到投诉不等于没问题。
- **品牌画像**：按可得证据列售后保修、企业背景、可靠性，未知即未知。注册资本、产线宣传和认证数量不折成质量分。

销量与口碑是独立观察维度，不强制合成双榜。有可比数据才出对应榜，缺数据给场景候选与缺口；推荐结合硬要求、性能和交付，不为凑榜忽略更适合的产品。不自造数值加权综合分。

## 6. 给出决定与下单清单

完整报告：需求卡及确认状态 → 指标科普 → 检索覆盖与转向摘要 → 候选比较/有依据的榜单及画像 → 场景推荐 → 下单核对清单。局部续查只更新受影响部分，引用既有需求与指标，不反复生成全篇。

每项推荐串起“满足什么—证据是什么—代价与未知是什么—下单核什么”。按场景分别给取舍，列最有决策价值的候选，通常不超过5项；不足少列，没有合格项就明说。放宽硬要求另列条件分支，用户未接受前不当主推。

型号命名查到规律才解释，同品牌不同渠道版本按具体规格比较。给用户可执行的判断；仅将公开渠道无法解决且会改变决策的问题留作客服/样品确认，不把全部研究转交用户。

报告按主题日期存到匹配目录，遵守宿主写入规则；续接记录确认项、淘汰前提、未验项和下一动作。仅在用户明确要求时更新持久记忆。时效信息注明采集日期及实时价限制。

## 红线

1. 历史、摘要、访问受限与未核验不能写成当前在售或已验证。
2. 公司承诺、用户反馈、独立实测和推算分开；不编参数、销量、引用或排名。
3. 硬约束未知的线索不冒充达标推荐；约束改变重查相关淘汰理由。
4. 不把列表顺序、佣金、热度或重复爆料当质量排名。
5. 无官方API或权限时用合法替代入口，不伪造签名、不绕过访问控制。
