# 中国采购：数据源与搜索入口

中国商品发现、或解释价格/销量/口碑/API字段时读取。这里是入口地图，不是网站质量排名；先选能回答当前问题的来源，再核实具体事实。整理于2026-09-01，接口与权限以使用时官方文档及实际结果为准。

## 按任务选渠道

| 当前问题 | 首选入口 | 取什么 | 下一跳与边界 |
|---|---|---|---|
| 标准品有哪些可买型号 | 京东、淘宝/天猫、拼多多、抖音商城 | 规格、卖家、商品链接 | 回商品页核可选规格，列表低价可能是其他变体 |
| 国内商品和别名 | 值得买商品/好价/文章/笔记搜索 | 商品线索、商家链接、历史记录、使用关键词 | 去重后回商城；爆料条数不等于商品数 |
| 非标材料、定制、零裁 | 1688、厂家、当地经销商/加工门店 | 牌号、尺寸、起订量、加工和配送 | 写清数量和城市；批发价不当单件到家价 |
| 当前价与历史促销 | 商品页＋值得买＋慢慢买 | 条件完整的价格记录 | 比同规格同口径；缺覆盖不能称全网最低 |
| 安装、体验、耐久、失败模式 | 订单追评、问答；小红书/B站/知乎/抖音 | 原始实拍、时长、问题和追问 | 检查同款、商业关系与转载；不按互动量排名 |
| 参数与兼容 | 厂家说明书、技术表、型号级检测报告 | 测量条件、使用限制、安装要求 | 国内外版本、受测样品与实购版本分别核对 |
| 性能比较 | 消协/消保委、香港消委会、方法透明的专业横评 | 同条件性能、安全及便利性 | 结果仅覆盖受测样品；认证不等于横评优胜 |
| 合规、安全和纠纷 | 标准、认监委、能效、药监（适用品类）、抽查/召回、12315公示/黑猫 | 型号、证书、批次及具体问题 | 区分备案、检测结论、投诉主张与处理状态 |
| 市场规模与份额 | NIQ/GfK、洛图、奥维等机构原始报告 | 品类、渠道、期间、监测或推算数据 | 未取得原始口径就降级；整机份额不外推配件 |

内容站按任务选，不要求每次全搜。网页不可读时，优先已授权的站内工具或用户可提供的页面，不反复停在搜索引擎摘要。未实测的入口标“待验证”，不声称已查过。

## 定向查询示例

示例展示搜索过程，不替用户决定产品形态：

- “白幕贴”展开为“投影墙贴”“前投膜”“哑光白幕料”；分别查背胶、静电和需张紧材料，先分类再按既定方案筛选，不只搜“最好白幕贴品牌”。
- “雪弗板”补“PVC发泡板”；查足厚、密度、结皮/共挤及单张裁切。只剩整柜报价就转当地经销商，不扩大海外工厂名单。
- “小房间升降桌”先找国内可买的尺寸系列，再用型号查最低高度、稳定性和售后，不用评论最多替代人体/空间适配。

“白软幕”若返回鞋和花洒，检查品类匹配与接口入参；17条若主要是同款反复促销，只计不同商品及规格，历史价另存。

## API与工具路由

1. 先检查宿主已提供的搜索/商城工具，再查平台官方文档；有工具不等于拥有该平台全部权限。
2. 官方授权接口优先；核应用凭据、账号授权、商品池、字段定义、更新时间及额度。商家自己的订单/库存接口不能代替全商城搜索。
3. 无权限时用允许的前台/站内搜索、定站查询或用户提供页面。遇访问控制停止该路径，不借凭证、不破解签名。
4. 未公开消费端接口和第三方数据服务，核来源、权限、时间及覆盖；返回JSON不等于官方全量数据。文档存在与本次成功调用分别记录。

| 通路 | 官方文档所列用途 | 必须核对 |
|---|---|---|
| 值得买开放平台 | 商品/好价/文章/笔记搜索；Agent商品检索、商品口碑、内容检索等 | 开通权限与字段来源；汇总追原文，零值不直接解释为零销量 |
| 淘宝联盟 | 导购物料、券及推广信息 | 可推广范围不保证全淘宝；无需用户授权不等于无需应用凭据 |
| 京东联盟 | 联盟商品、推广商品与订单 | 引单量/推广订单不当全站销量 |
| 多多进宝 | 推广商品搜索与返佣 | 推广池不是全拼多多，旧文档须核当前权限 |
| 1688、抖音电商 | 按具体开发者产品和权限查询 | 视频搜索、授权店铺数据、全商城检索是不同能力 |
| 小红书、B站、知乎等 | 前台内容供研究；开发者接口按各平台能力 | 不默认存在供任意第三方调用的全站搜索API |

值得买消费端 `https://api.smzdm.com/v1/list` 曾于2026-09-01匿名读取成功，仅是历史可达性线索，不是稳定公开契约。使用时重新核允许性与响应语义，不以它代替官方授权服务。

## 原始证据入口

按问题读取，不把列出链接等同已核验：

- [值得买官方目录](https://openapi.zhidemai.com/pages/)、[商品搜索](https://openapi.zhidemai.com/pages/search/3.%E6%90%9C%E7%B4%A2%E5%95%86%E5%93%81%E5%88%97%E8%A1%A8%E6%8E%A5%E5%8F%A3.html)：规格、店铺、好价、Agent能力与授权文档。
- [淘宝联盟](https://developer.alibaba.com/docs/api.htm?apiId=35896)、[京东联盟](https://jos.jd.com/jdunion)、[多多进宝旧版说明](https://commoncdn.yangkeduo.com/pdd_oms/2021-01-12/2e22638bda0b0f77479f89dab1de2988.pdf)、[1688](https://open.1688.com/)、[抖音权限](https://open.douyin.com/platform/resource/docs/accession-guide/type-and-permission)：接入线索，不是全站覆盖承诺。
- [慢慢买](https://tool.manmanbuy.com/)、[京东评价规则](https://help.jd.com/user/issue/41-51.html)：价格记录与评价口径。
- [北京消协](https://www.bjxx315.org.cn/bjxz/sxxbjsy/index.shtml)、[香港消委会](https://www.consumer.org.hk/sc)：核具体测试日期、样本和方法。
- [标准平台](https://std.samr.gov.cn/)、[认监委查询](https://www.cnca.gov.cn/hlwfw/)、[能效查询说明](https://www.cnis.ac.cn/tzgg/202501/t20250103_59327.html)、[药监查询](https://www.nmpa.gov.cn/zwfwqjd/index.html)：只查适用品类，不扩大认证意义。
- [市监抽查](https://www.samr.gov.cn/zljds/jdcc/)、[召回](https://www.samrdprc.org.cn/)、[12315公示说明](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/zfjcs/art/2023/art_a56f2982d6df4d759b1b548d07e3a839.html)、[黑猫帮助](https://tousu.sina.com.cn/help/index)：核具体主张、批次与处理状态。
