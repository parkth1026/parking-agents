# shopping-deep-research 设计文档

## 意图与触发场景

为高决策成本实物商品及既定方案的材料配件做循证选购：先在采购地发现实际商品，再核规格、性能、市场信号、口碑与交付。营销排名只提供线索；数据不可比时给条件明确的候选，不强制出榜。纯比价搜券、虚拟服务、单品识图和代写采购文书不在范围内。

## 设计取舍

1. **市场指标分开**（2026-09-01修正）：评论数默认只表示评价规模；可比销量须有期间、渠道、规格、单位和字段定义。不把爆料、推广引单或评价总量当全市场销量；旧轮断言见下方历史边界。
2. **访谈弹性轮数 + 需求卡确认**（iter-3 改）：一组 ≤5 问起步、未收敛继续追问、每轮末尾附「已锁定/仍待定」清单；收敛后输出需求卡（使用者/硬约束/一票否决/待定项）回读，用户确认或纠偏后才进调研。用户不在线（自动化/评测）时按"待定 + 分支结论"退化、需求卡标"未经确认"，不虚构答案。iter-1/2 原为"问答限两轮"，因与用户期望的"对话式慢慢锁定需求"冲突而改；无断言锁定轮数，AC-1 退化行为不变。
3. **D 级信源只当线索**：宁可结论慢，不要结论脏；企业自述单独标"公司口径"。
4. **纯指令技能、零运行时依赖**：主文档保留搜索决策和完成条件，中国来源/API知识按地区与问题读 references/china-sources.md。没有新增采集脚本；不为文案写关键词存在性测试。
5. **定性推荐与品牌画像**：按硬要求、实测、价格、口碑和交付作场景取舍；有可比数据才给对应榜，画像不折成自造综合分。厂商承诺、独立实测、个体反馈与推算按具体事实分开。
6. **指标摸底与商品发现分工**：保留含义/影响/读数及四档科普，但不让海外官网资料成为国内商品发现的前置筛选。已确认方案局部续查只补缺口；前提改变重查相关淘汰理由。
7. **结果驱动的定向搜索**：先名称/形态/地区分解，再选择入口；用相关候选而非总命中量判断效果。噪声、重复、批发不适配、访问受限各有下一动作；两批无增量时换路线或限定结论范围。阈值是可调整的工作起点，不是统计保证。

## 验收条件

| 编号 | 验收条件 |
| --- | --- |
| AC-1 | 需求缺口处理：用户不在线或信息不全时，影响结论的未知项标"待定"并给分支结论，不虚构用户答案 |
| AC-2 | 硬约束落表：物理/人体/预算/场景约束转化为可逐条核对的参数（一票否决 vs 加分分档），推荐型号不违反一票否决约束 |
| AC-3 | 市场信号口径：评论/爆料/联盟引单与销量分开，仅可比数据排序；无可比数据时给候选及缺口，营销榜单不作优劣依据 |
| AC-4 | 场景分榜：用户存在多个使用场景时，结论按场景分开给，不混排 |
| AC-5 | 在售证据：只推荐有在售证据的型号；抓不到在售证据的明确标"未确认在售" |
| AC-6 | 口径标注：价格、销量等时效数据标注检索日期或"以商品页实时价为准" |
| AC-7 | 结论可执行：最终落到面向用户约束的具体候选型号 + 可核对项（下单前核对清单或等价形式） |
| AC-8 | 诚实性：参数冲突标"口径分歧"、推算标"推断"，不编数；企业口径不转为事实陈述 |
| AC-9 | 品牌画像：按可得证据列售后/企业/可靠性，未知明示，逐项注明来源口径，不自造加权分 |
| AC-10 | 需求卡：进入调研前对需求做结构化汇总（含一票否决与待定项）回读确认；用户不在线时照常输出并标注"未经确认，按分支结论推进" |
| AC-11 | 指标框架：解释含义/影响/读数并分档；局部续查沿用已确认指标，推荐逐项带依据链，不强凑5项 |
| AC-12 | 定向入口：按采购地区、商品形态和证据缺口给出可执行查询；非标单件增加适用供货/本地渠道 |
| AC-13 | 搜索纠偏：噪声或重复高时改变词/渠道并去重；访问受限不当市场不存在，无法实测的入口不冒充已查 |
| AC-14 | 前提与商品状态：前提变化复查相关排除；零评论不否定在售，历史报价不当当前价；部件资料不当整体安全证明 |

## 本轮验证与历史边界

2026-09-01起主规则版本为search-routing-v1。history.json、trigger-benchmark.json及output-evals.json保留旧轮事实，不回写旧分数。旧output-evals.json含“评论数作销量代理”“评论数可作在售佐证”等旧断言，不能直接用于本版本质量验收；迁移后需新题库时期，不能与旧轮分数直接比。

本轮用search-direction-evals.json中的离线采购决策题检查查询路由，不新增运行脚本。with_skill/old_skill同批启动且分别使用新上下文，不带本次研究结论；without_skill因宿主任务数量限制启动失败，记NOT_RUN。题面提供虚构检索反馈，不联网，不冒充受控外部证据replay或live验收。主代理人工逐项读取两份输出，各7/7，未见区分度；不是独立评分或稳定性证明。真实检索质量、触发泛化与多轮稳定性尚未验证，质量结论为INCONCLUSIVE。过程证据位于仓库evals/shopping-search-direction-20260901/iteration-1/probe-review.json，属辅助探针，不并入旧联网成绩。
