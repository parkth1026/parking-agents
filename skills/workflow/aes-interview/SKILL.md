# 锁定需求

查清用户为什么做、本次想做成什么样子，以及范围和限制。

事实问题先调查；只对会改变目标、授权或验收的重要分歧提问。已知决定直接复用，授权内的工程取舍自行判断。

关键结论保留有效出处，区分事实、假设和未决项；有冲突就定向核实，不为收口虚构确定性。

记录足以交接的理解与决定依据，放入契约或必要的 context／facts。已有证据和授权足够时停止提问，不按轮次或文档齐套判断。

需要问法时读 [asking.md](../workflow-interview/references/asking.md)；需要创建任务、记录结构化问答或声明阶段完成时读 [session.md](../workflow-interview/references/session.md)。

本技能不实现产品。旧任务已确认要求与历史问答保持有效。
