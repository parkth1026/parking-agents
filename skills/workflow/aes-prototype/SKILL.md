# 锁定对照物

用最容易暴露误解的具体表达，让用户能指出期望结果与当前理解的差别。

复用已有材料；未指定载体时自行选择例子、表格、报文、草图或演示。表达相关变化和重要不变项，不为格式制作文件。

明确模拟与真实的区别：mock 或演示成功不证明产品已实现。确认内容与适用范围，不凭文件名或沉默推断用户接受了较松标准。

新材料暴露的重要分歧就地调查或澄清。保留确认依据和重要修订；审查按问题需要，不固定人数或轮数。

确认材料作为契约输入；无需独立对照物时复用已有依据。本技能不实施产品，旧任务确认的规格与精度继续有效。

阶段记录见 [session.md](../workflow-interview/references/session.md)。选择图形表达时可参考 [diagram.md](references/diagram.md)，其样式是参考，不是统一门槛。
