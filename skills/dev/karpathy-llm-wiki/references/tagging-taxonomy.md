# Tagging Taxonomy

Guidelines for tagging wiki pages. All tags must be defined here before use.

## Rules

1. Tags use **lowercase-kebab-case** (e.g., `language-model`, not `Language Model`)
2. Each page should have 2-5 tags
3. Include at least one category tag (from the top-level groups below)
4. Add new tags to this file before using them in a page
5. Prefer existing tags over creating new ones — check this list first

## Tag Groups

### Core Concepts
- `architecture` — neural network architectures and design patterns
- `training` — training methods, objectives, and procedures
- `inference` — inference optimization, serving, deployment
- `evaluation` — benchmarks, metrics, testing methods
- `safety` — alignment, safety, ethics, red-teaming
- `alignment` — RLHF, DPO, constitutional AI, value alignment

### Model Categories
- `model` — specific model (GPT-4, Llama, etc.)
- `language-model` — text-focused language models
- `multimodal` — models handling multiple modalities
- `open-source` — publicly available model weights
- `closed-source` — API-only or proprietary models
- `small-model` — models under 10B parameters
- `frontier-model` — state-of-the-art capability frontier

### Techniques
- `attention` — attention mechanisms and variants
- `fine-tuning` — fine-tuning methods (LoRA, QLoRA, full, etc.)
- `rlhf` — reinforcement learning from human feedback
- `prompting` — prompt engineering, chain-of-thought, etc.
- `retrieval` — RAG, retrieval-augmented methods
- `quantization` — model compression and quantization
- `distillation` — knowledge distillation
- `tokenization` — tokenizers, BPE, sentencepiece, etc.
- `embeddings` — embedding models and methods
- `moe` — mixture of experts

### Topics
- `scaling-laws` — scaling laws and emergent abilities
- `emergent-abilities` — capabilities that emerge at scale
- `reasoning` — chain-of-thought, logical reasoning
- `code-generation` — code models and programming
- `agents` — autonomous agents, tool use
- `long-context` — long context windows, memory
- `data` — training data, datasets, data curation
- `hardware` — GPUs, TPUs, compute infrastructure

### Organizations
- `openai` — OpenAI related
- `anthropic` — Anthropic related
- `google` — Google / DeepMind related
- `meta` — Meta AI related
- `microsoft` — Microsoft related
- `academic` — university research

### Source Types
- `paper` — research paper
- `blog` — blog post or article
- `talk` — lecture, presentation, podcast
- `tutorial` — educational material
- `comparison` — comparative analysis

### Meta
- `core-concept` — fundamental concept everyone should know
- `historical` — historically significant but possibly outdated
- `controversial` — topic with active disagreement
- `emerging` — new and rapidly evolving area
