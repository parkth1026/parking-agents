# 作者声音样本库（技能内示例层）

本目录与 `~/.config/parking-agents/voices/<作者名>.md`（环境层）构成两层画像结构，约定与 karpathy-llm-wiki 的 config 两层结构同构：

| 层 | 位置 | 内容 | 入库 |
| --- | --- | --- | --- |
| 示例层 | 本目录（技能内 `voices/`） | 随仓库版本化的示例画像、画像格式骨架 | 入 |
| 环境层 | `~/.config/parking-agents/voices/` | 本机个人画像（真实作者） | 永不入库 |

查询顺序：先环境层个人画像，再本目录示例；均无则按输入语域处理，不虚构样本。

## 画像格式骨架

文件名 = 作者名（如 `putonghu.md`）。结构：

```markdown
# <作者名> 书写风格画像

- 建立 / 语料来源与范围（时间跨度、体裁、篇数；标注纯人写基线与 AI 协写断层）
- 用途声明：借鉴句长、用词、标点与结构习惯；不搬经历、数据或立场

## 0. 一句话画像
## 1. 体裁分层（如适用：同一作者不同受众的体裁取不同规则）
## 2+. 按体裁分节：骨架 / 句式 / 用词词表 / 标点（可机检特征给计数） / 量化习惯
## 识别特征（识别用，不复刻）
错字习惯、大小写随手等，只用于判断原文语域，禁止写进改写稿。
## 仿写清单（正向 do/don't）
```

规则：画像内所有例句取自该作者真实语料；「识别用，不复刻」节必须有显式警告行。
