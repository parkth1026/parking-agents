# 第 0 格：处境与这次的决定

> 不算一层，是全景扫描的第一步。括号里的数字是报告纯文本行号；标「推导」的不是报告原话。

不先定这一格，V1 的「约束、必须贡献、赔得起」没有主语，各层也不知道该问事前版还是事后版（推导）。不先问清这次要拍哪个板，回答只会顺着用户提的那个下游问题往下说（180、1816）。这一格只做登记和分流，不下判断；它和 V1 一起是上溯的终点（推导）。

## 要定的四件事

### 1. 谁在问、以什么身份、钱和时间是谁的

**问**：这件事你是以什么身份在做：花自己的钱和时间，还是替别人（公司、出资人）做？钱和时间从哪来，谁有权说继续或停？手里现成有什么：能做什么、认识谁、能承担什么实验？事前版：同事后版。

**怎么判**：处境五选一（划分为推导）：A 从零开始，花自己的钱和时间；B 已上线产品的负责人，产品没起色；C 公司里的新项目负责人，有旧业务，批资源的是别人；D 已过验证期的经营者（属九类尺子外，照答，标明是经验）；E 不以赚钱为首要目的。另有一种输入：评一份材料、当事人不在场，走「当事人不在场时」一节。判定办法：指得出出钱的人和有权说停的人，这一项才算定；指不出记「未知」，带进 V1。

**答案不同，后面哪里跟着变**：V1 三个词的主语。V1 第 1 问用哪种替换问法（见「几种处境下『为什么做』的问法怎么换」）。是否加载「有旧业务」条件包。V1、V8 里「多少算够」问谁：别人定指标时问「这个数是谁定的」，自己出钱时问「你自己要它到多大才值得继续做」（推导）。只有一个人做时，V7「最懂的人没插手」问不出口（推导）。

来源：推导；锚点：读者设定 22、前提 147、G0 185；T03 手段盘点 1105–1107

### 2. 这次桌上要拍的是哪个板

**问**：这次聊完，你要做的是哪一个决定？只选一个：开始试、选方向、定价、加码、转向、停。追问一：如果我说行和说不行，你接下来做的事会不一样吗？一样，就说明要拍的不是这个板。追问二（用户说「继续投入」时）：这一轮是花小钱换信息，还是正式投入去检验有人用、能复制？事前版：同事后版。

**怎么判**：六选一（清单为推导）。判定办法：用户问的是下游具体问题（怎么定价、怎么标准化）时，先归到六个板之一再答。归不进去（只想听看法、要全面诊断）记「无待拍决定」，直答写跑不跑得通、最该先做什么，「我怎么看」后面给八个方面的白话状态表，不出裁决（见产出模板页）。「开始试」和「加码」必须分开：前者可以小额启动，后者要客户与经济证据（C01 1156；B00 252）。继续、调整、暂缓、停止的逐轮裁决归闭环检查（W16 1923；T06 1135），这里只登记是哪个板。

**答案不同，后面哪里跟着变**：扫描从哪层进、重点查哪层（以下对应为推导）：选方向从 V2 进，先看 V1 有没有尺；定价从 V5 进，必须回看 V3 的替代代价和 V7 的成本回填；开始试重点看 V1 的上限与停止条件、V2 初选、V3；加码要过全部层和闭环检查；转向先查有没有反证（1543）；停交闭环检查的收尾。给用户的直答围绕这一个决定写。追问二的答案直接给 V1 的「这一轮的身份」用（T01 1087）。

来源：W11 首字段「要改变哪一个决定」1816；关卡总则「每一关只回答一个经营决定」180；C01 1156；B00 252；T01 1087；T06 1135；W16 1923；六个板的清单与层的对应为推导

### 3. 手里最强的证据到哪一步

**问**：到今天为止，真实发生过、走得最远的一件事是什么？从上往下对：有没有第二个互不相干的客户也买了并且持续在用；有没有人在知情的情况下付了钱、你也交付了；有没有人为它付出过代价（时间、资料、样本，或往购买走了一步、回应过报价）；有没有让符合条件的人用原型做过真实任务；有没有问到过别人近期的具体经历和现在的凑合办法；还是只有自己的判断和类比。每件事说出对象、时间、经过。事前版：同事后版（这一问本身就是切换开关）。

**怎么判**：E0–E6 七级（210–216）。判定办法：按发生过的事定，不按自评；说不出对象、时间、经过的，按低一级记（推导，依据 206「样本代表性、测量质量和具体情境比级别名称更重要」）。每层、每个角色分别标，不只记一个最高值（206「同一项目的不同假设可能位于不同层级」）。案例和类比只算 E0（210）。自家的账和当事人的决定不上这把梯子，用「事实、线索、推断、未知」四档（W10 1802；两套标尺的分工为推导）。

**答案不同，后面哪里跟着变**：决定 V2–V8 每条必问句问事前版还是事后版，见「问事前版还是事后版」一节。没有客户时 V5–V7 的证据统一记「内部判断」（推导）。防越级（下游结论不得高于上游最弱一环）归闭环检查，这里只定级。

来源：证据梯级 205–216；总则 206；W10 1802

### 4. 约束是谁的

**问**：卡住你的那件事，是这门生意的、这个产品的、上面给的，还是你自己的（钱、时间、能撑多久）？换一个人来做同一件事，这条约束还在吗？事前版：同事后版。

**怎么判**：四选一（推导）：生意的（一门在运营的生意被卡住，185、244）；产品的（已上线产品没起色）；批资源的人给的（公司内项目，目标和上限是别人定的）；当事人自己的（从零开始）。判定办法：换人之后约束还在，是生意或产品的；换人就没了，是当事人自己的。答成「要增长」「要上某项技术」不算答了，原样交给 V1（G0 停止信号 185）。

**答案不同，后面哪里跟着变**：V1 第 1 问的问法和取证对象（见「几种处境下『为什么做』的问法怎么换」）。V1 的贡献线、赔付上限是谁的决定、找谁确认。约束是当事人自己的时，个人目标与意愿报告没有题源，V1 这部分只能标推导。

来源：推导；G0 185；B00 244；T03 1105

## 问事前版还是事后版

总规则（推导；报告没给关卡标证据级别）：一条必问句的事后版以某件事已经发生为前提（有客户、报过价、收过钱、交付过、有第二家）。那件事在第 0 格登记为发生过，问事后版；没发生过，问事前版，并把这层证据记「内部判断」（E0，210）。

分层分角色定，不用一个总级别（206）。有多个角色时逐个定级，本层取最弱一环：付钱方到了 E3、使用者只有 E0，V3 对使用者就问事前版（推导）。

参考对应（推导，按 210–216 各级的文字；每条问句的门槛由各页自己标）：
- 只有 E0：V2–V8 全问事前版；V2 只做初选。
- 到 E1（问到过近期具体经历与原有替代）：V3 问事后版；V2 可以定取舍。
- 到 E2（真实任务、代表性原型测试）：V4 问事后版。
- 到 E3（有成本的推进、报价响应）：V5 里「报过价、对方推进过」的问句问事后版；「收过钱」的仍问事前版。
- 到 E4（知情付费与真实交付）：V5 全问事后版；V6「从买下到用上」、V7 首次交付的成本记录问事后版；「第二家」仍问事前版。
- 到 E5（独立客户复制加持续使用或续约）：V7 问事后版；V5 的续费问句问事后版。
- 到 E6（可重复获客、贡献与可靠运营）：V6 重复获客、V8 规模里能实测的部分问事后版。

V1 不看这把梯子：贡献线、投入上限、停止条件是当事人的决定，两版相同；约束诊断在有经营记录时问事后版，没有时按「几种处境下『为什么做』的问法怎么换」的替换问法问。

回退：问了事后版，对方说不出对象、时间、经过，退回事前版并降一级（推导，依据 206）。防越级归闭环检查。

## 现在该发散还是该收敛

报告原话（1542）：候选阶段广泛；验证阶段有限并行；开发与进入市场阶段集中。以证据决定收敛，不以会议气氛决定。（1543）：战略规定问题范围、取舍和投入边界，实验修正具体假设；既不每次访谈就换战略，也不为维护战略拒绝反证。

判定办法（阶段怎么对上第 0 格的答案为推导）：
- V2 初选没做完、证据在 E0–E1：该发散。多列候选，不急着排序。只带一个方向来的，先补备选（G1 停止信号 187，展开归 V2）。
- 方向已选、正在取证：有限并行。新想法记进候选清单，不进本轮。「并行几个」报告没给数，不设门槛。
- 决定正式开发、开卖：该集中。

两条当场可核对的判定句（推导自 1542、1543）：
- 要砍掉一个候选时，说得出是哪条证据淘汰了它。说不出，是凭气氛收的，还不该收敛。
- 要加方向或换方向时，说得出是哪条反证推翻了现方向的哪条假设。说不出，是「每次访谈就换战略」。反过来，反证已出现却被解释成例外，是「为维护战略拒绝反证」。

与「拍哪个板」的关系（推导）：板是选方向，处在发散转收敛的交界；板是转向，先查有没有反证；板是加码，先查当初的收敛是不是证据定的。同一方法用错阶段可能比不用更危险（1537）。

## 当事人不在场时

固定五步（推导；报告锚点 1611、178–180）：
1. 先在材料里找四件事的答案，逐项标「材料写明（带行号）」「材料侧面透露」「材料没有」。
2. 材料没有的记「未知」，不猜，不替当事人补。报告允许写未知，但每个关键未知要有验证任务（1611）；这里的验证任务就是去问当事人。
3. 四件事里有未知时，缺口怎么进「我还需要你回答」、受影响的判断怎么按写明的假设带条件答、哪些事照常做，照上溯根因页第 6 步的四件固定动作，本页不重写。未知不当真正卡住的地方。
4. 「拍哪个板」材料没写时，从材料的结论句反推候选并标推导。结论句有两种读法的（例如「继续投入」可能是开始试，也可能是加码），两种都列，各写需要的证据；直答时按更保守的一种（开始试）先答，写明这是假设，请用户确认。
5. 证据级别只按材料里可核对的发生过的事定。调研体例、没有客户的材料，V5–V7 统一记「内部判断」，全问事前版。

## 在这里一次判定的条件包与开关

两个跨层条件包在这里一次判定，判定结果带给所有层，各页只留与本层直接相关的一句。

1.「有旧业务」包。触发句：「除了这件事，你或公司现在有没有一门在运营、在收钱的生意？这件事会不会和它共用人、钱、客户或渠道？」答有就加载。包内再分三个子触发：共用资源时；做事的人和批资源的人不是同一个时；新事做成会替代现有收入时。内容：两类成果分开记账、共享与隔离、预算人与裁决人、考核与阶段匹配、旧渠道（B01 271–274；B03 328–331；B15 414–416；W03 1658–1665）。被叫作「第二曲线」「新增长引擎」时的口径（术语 2012；T01 1087）并入这个包。

2.「付钱与使用分离」包。触发句：「掏钱的人和实际用的人是同一个吗？从买下到用上，中间要不要第三个人动手？」不是同一个，或中间有第三方，就加载。内容：角色链（B11 766；B17 794；术语 2013）。角色名单在 V6 一次画全；四条同时成立（150）归闭环检查。

另有几个开关，不是包，是各页条件项的触发条件，在这里集中问一次、各页直接引用（集中到本格为推导）：
- 交易形态：「客户是一家一家谈、按单成交，还是自己上来就能买能用？」决定按单销售、企业采购、报价类条件项是否触发；自助型改成分批比较（B20 679）。
- 技术当理由：「把技术名词（AI、三维等）拿掉，这件事还说得清吗？」说不清就触发 V1 的「技术当理由」条件项（185、244、147）。
- 声称是标准产品：「你说它是标准产品吗？」说是就触发 V7 的标准化条件项（推导）。
- 产品形态与客户类型：软件、实体还是服务；客户是企业还是个人消费者。软件专属内容按条件项加载；实体与服务、面向个人消费者属九类尺子外：各层按通用句照判，专属部分照答，标明是经验。

## 这一格尺子外的问题

下面九类不在诊断尺子里，本格只登记。碰到时照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：先查每条写的上游，再给做法，做法前标明是一般经验，每条做法写出前提。

- 团队与当事人：本格只登记身份和谁说了算。个人目标与意愿、团队与这件事的匹配、合伙关系，报告无题源（读者设定 22），只给经验。
- 时机：「为什么是现在、早了还是晚了」只给经验。报告只有一个时点隐喻，自认不是预测器、不给启动年份（237、1158）。先回查 V1 第 3、4 问：这一轮是换信息还是押注，上限多少。开始试和全押是两个决定（1156；252）。
- 融资与现金：本格只登记钱从哪来、能撑多久。融资节奏、账期、现金周转只给经验。
- 验证期之后的经营：处境是「已过验证期的经营者」时，说明这张地图止于验证期（报告止于 G9，203），先查眼下的问题是不是当初某层没站住留下的，再给经验。
- 面向个人消费者的产品：客户类型判为个人消费者时，各层按通用句问，消费者专属的定价、留存、口碑只给经验。
- 实体与服务类生意：产品形态判为实体或服务时，各层按「输入到结果」的形态照问，供应、产能、质量一致性、库存只给经验。
- 竞争动态：桌上的板是「对手降价或抄了要不要跟」时，本格登记；先回查 V2 的比较对象和 V8 的压力测试，再给经验。
- 获客与增长引擎怎么建：桌上的板是「怎么搭增长引擎」时，本格登记；先查 V6 客户从哪来、能否重复来有没有证据，再给经验。
- 合规：桌上的板取决于合规判断时，交相应专业人员核验（218 末句）；本格只查关键输入和授权验证过没有。
