# V2 做哪个：机会与取舍

**这一层只回答**：为什么是这个机会而不是别的，靠什么赢，不做什么。本层过两次：初选只到候选与比较；定取舍要等 V3 交回「客户不买你时用什么」后，才定比较对象和不做清单。

**多个角色时**：方案里并列着不止一类客户、不止一个角色（付钱的、用的）或不止一类场所时，场域句、「好在哪」、核心指标按每一类逐个问，任一类填不出，本层取最弱一环。角色名单取 V6 的，不在本层画。状态分两段报：初选、定取舍各取最弱一环；V3 还没交回替代事实时，定取舍记「待 V3」，不记「没站住」。（推导；锚点 1576「只选一种任务和一类商家」）

## 必问句

1. **事后版**：除了现在这个方向，当时摆在桌上的还有哪几个？每一个输在哪一条上？
   - **事前版**：现在桌上有哪几个候选？你打算按哪几条比，凭什么认为这一个更好？
   - 答不上来说明：属初选。答不出备选，方向只来自一个人的偏好或第一个找上门的客户。说不出按哪一维输的（购买理由、可达规模、经济性、实现障碍、到收入的时间、外部风险），比较是事后补的。
   - 来源：G1 187；B06 484、492；C10 1264；1574
2. **事后版**：把行业名和技术名拿掉，用一句话说：服务谁、在什么触发情境下、帮他完成什么、他在哪里会遇到你、替换掉他现在的什么做法？
   - **事前版**：同一句话按你的打算填。五格里哪几格核对过，哪几格是猜的？
   - 答不上来说明：属初选。句子里只剩行业名、技术名或「所有客户」，说明还没选。哪一格填不出，下游就在哪出事：填不出「在哪里遇到你」是 V6 的事，填不出「替换什么」是 V3、V5 的事。
   - 来源：B05 472；W04 1676；W05 1700；G3 191。「在哪里会遇到你」的通用说法和后半句对应关系为推导
3. **事后版**：客户不买你时用的那个做法（取 V3 的结论，本层不重问），你比它好在哪一点？这一点客户自己能检查吗？另一种赢法你为什么没选？
   - **事前版**：你打算让客户拿你替换掉什么？凭什么认为他会这样比？你打算好在哪一点，他怎么自己检查？
   - 答不上来说明：属定取舍。答出的差异是能力名词而不是结果改善，「靠什么赢」没落地。比较对象是自己挑的对标，定取舍没过。只有一种赢法且说不出另一种为什么不选，说明没选过。
   - 来源：B22 881–882；W05 1701；B05 473；C28 1480。引用 V3 而不重问为推导
4. **事后版**：你拿来衡量成功的核心指标，是客户的结果还是你自己的成本？已有的客户是凭这一项选你的吗？
   - **事前版**：你拿来衡量成功的核心指标，是客户的结果还是你自己的成本？凭什么认为客户会拿这一项来选？现有做法在这一项上已经到哪了？
   - 答不上来说明：属定取舍。指标是自己的成本、周期或能力参数，说明在打磨的这一环不是客户买单的那一环。现有做法在这项上已经达到，这项不构成差异。
   - 来源：推导；锚点 4.3 战略布局图 1035、B16 530、B22 882、W05 1701
5. **事后版**：你明确不做的是什么：哪类客户、哪种任务？最近一次真的放弃或拒绝的是什么（一个客户、一个请求、一笔生意），它保护了什么？
   - **事前版**：你打算不做什么：哪类客户、哪种任务？第一个不在范围内却找上门的，你拒吗，凭什么拒得掉？
   - 答不上来说明：属定取舍。清单为空，或每一项说不出保护了主任务的什么，聚焦只是说法。事后从没放弃过任何东西，清单没有约束力。事前答「到时候看」，等于没有清单。
   - 来源：B04 447；W05 1704；B16 520、1036。「最近一次放弃的是什么」和事前版为推导

## 站住了长什么样

- 初选：至少有一个写下来的备选，并写明主攻在哪一条可比维度上优于它；没证据的高潜力方向标着「待验证」。（187、492、1681–1684）
- 初选：方向写成了一句场域句，行业名和技术名不单独充当场域：谁、什么触发情境、什么任务、在哪里遇到你、替换什么；猜的格子标了出来。（472、1676、1700；标猜测为推导）
- 定取舍：比较对象取自 V3 交回的客户实际做法，不是自己挑的对标；「靠什么赢」写成相对它的、客户自己能检查的结果差异，并说得出另一种赢法为什么不选。（1701、881–882、1480、473）
- 定取舍：衡量成功的核心指标是客户用来选择的那项结果；自己的成本和能力参数只当内部指标。（1035、882；判定句为推导）
- 定取舍：有一份不做清单（不服务哪类客户、不接哪种任务），每一项说得出保护了主任务的什么。（447、1704）

## 没站住的信号

- 机会只来自一个人的偏好，或只来自第一个找上门的客户，没有写下来的备选。（187；484）
- 问「靠什么赢」，答的是目标数字、行业名或能力名词。（191；436。目标当诊断的幻觉归 V1）
- 候选机会每一条都是「低挑战、高潜力」，通常是把获客、采用、数据或完整成本藏起来了。（509）
- 比较对象是自己挑的对标或同类产品的宣传材料；或核心指标是自己的成本与能力参数，客户并不拿它来选。（881、1480、1035；后半句为推导）
- 声称聚焦，但不做清单为空，来的客户都收；或差异化四格只填了「增加」和「创造」。（447；520、1036；G3 191）
- 把几类客户或几个场景并排写，它们的输入、入口、付钱人各不相同，却没选主攻。（02 页症状表第 2 行；报告 472、970；推导；1576、1684）

## 上下游

- **依赖上游**：依赖 V1 三个结论：约束诊断（选择要能从诊断推出来，445、1698、1573）；必须贡献什么（候选之间比可达规模和经济性要有尺，1681）；赔得起多少（决定同时取证几个方向，300、1645）。依赖第 0 格：这次要拍的是不是选方向，现有证据到哪一级，据此问事前版还是事后版。V1 没站住时，本层只帮着列候选，不给排序结论（推导）。
- **回边与并列**：V3 回 V2：定取舍要等 V3 交回「客户不买你时用什么」，比较对象和可测差异才能判真（报告顺序 G1→G2→G3，186–191；881、1480）。初选可以先于 V3。V3 证据不足不等于 V2 没站住：V2 没站住的标志是没有选择，不是选择还没被证实（推导）。V8 守得住回 V2：守得住是「靠什么赢」在别人跟上来之后的复核，V8 查出守不住时回本层重看取胜假说（909、358；回边为推导）。
- **本层没站住时，下游这些问题不直接答**：
  - V3：初选没过，不直接答「先做哪个功能、该访谁」；事实调查可以并行，被挡住的是访谈对象的挑选和需求排序。（472、970、180）
  - V4：核心指标不是客户用来选的，不直接答「这项指标做到多少才达标」。（1035、882；推导）
  - V5：比较对象没定，不直接答「定多少钱、按什么收」；价格参照来自客户不买时的开支，赢法不同收费要求也不同。（881、473、1041）
  - V6：所选赢法与到达客户的方式没对齐，不直接答「怎么激励渠道」。（464、475、415；根因归属为推导）
  - V7：场域没选、没有不做清单，不直接答「怎么标准化、怎么复制到另一类客户」。（445、826）
  - V8：「靠什么赢」还是能力名词，不直接答「护城河怎么建」；场域还是行业名时，算出来的规模只是宏观总量。（882、909、854）

## 什么算证据

**算**

- 选择本身有没有：写下来的备选、场域句、不做清单，有或没有可以直接判。（187、447、1704）
- 初选：内部判断与类比（E0，210）够把机会放进候选并排出主攻，但主攻要标「待验证」。（187、502；E0 够初选为推导，报告未给关卡标梯级）
- 定取舍：比较对象要来自客户的实际行为，即 V3 交回的近期具体经历与原有替代（E1，211；881、1480）。E1 为下限是推导。
- 差异可测：相对 V3 那个实际做法、客户自己能检查的结果改善。（1701、882）
- 不做清单有没有约束力：事后看放弃或拒绝过的具体客户、请求；事前看清单是否写明、每项是否说得出保护什么。（447；问法为推导）

**不算**

- 行业规模与增速。（1554、1129、854；市场幻觉归 V8）
- 同类东西已有人在买、别人收到了钱：只算内部判断与网络类比一级。（210；推导）
- 一个人的偏好，或第一个找上门的客户。（187、484）
- 技术演示或内部跑通。（1553、158；主归 V3）
- 把潜力与挑战压成的总分、五力主观分求和。（494、1129、218）
- 选择写得明确、格子填满；逻辑讲得通。（481、453）
- 别家做成的案例。（1555；归案例类比纪律）

## 指针：归别处的内容

- 「客户不买你时用什么」的事实和「没有竞品」的幻觉归 V3；本层只引用它定比较对象；V5 只问这个代价是否对应一笔能挪动的钱。
- 目标当诊断归 V1；技术幻觉主归 V3（V1 留「技术当理由」）；市场幻觉归 V8。
- 必须为真的命题清单和假设总账（474、1705、W10 1797）归闭环检查。
- 行动一致性（446、475、1697：产品范围、到达方式、收费、交付、考核同页比对）归闭环检查；本层只交出选定的赢法。
- 标准边界内不支持哪些输入归 V7；V1 碰到「这个客户要破例接不接」指向本层的不做清单。
- 通用能力替代：V3 列进替代清单，V8 做压力测试，本层不收。
- 角色名单归 V6 一次画全。
- 同一机会比较不用技术、简单做法、复杂技术三档解法（972、1579）归 V4。（归属为推导）
- 同一能力比较几种收费结构（301）归 V5。
- 「现有厂商为什么不跟」的核查（1024）归 V8 守得住，查出问题按回边回本层。
- 现在该发散还是该收敛（1542）归第 0 格。
- 案例类比纪律（1555、1148）、证据梯级防越级、不取平均（218）、评审六问、预先写判定线、逐轮继续或停止裁决（W16）归三条强制动作。
- 有旧业务时的组织安排、付钱与使用分离时的角色链，各归一个跨层条件包。

## 这一层尺子外的问题

九类问题照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：本层能查的先查，做法前标明是一般经验，写出前提。

- 竞争动态：对手出招后怎么应对、要不要跟价，本层只定静态的比较对象，应对只给经验。
- 时机：为什么是现在、早了还是晚了，只给经验。
- 获客与增长引擎怎么建：场域句只问「他在哪里会遇到你」，引擎怎么搭只给经验。
- 团队与当事人：这个机会和团队配不配、谁来做，只给经验。
- 融资与现金：哪个方向更好融资、故事更好讲，不作为比较维度，只给经验。
- 合规：各候选的合规门槛高低，交专业人员核验（218）。
- 面向个人消费者的产品：必问句问得出口，但品牌、内容、口碑这类赢法报告无题源，只给经验。
- 实体与服务类生意：选址、供应、产能类的取舍，只给经验。
- 验证期之后的经营：要不要做第二个产品、换人群、做平台，只给经验。
- 报告无题源：证据到哪一步可以从多个候选收敛到一个（1542 只说以证据决定）。
- 报告无题源：「靠什么赢」有哪几类来源（429 自认遗漏）。
- 报告无题源：先打哪、后打哪的打法顺序，只有滩头概念到定义级。

## 薄在哪

- 收敛判定缺：G1 只说主攻「优于明确的备选」（187），没说按哪一维算优于、各维冲突时怎么裁。
- 关卡与证据梯级没有对应（182–216）：初选和定取舍各到哪一级是推导。
- B06 潜力与挑战只有维度名，没有评估细则（485）。
- B04 只有战略内核四条，「靠什么赢」的来源类型没有清单（429）。
- 不做清单只有一句判定（447），没有何时允许破例、谁批的规则。
- 多少反证该换方向没有判定（1543）。
- B16 工具各一句、无步骤（513）；W04、W05 只有字段标签。
- 「核心指标是客户的结果还是自己的成本」报告没有原句，锚点是 1035、530、882，判定句为推导。
- 「品类有人买就当切口成立」不在报告六种幻觉里，是推导。
- 所有事前版问法和事前迹象都是推导；报告动作栏例句写死在 AI、三维、付钱与使用分离的语境（472、530、881）。
- 案例没有比较过程（C09 只到「比较后选了」1248），没有取舍正确仍失败的样本。
