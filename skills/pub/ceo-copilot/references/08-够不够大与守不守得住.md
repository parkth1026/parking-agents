# V8 够不够大；守不守得住

**这一层只回答**：做成之后够不够大；别人或更便宜的通用能力跟上来之后还剩什么。

**多个角色时**：适用。够不够大：有多条收入线或多类付钱人时，每条单独倒推、单独数可达客户，没接触过的付钱人的钱不加进总数；本格状态取最弱的一条（推导，依据 206、218）。守不守得住：声称多项优势时逐项证收益、屏障、归属，不打分、不加总（918、1129）。两格各给各的状态，不互相平均（218）。角色名单取 V6，本页不重画。

## 必问句

1. 〔够不够大〕**事后版**：这件事要到多大才算数？（尺子取 V1 的贡献线。）按它倒推，要多少客户、多大客单、多高留存、多大的销售和交付能力？这几个数哪些是实测，哪些是假设？
   - **事前版**：你打算用哪条线判够不够大？按它倒推的每个数各凭什么这么填？哪个数最没把握、一变账就不成立？
   - 答不上来说明：说不出尺子，够不够大没法判，根因在 V1。给得出数，但它是覆盖自身开销的打平线，或只算在已被否掉的收费方式上，等于没有尺子（推导）。数全是假设，规模账还没有实测支撑。
   - 来源：B10 728、737；W12 1844–1845；评审六问第六问 2004；B00 245；逐数标级 206
2. 〔够不够大〕**事后版**：倒推出来的客户数，在你现在够得着、对方买得起的范围里数得出来吗？是自下而上一个个数出来的，还是总量乘一个比例？
   - **事前版**：你打算先卖给哪一批？这一批里现在点得出来、够得着、买得起的有多少？首个切口和远期市场分开写了吗？
   - 答不上来说明：只拿得出行业规模和增速，是市场幻觉。点不出下一批相似客户，说明首个切口没定，根因在 V2、V3。
   - 来源：B21 854–855；4.1 第 04 步 995、第 14 步 1005；张力表 1549；市场幻觉 1554
3. 〔够不够大〕**事后版**：客户多起来之后，每个客户的贡献和交付质量是变好还是变差？最近一批和前一批，用同一来源、同一版本、同一时间窗比过吗？价格降、成本升、回款变慢各算一遍，账还成立吗？
   - **事前版**：客户数成倍增加时，哪些成本跟着客户数涨，哪些会被摊薄？凭什么这么认为？价格降、成本升、回款变慢三种情形各算过吗？
   - 答不上来说明：没比过或后一批更差，说明新增客户在增加服务量，扩张会放大亏损；成本事实去 V7 查。只有一版乐观账，不能说成确定的增长。
   - 来源：G9 继续理由 203；W14 1887；B20 679；4.2 规模经济 1022；W12 1846–1847；B10 738–739；1604；事前版为推导
4. 〔守不守得住〕**事后版**：假定你的核心能力明天就被对手或更便宜的通用能力拿到，现在的客户为什么还选你？答案要落到结果可靠性、数据权利、渠道、流程、成本里的具体一项。
   - **事前版**：V2 写下的「靠什么赢」，在别人也有同样能力之后还剩哪一项？凭什么这么认为？
   - 答不上来说明：答案仍是功能名或资源名，说明价值停在功能层，没到任务结果，按回边回 V2 重写取胜假说。答案正好是 V3 替代清单里那个通用工具，说明相对真实替代的差异没定义。
   - 来源：B23 909；W15 1900；B13 359；推演第十步 1582；「回 V2」为推导
5. 〔守不守得住〕**事后版**：剩下的这一项：好处怎么测？对手是不能跟还是不愿跟，证据是什么？多出来的钱最后落在客户、供应方、渠道、关键人才还是你手里？客户随时能走的话，他还留下吗？
   - **事前版**：你打算靠的这一项：好处准备怎么测？凭什么认为对手不能或不愿跟？相关的数据、渠道、关键供给的权利现在在谁手里？没有锁定时客户凭什么留下？
   - 答不上来说明：说不出对手不跟的证据，只是希望它不跟。权利在别人手里，收益可能流走。客户留下靠导出困难或合同绑定，屏障没有和客户净收益一起成立。
   - 来源：B23 900、911–912；4.2 表头 1018、反向定位 1024、稀缺资源 1027；W15 1902–1906；张力表 1548

## 站住了长什么样

- 【够不够大】有一张从 V1 贡献线倒推的表：客户数、客单、留存、销售与交付规模都写出，每个数标明实测还是假设。（B10 730、737；W12 1844–1845；206）
- 【够不够大】倒推需要的客户数，与自下而上数出的、够得着且买得起的客户数并列写出，前者落在后者之内；首个切口与远期市场分开写。（B21 854；4.1 995、1005；比较规则为推导，依据 W12 1845 把两者并列）
- 【够不够大】事后：同来源、同版本、同时间窗的批次对比里，后一批的每客户贡献和交付质量不比前一批差。事前：写明哪些成本随客户数涨、哪些摊薄，并标为假设。价格降、成本升、回款慢三个情景都算过，收入、贡献、经营利润、现金分列，不是只有乐观情景成立。（G9 203；W14 1887；B20 679；W12 1846–1847；B10 738；1604；事前写法为推导）
- 【守不守得住】压力测试有具体答案：核心能力被拿走后，剩余价值落在结果可靠性、数据权利、渠道、流程、成本中的某一项，并且与 V2 的取胜假说说的是同一件事。（B23 909；W15 1900；与 V2 对照为推导）
- 【守不守得住】这一项同时写出了四样：好处怎么测、对手不能或不愿复制的证据、收益归谁、没有锁定时客户是否仍留下。（B23 900、911–912；4.2 1018；W15 1902–1906）

## 没站住的信号

- 【够不够大】规模论据只有注册数和合同数，没有贡献、现金、续用的数据；或预测收益依赖未经证明的低成本、高续费和无竞争。（G9 停止信号 203）
- 【够不够大】够大的理由是「行业很大、在增长」，拿不出可达客户、预算和价值分配分析。（市场幻觉 1554；张力表 1549；B21 854）
- 【够不够大】客户越多，每客户贡献或交付质量越差；或新增客户反而增加大量服务。（4.2 规模经济 1022；G9 继续理由的反面 203）
- 【守不守得住】优势论据是资源名称（有某项技术、有数据、先做的），说不出收益、屏障、权利归属和持续时间。（护城河幻觉 1558；W15 1899；4.2 1018）
- 【守不守得住】「对手不会跟」拿不出不能或不愿的证据；或客户留下靠的是导出困难、合同绑定。（4.2 反向定位 1024；B13 358；B23 912；张力表 1548）

## 上下游

- **依赖上游**：够不够大：V1 给贡献线（尺子），V5 给每客户贡献口径、收费单位和续费实测，V7 给每客户成本清单和复制证据；V1 没站住时本格只能写「待定尺后才可判」（B10 737；2004；W12 1837–1845；215）。守不守得住：V2 给取胜假说和不做项，V3 给替代清单（含通用能力）和任务结果；判收益归属要用的渠道、数据权利归属取 V6（G3 191；B13 359；W15 1904）。
- **回边与并列**：守不守得住 → V2：压力测试答不出具体一项，或答案与 V2 的「靠什么赢」不是同一件事时，回 V2 重写取胜假说，再回本格复核（推导，依据 B23 918「先证明客户价值与经济性，再判断哪些优势可能累积」、G3 191）。V7 → V5（成本回填定价）不在本页，本页只用回填后的每客户贡献。V5 与 V6 并列，本页两个都取。
- **本层没站住时，下游这些问题不直接答**：
  - 本层是最下游，挡住的是扩张决定。「要不要加码、铺渠道、扩团队」不该直接答：无法证明单位贡献、真实采用、可靠交付时，不因融资或领导期待大规模铺渠道。（B14 388，扩张判定只在本页收）
  - 「要不要做重大不可逆承诺」不该直接答：现金、重大责任和不可逆承诺不能靠「敏捷」绕过。（180；T06 1139）
  - 「这门生意已经成立、可以当成需要的那条增长来投」不该直接说：结果不够大可能仍是好产品，但不等于够大。结论只能写成「在某类客户、某个边界和收费范围内，现有何证据、还缺什么、下一笔投入验证什么」。（B10 737；1606）
  - 守得住没站住时，「怎么建壁垒」不该直接答：先证明客户价值与经济性，再判断哪些优势可能累积。（B23 918）
  - 守得住没站住时，V2 的取胜假说标为「待复核」，不拿它当已定的前提往下用。（推导，回边）

## 什么算证据

**算**

- 同来源、同版本、同时间窗的客户批次对比。（B20 679）
- 续费和流失的实测值，且与假设分列；实际续费，不是续费概率。（W12 1844；B17 797）
- 自下而上数出的、够得着且买得起的客户。（4.1 995；B21 854）
- 独立客户复制加持续使用或续约（E5 215）；可重复获客、贡献与可靠运营（E6 216）。规模结论对应这两级的文字描述，这一对应为推导。
- 对手不能或不愿复制的证据；数据与渠道权利的归属和有效范围。（W15 1903–1904）
- 事前：倒推表里每个数按各自证据分别标级（206）。事前的倒推表只算暴露了假设，不算预测（B10 746）。

**不算**

- 注册数和合同数。（203）
- 宏观市场总量和行业增速。（854、1554）
- 短期数据外推的多年客户价值；年度合同当作长期经常性收入；猜测续费率算出的精确数。（856、797、2025）
- 资源名称；总用户数当作网络效应。（1899；C24 1430）
- 「某公司做成了」的类比。（1555，纪律归全景扫描）
- 七种力量打分、五力主观分求和。（918、1129）
- 到了 E5 也不能证明未来没有竞争或稳定的多年客户价值；到了 E6 也不能证明永久护城河、无限市场或必然达到目标。守得住的结论只能写成带条件的判断。（215–216）

## 指针：归别处的内容

- 已投入成本、停止条件：首次写下归 V1，逐轮的继续或停止裁决归闭环检查（W16），本页不收。
- 评审六问：前五问归闭环检查；第六问由闭环检查提问，尺子取 V1，判定在本页（2004）。
- 每客户成本清单：产出归 V7，本页只用结论。每客户贡献口径与收费单位归 V5。
- 续费续用：同一客户还要不要归 V5；第二次交付特殊工作是否减少归 V7；本页只把续费率当规模假设。
- 通用能力替代：列进替代清单归 V3；本页只做压力测试。
- 取胜假说、不做清单、多个候选方向争资源：归 V2；本页复核后按回边回 V2。
- 同一笔交易里付钱、使用结果、服务成本三样同时出现（G7 199；B11 769）：归闭环检查。
- 行动一致性（B04 446）、假设总账（W10）、预先写判定线、证据梯级防越级：归闭环检查；倒推表里的假设登记进总账。
- 不用评分平均掉致命缺口（218）、案例类比纪律（1555、1148）：归全景扫描。
- 有旧业务时的组织安排（B15、T04、B03）、付钱与使用分离时的角色链：各归跨层条件包；角色名单归 V6。

## 这一层尺子外的问题

九类问题照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：本层能查的先查，做法前标明是一般经验，写出前提。

- 竞争动态：对手降价、抄袭之后怎么应对、下一步怎么出招，只给经验；本页只做一次静态压力测试。
- 时机：早了还是晚了、窗口还有多久，只给经验。
- 获客与增长引擎怎么建：本页只查声称的规模里每个数有没有证据，增长回路怎么设计只给经验（报告自认增长引擎未展开，661）。
- 团队与当事人：扩张需要的人和能力配不配，只给经验。
- 融资与现金：融资节奏、账期与现金流推演只给经验；本页只要求反向情景里把现金单列（报告只点名不演算，1603–1604）。
- 合规：本页只问数据与渠道权利在谁手里，是否合法由专业人员核验（218）。
- 面向个人消费者的产品：可达人群怎么数、留存与口碑怎么算进规模，只给经验。
- 实体与服务类生意：产能、供应、库存对规模的约束，只给经验。
- 验证期之后的经营：提价、第二产品、大客户依赖、并购退出，只给经验。
- 报告无题源：「够大」的门槛是多少；优势能持续多久怎么估（1558 点了名，全文没有方法）。
