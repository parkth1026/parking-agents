# V5 谁付钱：购买与收费

**这一层只回答**：谁掏钱，这笔钱从他现在哪项开支或哪种凑合里换出来，按什么单位收，价格证据到哪一步。

**多个角色时**：掏钱的人和能否决这笔支出的人不是同一个时，两个都问。有几档收入、每档付钱人不同，逐档问。本层状态取最弱的一个，证据级别分开标，不取平均（206、218；逐个问与取最弱为推导）。角色名单取自 V6，本页不重画，只问谁批谁付。

## 必问句

1. **事后版**：这笔钱最后是谁掏的？有没有另一个人能否决这笔支出？你和掏钱的人本人谈过钱吗？
   - **事前版**：打算让谁掏钱？有没有另一个人能否决？凭什么认为是他：接触过他本人，还是只接触过用的人？
   - 答不上来说明：只答得出「客户」「用户」这类集合名词，说明还没找到掏钱的人。只说得出用的人多喜欢，是把使用者喜欢当成了掏钱的人同意。
   - 来源：B09 709；W08 1758；4.1 步骤 12（1003，含否决角色）；4.4 表 1057；通用问法为推导
2. **事后版**：这笔钱是从他原来哪项开支或哪种凑合里换出来的？你的价是照那笔开支和他要的结果推的，还是照我方成本加的？
   - **事前版**：他现在为这件事花着什么钱、付着什么凑合的代价（取 V3 的替代清单）？哪一项他自己能停掉、把钱挪给你？打算定的价相对那一项是省、平还是多花？
   - 答不上来说明：换不出来有两种可能：他现在没为这件事花钱，代价也折不成钱，等于要他新掏一笔；或代价是真的，但落在不掏钱的人身上。答「成本加毛利」对应 B09 699；只按某一项成本定价对应 G4 停止信号 193 的通用化（推导）。替代开支说不出数，回 V3。
   - 来源：B09 709、699、711；W08 1761；G4 193；4.3 价格走廊 1041、目标成本 1042；通用句为推导
3. **事后版**：按什么单位收、多久收一次？付钱的人算得清下一期要付多少吗，对得上账吗？用得多的时候，他是觉得值还是开始限制使用？
   - **事前版**：打算按什么单位收、多久收一次？比过不止一种单位吗？按这个单位，他用得越多是越觉得值，还是越想少用？
   - 答不上来说明：公平、可预测、可审计、毛利四项，任一项说不清，说明单位是随手选的，没模拟过它怎样改变双方的风险分配。
   - 来源：B09 702、712；W08 1763；W12 1837；C15 1322–1324；B02 301；口语问法为推导
4. **事后版**：最近一次让掏钱的人看到写明的范围和价格是什么时候？他接下来做了什么？没推进的，原因是什么？
   - **事前版**：打算什么时候、用什么方式让掏钱的人第一次看到写明的范围和价格？在那之前，你凭什么认为他会付？
   - 答不上来说明：从没让他看到过价，价格证据停在内部判断或口头。看到了但说不出他的后续行动，还没到「有成本的推进」。说不出一条拒绝原因，多半只留了支持方向的记录（推导）。事前版的依据若是口头表态或别人的收入，仍是 E0。
   - 来源：W08 1764；B09 711；B08 589–590；E3 213；B19 650；张力表 1544
5. **事后版**：已经收到的钱，是在什么特殊条件下收到的（试验性的钱、熟人、折扣、额外人工）？条件到期后，同一个客户还要不要，他做了什么？
   - **事前版**：第一笔钱打算在什么条件下收（免费、特价、熟人）？条件到期后，凭什么认为同一个客户会按正式条件继续要？
   - 答不上来说明：说不出钱的性质、折扣何时到期、转正条件，是付费幻觉的典型形态（1557）。「一笔钱进账」和「这个客户会按这个价继续买」是两种事实。
   - 来源：W08 1765–1766；付费幻觉 1557；E3、E4「尚不能证明」213–214；G7 停止信号 199；B17 797；B12 825（钱的便利一半）

## 站住了长什么样

- 掏钱的人已写成具体的人或角色，并且和他本人谈过钱。（B09 709；W08 1758）
- 能指出这笔钱替代他现在哪一项开支或哪一种凑合，这一项他自己能停掉或挪动，且说得出价格相对它是省、平还是多花。（B09 709；W08 1761；「能挪动」与「省平多」为推导）
- 收费单位和周期已定，公平、可预测、可审计、毛利四项各有一句模拟结论。（B09 712；W08 1763；W12 1837）
- 至少一个掏钱的人在看到写明的范围和价格后付出了成本：投入时间、资源、样本，推进了购买，或付了钱。（G4 继续理由 193；E3 213；B08 589）
- 已收到的每笔钱都写明了性质和特殊条件；同一个客户到期后还要不要，有实际行为或写明的条件。（W08 1765–1766；B17 797；E4 214）

## 没站住的信号

- 把「应该会买」「肯定会买」计入了订单或收入。（G4 停止信号 193；B19 650；B09 711）
- 价格只由我方某一项成本决定，没对照掏钱的人的替代开支和他要的结果。（G4 停止信号 193，原话是模型调用成本，通用化为推导；B09 699）
- 只有用的人的好评，从没让掏钱的人看到过价。（B09 709；B19 650）
- 把试点费或首单当成正式购买的证明，说不出钱的性质；或用免费、特价试点推正式价格。（E3「尚不能证明」213；付费幻觉 1557；G7 停止信号 199；十步推演 1578）
- 掏钱的人明确表示不愿为这项收益付钱。（退出条件 1589）

## 上下游

- **依赖上游**：V3：替代清单和凑合的代价是本层「换出来」的原料，E1 只说明问题发生，不说明有足够付费意愿（211）。V2：选定的客户、任务和比较对象决定向谁开价、范围写什么（G3 191）。V4：先有范围内用了真变好的东西，才有价可开（E2 在 E3 前，212–213，推导）。V1：「必须贡献多少」是价格倒推的终点，「赔得起多少」决定付费验证投多少（G0 185；B10 737）。
- **回边与并列**：V7 回 V5（成本回填定价）：每客户成本清单产出后，回本页核对价格、单位、范围是否还成立；G4「全成本有记录」（193）靠这条边满足，本页不自己列成本。V5 与 V6 并列：可并行取证（180）；谈成了却卡在执行的人那里，去 V6 查，不算上溯。
- **本层没站住时，下游这些问题不直接答**：
  - V6「获客花多少划算、渠道分多少」：价格和单位没定，算不出每一环的收益。
  - V7「怎么复制到下一个客户」：复制检验的是同样范围、同样价格换一个客户还成立（B12 828），范围和价格没定就没有可复制的对象。
  - V8「够不够大、打平要多少客户」：客单价来自本层；没有价格证据，测算落在 G9 停止信号（203）。扩张判定（B14 388）归 V8，本页只留指针。
  - 「怎么提高续费率」：第一次购买的性质没分清之前，谈续费没有基线（B17 797；推导）。

## 什么算证据

**算**

- E3（213）：掏钱的人看到写明的范围和价格后，投入了时间、资源、样本或推进了购买。（B09 711；B08 590）
- E4（214）：一个客户在知情条件下付钱并得到真实交付；知情指成熟度、输入限制、人员参与、价格、服务边界、退出安排都已说明。（1587）
- 同一个客户到期后实际继续付钱或继续用（E5「持续使用/续约」一半，215）；新购买实际替代了一笔旧开支（B09 711）。把后者归到 E5 为推导；E5「独立客户复制」一半归 V7。
- 分开标级：「谁掏钱」可能已到 E4，「按这个单位收」仍在 E0。（206）
- 还没人看到过价时，本层统一记 E0，如实标，不算答错。（210；推导）

**不算**

- 内部判断、类比、别人的收入或别人的价（E0 210；案例幻觉 1555）。
- E1 近期经历只说明问题发生，不证明足够付费意愿（211）；E2 原型测试不证明正式采购（212）。
- 口头付费意愿、「肯定会买」（B09 711；B19 650；G4 193）。
- 等待名单、点击率、满意表达；一次签单与它们也不是同一种证据（B08 599）。定价研究不能替代真实销售（B09 718）。
- 隐瞒试点性质、用隐藏人工冒充全自动、隐藏收费条件换来的付费（1587；B08 592）。
- 降级：试点的钱不等于正式的钱，承诺不等于付款（213）；一次付费不证明可复制、续费与规模（214）；免费试点不能推正式价格（1578；199）。
- 把客户的同一笔损失同时计入多个收益项得出的「客户能省多少」（1604）。

## 指针：归别处的内容

- 替代清单与凑合代价的事实、「没有竞品」幻觉：归 V3。
- 比较对象、不做哪类客户和任务：归 V2。
- 每客户成本清单（实施、获客、支持、失败重做）的产出、首单交付上的便利、第二次交付特殊工作是否减少：归 V7。
- 角色名单、各环有没有动力、入口在谁手里：归 V6。
- 续费率作为规模假设、目标贡献对应客户数、逆向损益、市场幻觉、扩张判定（B14 388）：归 V8。
- 必须贡献多少、赔得起多少、目标当诊断：归 V1。
- 技术幻觉主归 V3；「演示不等于可靠」归 V4。
- 同一笔交易里付钱、使用结果、服务成本三样同时出现（G7 199；B11 769）：归闭环检查。
- 行动一致性（B04 446）、必须为真的命题清单与假设总账（W10）、预先写判定线、证据梯级防越级：归闭环检查。
- 逐轮的继续或停止裁决（W16）、评审六问（2004）：归强制动作。
- 案例类比纪律（1555、1148）、不取平均（218）：归全景扫描。
- 诚实底线（1587、592）与专业核验（218 末句）：归 skill 总则。
- 有旧业务时的组织安排、付钱与使用分离的角色链：各归一个跨层条件包。

## 这一层尺子外的问题

九类问题照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：本层能查的先查，做法前标明是一般经验，写出前提。

- 面向个人消费者的产品：自助定价、订阅、应用内购买怎么定价，本层只给经验；报告只有 C23 一张卡（1414–1424），一两句机制。
- 具体定多少钱、版本怎么分层：报告没有方法（693、55、710），本层只查价格的锚和证据，不给价位。
- 竞争动态：对手降价、价格战要不要跟，本层只给经验。
- 时机：什么时候开始收费、什么时候提价的窗口判断，本层只给经验。
- 获客与增长引擎怎么建：获客成本只作为 V7 清单里的一项被引用，怎么获客只给经验。
- 团队与当事人：谁去谈价、销售怎么招怎么考核，本层只给经验。
- 融资与现金：账期、回款节奏、现金周转不演算，只给经验；报告只点名（1603–1604；W12 1847）。
- 合规：合同条款、税务、结算的法律财务要求，由专业人员核验（218）。
- 实体与服务类生意：库存、产能、按件成本对定价的影响，本层只给经验。
- 验证期之后的经营：提价、大客户依赖、续费率运营，本层只给经验。

## 薄在哪

- 价位怎么定没有方法：只有「价格区间」字段（1763）、「从可接受价格反推」一句（1042）、价格走廊一句（1041）；B09 九条规则等未展开（693、55）。
- 收费单位四检只有名称和三个例子（712），每项怎么判没写。
- W08 八个字段只有标签；本层判定句全来自 G4 一行（193）。
- 怎么识别钱是试验性的还是正式的，只有警告（213、1557），没有识别方法；「有边界的付费验证」边界怎么划没写（193）。
- 没有数值门槛：多少次报价响应算够，报告不给。
- 通用句「从哪项开支或凑合里换出来」、全部事前版问法、事前迹象、新增幻觉都是推导；报告原文写在企业经济买方语境（709）。
- 个人消费者付费、订阅、应用内购买基本空白，只有 C23（1414–1424）。
- 案例没有结果证据：C13–C15 只有一两句机制，不能证明某种收费方式有效。
- 流失、账期、现金流没有演算，三个反向情景只点名（1603–1604）。
- 报告的动作栏是报告作者的应用推导（705、790、849），不是原书作者的主张。
