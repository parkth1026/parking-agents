# fix-codex-project

恢复本机仍保存的项目组织关系到当前账号，保留原件和目标账号新增记录。以原项目分组重新可用为完成标准。

## 只读定位

解析实际 `CODEX_HOME`；未设置时用当前用户的 `.codex`。检查环境覆盖、目录联接、实际桌面端版本及进程，避免读取一个目录却修改另一个目录。

```powershell
python '<skill-dir>\scripts\projects.py' inspect --home '<codex-home>'
```

脚本输出匿名账号前缀、项目数、工作目录数、会话关联数、路径存在情况及 SQLite 摘要，不打印会话正文、完整账号 ID 或认证信息。

区分项目文件夹、项目元数据、会话正文、会话归属四种证据。`inactive` 是状态 JSON 的字段，不是磁盘目录。创建者字段存在不代表会话列表按账号过滤。需要解释结构或版本行为时读 [references/storage.md](references/storage.md)，并核对已安装版本或官方说明。

## 生成计划

只问原因时保持只读。用户已要求备份恢复时，直接在授权范围完成，不重复请求确认。

```powershell
python '<skill-dir>\scripts\projects.py' plan --home '<codex-home>' --source '<完整来源标识>' --out '<run-dir>\plan.json'
```

来源唯一且确有项目记录时可省略 `--source`。多个来源时比较项目名称与路径再选择；不要仅按记录最多判断旧账号。脚本锁定当前身份、来源内容指纹和恢复字段。目标账号不明确、来源歧义或结构异常时先解决问题再写入。

创建独立运行目录。备份含本地私人数据，保持在本机；技能分发包只含通用脚本和文档。完成标准：计划可读、来源和目标明确、范围符合用户授权。

## 关闭应用后恢复

桌面端缓存状态，运行中改文件会被内存写回覆盖。先说明需要短暂重启，通过环境允许的进程管理方式关闭已核实的桌面 GUI，等待退出，保留后台服务、其他任务和会话正文。优先正常退出；结束进程前检查未保存输入与其他受影响活动，核对准确 PID、启动时间与可执行文件。若当前会话会随应用退出，先准备独立后台辅助程序、日志与恢复入口再关闭。重启使用实际发现的可执行文件/包标识。

脚本不关闭应用、不登录、不处理凭据、不自行重启。Windows 上检测到 `ChatGPT.exe` 或 `Codex.exe` 桌面进程时拒绝写入；检测失败也拒绝。其他平台需现场确认桌面进程退出。

```powershell
python '<skill-dir>\scripts\projects.py' apply --home '<codex-home>' --plan '<run-dir>\plan.json' --backup-dir '<run-dir>\backup'
```

脚本重新核对身份与来源，创建独立 JSON 和 SQLite 一致性备份，然后只合并白名单字段。对象递归合并、列表保留目标顺序补缺项；冲突保留目标值。保留整个 `inactive`、身份与其他配置。迁移映射只导入当前 Home 的本地主机记录。写入采用原子替换，两文件任一写入或校验失败时恢复已改文件并报告失败。

执行期间以 Home 下临时 `.fix-codex-project.lock` 阻止本工具并发恢复，退出时释放。残留锁须核对记录的 PID 与运行状态，不直接删除。锁不能约束其他工具；恢复窗口应保持其他写入者静止，指纹变化就停止，不循环覆盖。两文件独立原子替换不等于跨文件事务，断电或持续磁盘故障后应按独立备份重新检查，不承诺无条件自动恢复。

仅修改 `.codex-global-state.json` 及其 `.bak`；SQLite 和会话正文只读。备份目录须新建且位于技能扫描根之外。来源不存在时不能凭空重建；数据库 `project_id` 为空也不能证明会话无归属，旧关联可能在 JSON。

## 重启与验收

重启应用，重新 `inspect`，确认项目及归属仍处于当前身份。比较恢复凭据的计数和冲突数。检查真实界面至少一个原项目及其已知会话；工具禁止操作目标应用时让用户检查界面，并保留 `NOT_RUN`。

分层报告 `PASS`、`FAIL` 或 `NOT_RUN`：备份、文件合并、重启后持久化、界面分组、原会话续用。明确两个 JSON 的绝对路径、备份位置及数据库未被脚本修改。应用启动后的数据库自行更新若未审计则单独说明。

这是一次恢复当前账号，不改变按账号选择状态的逻辑。不承诺再次切换自动共享；永久同步需要另行设计并验证双向合并与 A → B → A。

## 撤销本次恢复

先退出应用，再使用恢复凭据所在目录：

```powershell
python '<skill-dir>\scripts\projects.py' rollback --home '<codex-home>' --backup-dir '<run-dir>\backup'
```

只回滚本次改动的 JSON，不覆盖 SQLite。当前文件须匹配写后指纹；若重启或新增内容已改变文件，拒绝整份覆盖，分析差异并保留新记录后再撤销。回滚中途失败时补偿恢复到回滚前；持续磁盘错误导致补偿失败时保留备份并报告实际状态。

## 维护

修改后运行 `node '<skill-dir>\run-tests.mjs'`。测试使用临时夹具，不再次修改真实账号。设计与验收条件见 [references/design.md](references/design.md)。
