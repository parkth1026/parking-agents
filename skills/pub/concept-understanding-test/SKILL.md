# concept-understanding-test：概念理解测试

测一个 AI 模型对某个概念是原生理解还是靠检索补齐。同一考题跑两遍：第一遍闭卷（禁搜索）出答案，第二遍带搜索出答案；对比两份答案，输出**理解程度百分比**。闭卷答案与带搜索答案的重合度越高，原生理解越完整；闭卷答错而被搜索纠正的部分，就是靠检索才能补齐的部分。

## 考题形态（原始问法，不加结构）

每个概念出两道自然考题：

1. **概念题**：「X 是什么？」
2. **应用题**：「对<某个具体对象>使用 X，你会怎么做？」对象在出题时给定（一个文件、一个方案、一组数据）。

题面不写任何评分维度提示（机制/边界/例子/答题格式）——提示了测的就是被引导的展开能力，不是原生理解。

## 双跑（两个 subagent 并行，两臂考题逐字相同）

- **臂 A 闭卷**：考题 + 工具禁令（不搜索、不抓网页、不读文件、不调用 Skill、不执行命令）。结果 tool_uses 必须为 0，否则作废重跑。
- **臂 B 带搜索**：同一考题 + 要求必须联网核实、引用权威来源、末尾附来源链接；与先验冲突的搜索结果必须采纳并修正答案。tool_uses 必须大于 0 且答案含来源，否则参照臂无效，重跑。
- 搜索通道降级顺序：内置 WebSearch → Exa → WebFetch 直抓权威页。全部耗尽时本次测量作废、择时重跑；不得拿无搜索的答案冒充臂 B。

## 对比与判分

以臂 B（经核实、带来源）为参照：

1. 从 B 的答案提取实质要点清单：定义、机制、前提条件、边界、关键事实、出处。逐条去重、编号。
2. 逐条对 A 的答案判：**一致**（A 覆盖且无冲突）/ **偏差**（A 覆盖但与 B 冲突）/ **缺失**（A 没有）。
3. A 独有主张若被 B 的来源反驳，追加为偏差项；B 未提及的 A 独有内容不扣分，作加分注记。
4. **理解程度 = 一致 ÷（一致 + 偏差 + 缺失）× 100%**。
5. 分级：≥90 深度理解；70–89 理解；40–69 条目式记忆；<40 不理解。
6. **子分诊断**：要点分「原理类 / 出处类」两列子百分比。原理类子分回答「懂不懂原理」；总分回答「与检索后的自己差多少」。
7. 报告：百分比 + 分级 + 三分类明细表 + 子分 + A 的校准注记（A 标不确定处 B 是否确有修正）+ B 的信源清单。

## 纪律

- 单次对比有抽样方差；重要判定换问法或换应用对象重跑，报一致率。
- B 的信源低质（全是博客、无权威页）时参照失真，报告注明；必要时主 agent 直接抓权威页抽查 B 的关键断言。
- 诱饵校验可选：已知「模型先验 ≠ 权威页」的冲突条目时，A 若给出权威页新说法而非先验说法，判闭卷被污染。
- 跨模型：考题是模型无关资产；测其他模型经对应通道发同一双臂，收回后按本节对比。

## 测试

技能自带回归测试。每次升级、改动后必跑：

    node run-tests.mjs
