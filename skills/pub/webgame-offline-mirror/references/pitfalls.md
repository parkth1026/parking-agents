# 实测坑清单（全部踩过，标注 通用 / 引擎特异）

## 提取类

**1.（通用）模板字面量配对位移**：用 `` /`([^`$\n]+)`/ `` 这类正则提取引用时，一旦源码里有 `${...}` 插值模板，反引号配对整体位移，后面的合法引用全被吞进错误的配对里。
解法：hash 锚定正则——文件名带构建哈希（`-Ab3xY9z2.ext`）时，用**同引号锚定**的模式 `(["'`])(…-[A-Za-z0-9_]{6,12}\.ext)\1` 直接按文件名特征抓，配对位移免疫。mirror.mjs 已内置。

**2.（通用）CSS 无引号 `url(...)`**：`url(./font.woff2) format("woff2")` 没有引号，引号正则漏抓，字体全丢。
解法：单独的 `url\(\s*(['"]?)([^'")]+)\1\s*\)` 提取器。mirror.mjs 已内置。

**3.（通用）资源 base 前缀与版本参数**：资源 URL 由 `base + path + '?v=' + build` 函数拼接，直接按字面量路径访问全 404。
解法：先从 bundle 找到 resolver 函数（在 `.png`/`.glb` 字面量附近），读出 base 前缀（常是 `/assets/` 一类的目录），本地服务对 `?v=` 透明（按 pathname 查文件）。

**4.（通用）UI 计数器语义要用实测校准**：进度型 UI（「x/79」）计数的可能是**家族/类别**而不是条目数。给存档字段灌满后看 UI 数字，对不上就找计数函数，别按字面猜。（实测：联盟槽位按进化家族计数，塞 79 个个体只显示 33。）

## 网络类

**5.（通用）fetch 无超时 = worker 全挂**：并发抓取器不设 AbortController 超时，一个慢连接挂死一个 worker，速率归零且无报错。
解法：每请求 30s 超时 + 指数退避重试 + 429/403 按 Retry-After 退避。mirror.mjs 已内置。

**6.（通用）CDN 比源站多一层目录**：字面量 `ui/icons/x.png` 的真实路径可能是 `/assets/ui/icons/x.png`。探测 404 时先怀疑前缀，再怀疑文件不存在。

**7.（通用）语言 chunk 懒加载**：多语言站点的语言包是独立懒加载 chunk（引用藏在动态 import 表里，且可能因反引号位移被提取器漏掉）。按语言列表枚举 chunk 名，或运行时录制让浏览器自己暴露。

## 后端类

**8.（通用）后端启动闸门**：客户端启动时先打一个状态接口（常见 `/status`、`/health`），不通就卡死在重试屏——镜像再完整也跑不起来。后端分析的第一件事：找到闸门接口，mock 它。
解法与完整流程见 backend-mock.md。

**9.（通用）客户端离线降级要读代码确认**：很多游戏自带离线模式（存档不保存、队列重试）。读客户端的请求封装（超时/重试/降级分支），决定 mock 要实现到什么程度——有时只需闸门接口，有时全链路。

## 浏览器自动化类

**10.（通用）`:visible` 不是合法 querySelector**：原生 DOM API 不认 Playwright 的 `:visible` 伪类。可见性判断要么用 Playwright locator（`button:visible`），要么用 `offsetWidth` 检查。

**11.（通用）UI 交互三连坑**：① 弹窗（赛季/公告/引导）拦截所有点击，Playwright 的 click 静默超时——.catch 吞掉后像什么都没发生，先关弹窗；② 同名按钮有多层含义（顶部「进入」是模式切换，表单里才是提交），按文本点击前确认上下文，实在不行在输入框按 Enter 提交；③ 无头浏览器语言随系统，按钮正则必须多语言。

## 引擎特异（详见 engine-playbooks.md）

**12.（Unity WebGL）**：入口 `.loader.js` → `.data` + `.wasm` + StreamingAssets；URL 由 loader 计算，闭包抓不全时优先运行时录制。
**13.（Godot 4 web）**：`index.pck` 单文件打包了几乎全部资源，抓到 pck 就抓到 90%；pck 内资源不需要单独镜像。
**14.（Phaser/PixiJS）**：图集 atlas JSON 引用 png 是相对路径且常无引号（JSON 键），抓完 atlas 后解析其 `image`/`meta.image` 字段。
