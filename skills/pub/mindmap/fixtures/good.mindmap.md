# WDP6 产品架构

## 价值闭环
- 进：多源数据经 AI 整理、人确认后入资产层
- 产：双 Agent 消费资产，生成业务应用与三维场景
- 用：交付部署，场景按 3D Tiles 装进交付态引擎
- 回：反馈与数据变化回流，应用与场景自动更新

## 五层架构
- L1 使用侧
  - 用户：业主 / 决策层
  - 交付态应用
    - 业务应用：面板 / 告警 / 报告 / 问答
    - 三维场景
      - 与业务应用联动：高亮 / 定位
      - 运行于交付态引擎，非静态网格
  - 消费 Agent <!-- markmap: fold -->
    - 定位：轻量调度，小模型即可
    - 意图路由：问数 / 问知识分流
    - 自然语言问答：答案附数据出处
    - 结构化记忆：用户偏好条目化
    - 反馈标记：不满意一键回传
- L2 生产侧
  - 用户：开发者 / FDE / 业务专家
  - 生产工作台 <!-- markmap: fold -->
    - 模板入口 + AI 引导，不强制线性流程
    - 账本确认 / 修正，含场景语义候选
    - 应用预览 → 人审阅确认
    - 行业知识库冷启动
  - 业务 Agent <!-- markmap: fold -->
    - 职责：数据 → 业务系统
    - 需求理解：听懂客户要什么
    - 骨架组装：挑预置模板 → 填资产 → 绑数据源
    - 知识问答生成：沿图谱检索，答案带依据
  - 场景 Agent
    - 职责：资料 → 三维场景
    - 空间资产理解：坐标 / 关系解析，1:1 还原
    - 语义候选确认 ✅已定
      - 候选附来源，歧义可拒绝
      - 与业务档案共享 稳定对象身份
    - 场景组织：资产置入底板，带业务语义标注
    - 建模工具箱 <!-- markmap: fold -->
      - PCG 生成管线
      - 3D Gaussian Splatting 重建 🧪探索（注：不进首发承诺）
      - 第三方建模工具
- L3 数据资产层
  - 原则：AI 整理 + 人确认，AI 不碰原始数据
  - 资产卡片：设备 / 空间 / 规则逐条建档
  - 主题域：原子资产按业务主题组装复用
  - 知识图谱：对象—关系—规则连网，分钟级增量
  - 口径仲裁：多源冲突指定基准源，冲突人定
- L4 数据接入层 <!-- markmap: fold -->
  - 业务文档：Word / PDF
  - 台账表格：Excel
  - 实时接口：IoT 传感器 / 数据库
  - 空间数据：BIM / CAD / GIS
  - 现场资料：图纸 / 照片 / 坐标
  - 客户本地知识库：需 FDE 配合接入
- L5 AI 底座
  - 原则：外部成熟方案，可替换，私有化部署
  - DeepSeek Harness：开源 Agent 运行时
  - 国产大模型：DeepSeek / GLM / Qwen

## 横切支撑
- 运行引擎
  - 形态：引擎双形态，生产编辑、交付渲染
  - 生产态
    - 编辑 / 预览 / 语义标注会话
    - 场景 Agent 经 CLI / API 调用原子能力
    - 沿用 UE ❓待定（注：判断，基于存量积累）
  - 交付态
    - 渲染 + 对象交互：高亮 / 定位 / 点选
    - 要求：轻量、可嵌入、可国产化
    - 引擎选型 ❓待定（注：T2 国产实测后定）
  - 解耦契约 ✅已定
    - 场景资产格式：3D Tiles
    - 两端技术分别演进、分别替换
    - 「UE 还是 Web」是两道独立选型
- 安全机制
  - 范围：贯穿接入 → 生产 → 使用
  - 工具规训：AI 只能调用批准的能力清单
  - 人审阅闸门：写入先预览，人确认才执行，全程留痕
  - 数据边界：敏感数据只走本地模型，日志可审计
