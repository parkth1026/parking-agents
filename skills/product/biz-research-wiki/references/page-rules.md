# 页面怎么写

写死的只有三样：证据写法、必答题、页面头尾。其余章节跟着主题 Prompt 走。

## 证据写法（所有页都一样）

- 一句只说一个事实。每个事实句末带来源链接与日期：`……（来源：[[来源页名]]，2025-03）`。
- 句末日期用原文的发布日。原文没有发布日的（官网栏目页等），用抓取日并写成 `抓取 2026-10`。
- 三种句子分开写，不混：
  - 事实：原文里有。
  - 推断：以「推断：」开头，后面写依据，依据用完整的 `[[来源页名]]` 链接。推断句可以比事实句长。
  - 查不到：写「查不到」，并写查过哪里。写到子项这一层：一道题里有答案的照写，缺的那一项单独写一行「查不到：……」。
- 来源强弱分五档，写在来源页里每个网址的那一行：
  1. 客户方或监管：付款方自己的公告、中标与成交公告、工商与监管登记。
  2. 独立媒体：记者自己采访或核实过的具名报道。
  3. 转述公告的媒体：照公司新闻稿或公司口述写的报道，以及有利益关系的第三方（投资方、房东、律所）。
  4. 厂商自述：官网、新闻稿、厂商案例、供稿软文。
  5. 数据站估算：没有说明方法的收入、人数估算，软件目录的转录。
- 页面里出现第 4、5 档的数字时，写明是谁说的：「官网写……」「数据站估算……」。
- 数字写原文的数和口径，不换算，不取整。几个来源的数互相对不上时并列写，不取舍，不取平均。

## 页面头尾（所有页都一样）

- 头部字段照引擎要求，另加：`type`（company / product / overview）、`topics`（本页属于哪些调研主题，可多个）、`as_of`（事实截至日期）。
- 正文第一段是「一段话结论」：不超过 5 句，读完就知道这个对象是什么、靠什么站住。每句照样带来源。
- 单页不超过 200 行。超了把最长的一节拆成新页并互链。
- 每页至少链到 2 张别的页：所属公司或产品、同主题的其他对象、主题综述页。

## 必答题

每道题一节，节标题用题目原文，方便以后跨页对比。答不出就写「查不到」，不得删掉这一节。

公司页：

1. 卖什么，卖给谁（付款方是谁）
2. 付款方为什么付钱
3. 怎么卖，怎么收费（渠道、计价方式、价格带）
4. 多大（客户数、收入、员工数，有哪个写哪个）
5. 靠什么站住（别人难拿走的是什么）
6. 近 3 年有日期的动作（融资、发布、改价、收购、转型、退出）

产品页：

1. 解决谁的什么问题
2. 交付的是什么（形态与核心功能）
3. 怎么收费，多少钱
4. 具名客户与案例
5. 替代品是什么，差在哪
6. 近期变化（改版、改价、下线）

## 自由节

必答题之后，按主题 Prompt 加节。例：主题关心出海，就加「海外布局」；主题关心技术路线，就加「技术方案」。同一次调研里各页用同一组自由节标题。自由节同样守证据写法。

## 来源页

一个站点一张来源页，不是一个网址一张。页名用 `<对象> 来源 <站点名>`，例：`蜂鸟视图 来源 官网`、`Mappedin 来源 BetaKit`。页内每个网址一小节：网址、发布日或抓取日、强弱档、对应的 raw 文件、从中用到的事实行。同一站点的多篇文章写在同一张来源页里。页面句末的来源链接指向来源页；要指到具体网址时在链接后写文章短名。

2026-10-07 首次调研的 67 张来源页是旧写法（一个网址一张、三档强弱），保留不改；以后更新这些对象时再并。

## 综述页的横向对照表

每张主题综述页有一节 `## 横向对照表`，放在一段话结论之后。本主题的每个对象一行，按公司页里已核实的内容填，不新增事实。它的用处是让「哪几家有……」这类跨对象的问题只读综述页就能答全。

固定五列，主题需要时可以在后面加列：

| 列 | 填什么 |
| --- | --- |
| 对象 | `[[页名]]` |
| 收费方式 | 卖断、订阅、RaaS、API 计费、项目制等；查不到写「查不到」 |
| 公开价格 | 有就写数和口径；只有厂商自述或数据站估算的要注明；没有写「无」 |
| 客户方或监管证明的付费客户 | 只认来源第 1 档。写客户名；只有厂商自己列的客户写「仅厂商自述」；没有写「无」 |
| 合同金额或收入 | 有就写数、口径、年份；没有写「查不到」 |

每格不超过 25 个字。详情留在对象页，表里不写来源链接。表后写一行：本表依据各对象页，截至日期与对象页的 `as_of` 相同。
