# V4 解法成立吗：做得出，用了真变好

**这一层只回答**：你的解法在不是自己挑的真实输入上做得出来吗；用的人用了之后，那件事真的比旧做法好了吗

**多个角色时**：用的人不止一种时（例如做配置的人、日常操作的人、最后拿结果的人），必问 2、3、5 对每个角色各问一遍。本层状态取最弱一环：任一角色没有净改善或自己用不成，本层记没站住，不拿别的角色的好结果平均掉（218；W06 1718；「取最弱」为推导）。角色名单取自 V6，本页不重画。只有一种使用角色时不适用。

## 必问句

1. **事后版**：拿一批不是你们自己挑的、用的人真会给的输入跑过吗？出了什么结果？哪些输入你们明说不接？
   - **事前版**：打算接哪些输入、明说不接哪些？手里有没有真实输入的样本（不是自己造的）？凭什么认为真实输入就长这样？
   - 答不上来说明：只举得出自己准备的样例，或答「都能支持」，说明手里只有演示。事前版拿不出真实输入样本，说明能力合同是照着能力写的，不是照着输入写的。
   - 来源：G6 197；E2 212；B06 500；W02 1640–1642；W13 1862–1863；B08 590。「不是自己挑的」是对「代表性」的改写，推导
2. **事后版**：最近一次出错或给不出结果时，用的人看到了什么？谁发现的，谁兜的底？
   - **事前版**：它总会在某些输入上出错。到时用的人会看到什么，打算由谁兜底？错了没被发现，后果落在谁身上？
   - 答不上来说明：答不上来，说明出错这条路没设计过。答「基本不出错」，通常等于没在真实输入上测过（推导）。
   - 来源：G6 197；W13 1864；B24 942、944；W02 1642–1643；1586（错误后果）。兜一次花多少归 V7
3. **事后版**：同一件事，让用的人用旧做法做一遍、用你的做一遍，再加一个更简单的办法，结果差在哪、差多少？是按他自己的做成标准量的吗？
   - **事前版**：打算拿什么和什么比、看哪个结果、基线从哪来？如果更简单的办法就够了，你打算怎么发现？
   - 答不上来说明：拿不出对照，「更好」只是自己的判断。比的是自己的指标（速度、精度、成本）而不是用的人的结果，说明能力到结果这一段没连上。没比过更简单的办法，就排除不了「简单办法已经解决」这条退出条件。
   - 来源：任务对照 1586；W11 1818–1819；W06 1721、1725；B16 533；1579；B25 972；B18 620；退出条件 1589
4. **事后版**：从拿到输入到用的人拿到结果，哪些步骤其实是你们的人在做（准备、修、复核、救场）？用的人知道吗？
   - **事前版**：哪些环节打算先由人顶着？对用的人怎么说？人撤掉以后结果还成立，凭什么这么认为？
   - 答不上来说明：列不出，说明「做得出」里机器和人分不开，技术可行其实没证。有用的人不知情的人工，「已自动」的说法不成立。
   - 来源：W02 1643；B08 592；知情商业实验 1587；W13 1864；B20 678。人工的成本归 V7
5. **事后版**：你们的人不在场时，用的人自己从头做完过吗？开始前要他备好什么，中途在哪卡住、在哪求助？
   - **事前版**：打算让谁、在什么条件下自己走一遍？他要先备好什么，凭什么认为他备得出？
   - 答不上来说明：只有己方操作的记录，证的是技术，不是可用。准备这一步没人量过，就是在默认输入总是齐全。
   - 来源：B24 931、943；G6 197（准备成本与端到端负担）；1586（完成时间、帮助请求）；B08 590；B13 357

## 站住了长什么样

- 写得出接什么输入、不接什么输入，并在不是自己挑的真实输入上跑过，结果有记录（G6 197；W13 1862–1863；B06 500；E2 212）
- 出错或给不出结果时，用的人看得到提示，有写明的兜底人和处理办法，且有一条真实发生过的处理记录（G6 197；W13 1864；B24 944；「真实发生过一条」为推导）
- 有一次同任务对照：旧做法、一个更简单的办法、本解法，按用的人自己的做成标准量，差在哪、差多少有记录，基线先于结果写下（1586；W11 1818–1819；W06 1721）
- 从输入到结果，每一步标明是机器做还是人做；有人做的部分，用的人知情（W02 1643；B08 592；1587）
- 用的人在我方不代操作的情况下自己做完过，事先备了什么、在哪求助有记录（B24 943；G6 197；1586）

## 没站住的信号

- 只有演示或自己挑的样例，没有代表性输入测试（G6 停止信号 197）
- 答「都能支持」，写不出不接的输入；或默认输入总是齐全、合格（B06 500；W13 1863；G6 停止信号 197）
- 更简单的办法已经把事办了，或用的人没有净改善（退出条件 1589；由「简单信息卡」「消费者」通用化，推导）
- 把内部跑通当成用的人有效；「更好」量的是自己的指标，不是用的人的结果（B20 678；B24 943；B18 620；后半句推导）
- 有不告知的人工在顶着，对外称全自动（B08 592；1587）

## 上下游

- **依赖上游**：依赖 V3 的任务、旧做法和做成标准：对照的对象和尺子都从 V3 取，V3 没站住时本层的「变好」没有基线（G6「符合任务边界」197；1586）。依赖 V2 初选出的那一个任务和那一档解法；选哪一档归 V2，本层只测（B25 972；1579）。
- **回边与并列**：本层不在三条已认回边上。相关两处：V3 回 V2 定取舍要用的「可测差异」，实测出自本层的对照（推导）；V7 回 V5 回填成本里的出错重做、人工复核两行，事实起点在本层，清单产出归 V7。致命缺口命中（简单办法已解决、没有净改善；报告称退出条件，1589）时，去向是回 V2 重新定位或缩小范围。这属于裁决的去向，不是回边；回边只有已认的三条。
- **本层没站住时，下游这些问题不直接答**：
  - V5：按什么范围报价、值多少钱不该直接答。输入边界没定就没有可报价的范围，改善没量过价格就没有结果可对应（E2 在 E3 之前 212–213；推导）。
  - V6：使用率低怎么培训、怎么运营不该直接答。先分清是不愿用还是用不成（B24 944）。
  - V7：怎么标准化、每客户成本多少不该直接答。没有输入边界和人工环节清单，标准范围和成本清单都列不出（W13 1862–1864；推导）。
  - V8：「靠更可靠守住」，以及任何以全自动、低成本为前提的规模推算，不该直接答（B23 909；G9 停止信号 203）。
  - 任何层：「技术已跑通」「效果已验证」不该当作前提往下推；没测过时下游结论一律写成待验证（158；205）。

## 什么算证据

**算**

- E2：真实任务与代表性原型测试，证明在规定样本和边界内可用或有初步价值（212）。G6 对 E2 的对应为推导。
- 代表性输入上的盲测记录，证可靠（B08 590；G6 197）。
- 同任务对照记录：旧做法、简单办法、本解法，看判断正确性、完成时间、求助、错误后果（1586；W11 1818）。
- 用的人自己在现场完成任务的记录，证可用（B24 943；B08 590）。
- 真实发生过的出错与处理记录（G6 197；W13 1864）。
- 知情的人工代办可以证价值，不证技术可行（B08 592；B20 678；后半句推导）。
- 还没做出来或没测过时：能力合同、不接清单、对照方案写下来，只算「要测什么定了」，本层记 E0（210；推导）。

**不算**

- 内部测试、内部自动跑通：只证部分技术（B24 943；B20 678；E0 210）。
- 演示效果、口头满意、审美投票（G6 停止信号 197；B08 599；B16 533）。
- 自己挑的样例上的好结果（197「代表性」的反面，推导）。
- 登录量、等待名单、访问和使用次数（C25 1444；B08 599；1580）。
- 别家公开的数字、开源实现、「这条路线别人跑通了」：网络类比，只到 E0（210；1555）。
- 自己的能力指标变好，但没连到用的人的结果（B18 620；W06 1725；推导）。
- E2 的上限：不证明正式购买、长期可靠、规模经济（212）。
- 样本数和级别名称本身：代表性、测量质量和情境更重要（206）。

| 付钱的人和用的人不是同一个时（跨层条件包，本页只留一句） | 用的人的任务结果单独量，不拿付钱方的指标改善（如转化、销量）当用的人受益。 | 张力表 1550；1569；W06 1718；B18 619 |
| 方向从一项已有技术或能力出发时（含三维等复杂表现形式） | 复杂形式要和更简单的形式在同一任务上对照，带来额外可测结果才上；不因团队擅长就预先定下形式。 | B16 533；1579；C26 1456；D02 1526–1528；C14 1312 |
| 出错会伤及真实资产、隐私或导致重大错误决策时 | 实验可以缩小范围，安全、授权、可追溯的底线不缩；不隐瞒成熟度和误差；这类投入用更严的关卡；法律和安全要求交专业人员核验。 | 张力表 1547；B20 686；T06 1139；MVP 术语 2018；218 |
| 先用人工代办来验证价值时 | 可以证价值，不证技术可行；对用的人明说有人参与；人撤掉后的表现要另测。人工的成本去向归 V7。 | B08 592；1587；B20 678；「人撤掉后另测」为推导 |
| 结果靠多个组件或第三方能力拼起来、接口还不成熟时 | 需要更强的整合与端到端验证，不能假设拼标准件就保证结果；接口已够用时不必全部自己做。 | B14 378、386；[[K18-RPV与整合模块化]] |
| 产品是软件、在对方组织里多人使用时 | 权限、日志、回滚与导出算产品的一部分，测的时候一起测。 | W13 1865；B24 944 |
| 用的人数量多、没法逐个看时 | 按同来源、同版本、同任务、同时间窗分批比较，防止总体数字盖住结果退化。 | B20 679 |
| 有旧业务、新产品要摆脱旧的逐单重做时（跨层条件包，本页只留一句） | 新解法要在共享的输入合同和共享验收上测；只是做得更快不算摆脱原约束。 | 十步推演 1573 |

## 指针：归别处的内容

- 每客户交付成本清单、出错兜一次花多少、人工环节的成本：归 V7，再经回边回填 V5。
- 首单在交付上得到的便利（数据、容错、人手）：归 V7。
- 技术幻觉主体「跑通了所以有人要」：归 V3；「技术当理由」归 V1。
- 任务、旧做法、做成标准、「不买你时用什么」的事实：归 V3，本页只取来当基线。
- 通用能力替代：V3 列进替代清单，V8 做压力测试；清单里有时，本页把它当一档对照（推导）。
- 选哪一档解法（不用技术改流程、简单数字化、复杂技术）、不做哪类客户和任务：归 V2。
- 愿不愿意用、谁多干活、角色名单：归 V6。
- 同一客户还要不要归 V5；第二次交付特殊工作是否减少归 V7。
- 同一笔交易里付钱、使用结果、服务成本三样同时出现（G7 199）：归闭环检查，本页只交「使用结果」一项。
- 预先写判定线（B08 591；W11 1815）、假设总账（W10，本层产出技术、可用、价值三类命题 1798）：归闭环检查。
- 证据梯级防越级：归闭环检查；本页只守 E2 的上限。
- 「结论写已跑通、正文写未实测」这类对不上：归闭环检查。
- 「别家做成了所以我做得出」：归案例类比纪律（全景扫描）。
- 不隐瞒成熟度、不用隐藏人工冒充全自动的诚实底线（592、1587、1547）：归 skill 总则，本页只查有没有不知情的人工。

## 这一层尺子外的问题

九类问题照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：本层能查的先查，做法前标明是一般经验，写出前提。

- 合规：输入和数据能否合法取得与使用、出错造成损害的责任归谁，本层不判，交专业人员核验（218）。
- 面向个人消费者的产品：体验、习惯、情感类的「变好」怎么量，报告无题源，只给经验。
- 实体与服务类生意：质量一致性、良率、供应与产能，报告无题源，只给经验；本页只按「输入到结果」的形态问。
- 验证期之后的经营：长期可靠、服务水平、容量、故障响应，E2 明说不证明长期可靠（212），报告无题源，只给经验。
- 团队与当事人：这支团队有没有能力把它做出来，只给经验；本页只看做出来的东西在真实输入上的表现。
- 时机：现在做不到的技术将来会不会成熟，只给经验。
- 竞争动态：对手的解法做到什么水平、怎么应对，只给经验；本页只和用的人现有的做法比。
- 报告无题源：多少份输入算有代表性、改善多少算够，没有数值线，本页不设（1586）。

## 薄在哪

- 没有任何数量判定：样本多少、改善多少算够，报告明说不虚构（1586；206）。
- 「代表性输入」怎么挑，报告没有方法；「不是自己挑的」是推导出的替代问法。
- 「衡量结果与最小有意义改善」「产品能力如何连接到任务结果」只有字段名（1721、1725），B18 只给一个例句（620）。
- 任务对照只出现在报告自编的教学场景里（1563、1586），没有一张到机制级的真实案例。
- 可用性（会不会用）只有 B24 两句（931、943）；礼宾测试、发现测试等方法报告自认未展开（925）。
- W13 只有字段标签，没有通过标准（1862–1865）；判定句只在 G6 一格，要两处合读。
- B08 的 44 种实验、B20 的创新会计都自认缺（574、661），怎么设计一次对照要回原书。
- 长期可靠、出错率随量变化，报告没有内容。
- G6 对 E2 的对应、全部事前版问法、症状迹象、三个幻觉名称都是推导。
- 六种立项幻觉里没有专属本层的一条；技术幻觉（1553）原句讲的是缺任务、购买和重复交付证据，不是可靠性。
- 语境写死在软件与模型输出：「输入」「出错提示」对实体和服务类产品要改写，报告没给改法。
