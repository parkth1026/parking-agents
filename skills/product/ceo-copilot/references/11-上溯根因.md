# 上溯根因

> 三条强制动作的第二条，排在全景扫描之后、闭环检查之前。治的是「顺着语境说、说不到上层根因」。括号里的数字是报告纯文本行号；标「推导」的不是报告原话。板、层状态、根因、来源三色、裁决等词按共享词表用，本页不另定义。

**为什么要有这一步**：一环短板会让别处的改善无效，局部很强不等于整门生意成立（B04 438）。用户通常问在下游（怎么定价、怎么标准化、怎么放量），毛病常在上游。不先上溯，回答只会在提问那一层里打转（推导）。

**取**：第 0 格的登记（板、处境、证据到哪一步）；全景表（十一行：V2、V6、V8 各两格，其余每层一格）。

**交**：「真正卡住的地方」和「我怎么看」里的传导；「我还需要你回答」里第 0 格和 V1 的未知项；直答和「该怎么做」里带的条件句。节名和写法见产出模板页。

**本页来源**：步骤、合并规则、回边规则、终点动作、索引的合并都是推导。报告只给三个锚点：链条视角（438）；证据允许并行、回退和循环，现金和不可逆承诺不能绕过（178–180）；致命缺口不被平均掉（218）。

## 上下游顺序

```
第 0 格 → V1 → V2 → V3 → V4 → V5 ∥ V6 → V7 → V8（够不够大；守不守得住）
回边：V3 回 V2；V7 回 V5；V8 守不守得住回 V2
```

- 「往上」指沿这条线向左。V5 与 V6 并列，互不算上游。
- 回边的意思：起点那一层产出的事实，要交回终点那一层，终点才能定稿。各条回边交回什么，见 02、05、07、08 页的「回边与并列」。

## 步骤

### 1. 把用户的提问定位到一层

- 拿用户原话去对「症状总索引」（11a 页）。对上的那一行，括号里写着问在哪层。
- 对不上：看扫描卡八层的「只回答」，哪一层那句话盖住了这个问题，就定在哪一层，标「定位为推导」。
- 板是「无待拍决定」，或用户要的是全面诊断：提问层记「全图」，第 2 步从 V8 读起。
- 用户自带归因时（「是不是定价高了」「是不是话术不行」）：把这个归因记成一条待查的假设，写明它落在哪一层，照常往上查。它不是已定的前提。（推导）
- 问题落在九类尺子外：索引对应行写着「尺子外：先回查某层」，先照那一行回查，再按产出模板页「不在诊断尺子里的问题：照答，标明是经验」给做法。
- 一句提问含两个子问时，各自定位、分别上溯，各记一句「问在 Vx」。根因相同就合并写；不同就取更上游的一个，另一个列为下游表现。（推导）

完成条件：每个子问都写得出一句「问在 Vx」，后面跟着用户原话。

### 2. 从提问层往上读全景表

- 从提问层自己读起，逐层往上读状态，读到 V1，再看第 0 格四件事有没有未知。V2、V6 各读两格。这一步只读状态，不重做扫描。
- 提问层是 V5 或 V6 时，把并列的另一层一起读。
- 提问落在 V8 时分格上溯：问够不够大，只往 V1、V5、V7 查；问守不守得住，只往 V2、V3 查，收益归属再看 V6（照 08 页「依赖上游」）；症状总索引对这句提问另列了候选层的，照索引核迹象。不在这条路径上的没站住层不参与定根因，列为独立缺口。（推导）
- 索引那一行列了候选层的，对每个候选核一条区分迹象。第 0 格登记那件事发生过，核事后迹象；没发生过，核事前迹象；标「通」的两版都核。每个候选记一句「命中」「没命中」或「待问」，附依据：材料行号或用户原话。
- 当事人不在场时：材料里有对应或相反的内容，记命中或没命中并带行号。迹象写成「问某某答不出」的，当事人不在场、材料里没有时，记未知，不算命中：候选栏写「待问」，这一层状态照全景表，问句进缺口清单，按产出模板页「末尾提问规则」取进「我还需要你回答」。（推导）
- 迹象命中，而全景表里那一层写的是站住或部分站住：按层页「症状到根因」表该行「本层哪件事没站住」把这一层改记没站住，依据写迹象加材料行号或用户原话，改全景表。（推导）
- 索引不代替全景表。候选层之外有更上游的层没站住或未知，照样算数。

完成条件：从提问层到 V1 每一层在全景表里都有状态，没有空格；索引候选层各有一句命中、没命中或待问。

### 3. 定根因

- **“查实没站住”的条件**：先在对应层页找到一条具体的“没站住的信号”，再从材料中逐字摘出能证明该信号已发生的原话，并说明原话如何满足这条信号；有页码、段落或行号时一并标出。原话必须证明“条件未达到、事实相矛盾或该验证明确未完成”。材料没有提到某事、没有给数字、没有提供访谈记录，只能说明信息未知，不能单凭缺席判成“没站住”。如果原话只说明尚未验证，只能判“这项验证未完成”，不能推成客户不会买、产品无效等更强结论。（推导）
- **先读层页**：定根因之前，读完每个根因候选层的层页全文，包括该层的信号与“症状到根因”表；候选不止一层时，先读完所有候选页再比较。没读到对应层页，或找不到能对应信号的材料原话，该层不得进入已查实根因集合。（推导）
- **唯一选择规则**：只比较第 2 步确认与当前提问有关、且满足上面“查实没站住”条件的层。未知和部分站住不作为根因；回边未交回造成的部分站住，照第 4 步回查起点。沿依赖顺序从上游向下游检查：`第 0 格 → V1 → V2 → V3 → V4 → {V5, V6} → V7 → V8`。第 0 格不作根因层；取第一个有已查实失败的层级，不按用户提问措辞、失败数量、严重程度或材料篇幅改变顺序。这样，多个层都没站住时总是取最上游的已查实层，其余列为下游表现或独立缺口。（推导）
- **V5、V6 并列规则**：V5 与 V6 是同一层级、互不为上游。若它们是沿路径遇到的第一组已查实没站住层，且两层都满足引文条件，把唯一根因写成 `V5 ∥ V6（并列根因）`，并分别附上各自的材料原话；不任选其一，也不按 V5、V6 的书写先后决胜。若其中只有一层查实没站住，就只选那一层；若 V1–V4 已有更上游的查实失败，则先选更上游层，V5/V6 列为下游表现或独立缺口。（推导）
- 未知不当根因。若相关层都没有查实没站住，明确写“现有材料不能确认根因”，把上溯路径上最上游的未知列为待问缺口；不能把“材料缺少某信息”改写成已查实的根因。第 0 格未知按第 6 步办。（推导）
- 部分站住的层不直接定为根因。因回边未交回而部分站住时，按第 4 步找回边起点；下游判断按第 6 步写条件句。（推导）
- 加载了「付钱与使用分离」包时，每层状态已经取最弱的那个角色（各层页页首「多个角色时」与全景扫描页「状态怎么判」），这里不再重取。

完成条件：根因候选层页均已读；唯一根因符合固定上游顺序，或按规则写成 `V5 ∥ V6`；每个入选层都有对应信号、材料原话和二者之间的说明。无查实根因时明确不定根因，并列出最上游未知及对应必问句。

### 4. 上溯查不到时按回边查

适用：提问层和它的上游没有一层查实没站住（只有站住、部分站住或未知），而用户说的症状确实在。

| 提问层 | 去哪层查 | 查什么 | 找到后怎么记 |
|---|---|---|---|
| V5 | V7 | 每客户成本清单产出了没有 | 「回边：V7 的成本清单没产出，V5 的价定不了稿」；V5 记部分站住，最要命的一条写「待回填」 |
| V5 或 V6 | 并列的另一层 | V5 问题查 V6：要动手或能叫停的人在不在名单上。V6 问题查 V5：带客或操作的一方拿不拿得到钱，收费单位是不是在惩罚使用 | 「并列：根因在 Vx」，不写成上游 |
| V2（差异化、定位、比较对象） | V3 | 「客户不买你时用什么」交回了没有 | V2 定取舍记部分站住，最要命的一条写「待 V3」；根因记 V3 |
| V2（靠什么赢）；V8 守不守得住 | 互查 | 压力测试答不答得出具体一项；这一项和 V2 的「靠什么赢」是不是同一件事 | 答不出或不是同一件：V2 定取舍记部分站住，最要命的一条写「待复核」，回 V2 重判；重判没站住，根因记 V2 |

- 在回边起点找到之后，从起点再往上，把还没读过的层读一遍。
- V3、V4、V7、V8 够不够大没有回边。
- 回边也查不到：「真正卡住的地方」写明上游没查到站不住的地方；有未知的，写「材料里缺……，先补这个」。部分站住的层按上游在前写进「我怎么看」，原问题按提问层的页直接答。不硬造根因。

完成条件：底稿里写明走过哪条回边或并列、在起点层看到了什么，或写明「回边无发现」；查到的结论已写进「真正卡住的地方」或「我怎么看」。

### 5. 把下游写成根因的表现

- 从根因层往下逐级写。每个没站住的层挂到离它最近的上游没站住层，写一句传导句：「因为 Vm 的〔哪件事〕没站住，所以 Vn 的〔哪件事〕定不了（或没有参照、只是假设）。」（逐级写为推导）
- 传导句先从上游那一层页的「本层没站住时，下游这些问题不直接答」里取。那一节没有的，自己写，标推导。
- 写不出传导句的下游层单列为「独立缺口」，不硬挂。（推导）
- 最后一句落到用户原来问的那件事。

完成条件：全景表里根因以下每个没站住的层，要么有一句传导句，要么标了独立缺口；传导句从根因层一级一级连到用户原问题，中间没有跳过没站住的层。

### 6. 追到 V1 和第 0 格时

上溯的终点是 V1 和第 0 格（推导）。分三种情形；三种可以同时成立，各做各的动作。V1 既命中没站住的信号、又有必问句材料答不了时，状态记没站住，根因写 V1，答不了的部分照常进缺口，四件固定动作照做。

- **V1 没站住**（命中信号）：根因就是 V1，按第 3 步写。V1 只判四样：写没写下，能不能被反驳，有没有写反证，是不是看到结果之前写的。诊断对不对、多条约束里哪条是主约束，报告没有判法（01 页「薄在哪」第一条），不判，明说。
- **V1 未知**（材料和当事人都没给）：不当根因，做四件固定动作。
  1. V1 哪几条必问句没有答案，改写成用户听得懂的问句（按 01 页的事前版或事后版），按末尾提问规则排在最前，进「我还需要你回答」。
  2. 下游每条涉及值不值、够不够、选哪个、投不投的判断，带条件答：先按一个写明的假设给出答案（取材料里最接近的数或说法，写理由），再说明这个假设要用户确认。受影响的具体问题，见 01 页「本层没站住时，下游这些问题不直接答」。
  3. 不涉及这四类的照常做完：各层证据到哪一级，材料的结论和正文对不对得上。V2 的排序、V8 的「够大」只按第 2 条带条件给。取证可以并行，被挡住的只是决定（178–180）。
  4. 「真正卡住的地方」不写这项未知，写第 3 步定的已查实根因；没有的，写「材料里缺……，先补这个」。
- **第 0 格有未知**（谁出钱、谁有权说停、约束是谁的、拍哪个板）：V1 的三个词没有主语，照 V1 未知同样办，做那四件动作。板没写明时两种读法都列（00 页「当事人不在场时」第 4 步）。

硬护栏：禁止因为 V1 未知就停住不输出，也禁止跳过 V1 在下游长篇输出（推导）。正面做法就是上面四件。

完成条件：V1 或第 0 格有未知时，「我还需要你回答」里有对应的问句；下游四类判断都带条件答，写明了假设并说了要用户确认；这项未知没有写成真正卡住的地方。

### 7. 根因没解决前，怎么答用户原来的问题

先有条件地答，紧跟着说根因。不拒答。固定三句（内部说法，写给用户时换成白话，见第 8 步）：

1. 根因句：「你问的是〔原问题〕，问在 Vy。往上查，Vx 的〔哪件事〕没站住，迹象是〔……〕。」
2. 条件句：「如果 Vx 按〔一句可核对的假设〕成立，且路径上 Vm、Vn 各按〔假设〕成立，那么〔原问题的答案〕。」上溯路径上每个没站住的层都列，上游在前。每层的假设取该层页「站住了长什么样」里对应的那一条；答案按提问层的页给。（逐层列为推导）
3. 反面句：「如果不成立，〔答案怎么变，或这个问题不用再答〕。」

- 上游有未知、假设不同答案就不同：照第 6 步第 2 条，先按一个写明的假设答，再说这个假设要用户确认；换一种假设答案会变的，用一句写怎么变。
- 条件句的结论只当「待验证」用，不当已定前提往下推。它的证据级别不得高于根因层，由闭环检查第 1 步第 4 条把关（根因层不在五段链上时也一样）。
- 先补哪条证据：根因层的取证排第一。下游的事实调查可以同时做，被挡住的只是涉及现金和不可逆承诺的决定（178–180；T06 1139）。
- 原问题落在九类尺子外：先给索引里写的回查结果，再按产出模板页「不在诊断尺子里的问题：照答，标明是经验」给做法。

硬护栏：禁止只报根因不答原问题；禁止把根因放在末尾当补充。顺序固定：带条件的直答在前，真正卡住的地方紧跟在后。

完成条件：输出里找得到这三句的白话版（条件句、反面句在直答或「该怎么做」，根因句在「真正卡住的地方」）；条件句里每个假设都是一句能核对真假的话；上溯路径上每个没站住的层都在条件句里出现。

### 8. 写进输出

节名、顺序和白话对照见产出模板页「决策模式」。
- 直答：正面回答原问题，答案带第 7 步的条件句，照产出模板页「先答他问的」。全面诊断时直答跑不跑得通、最该先做什么，可用报告 1606 的句式：在哪类客户、什么输入边界、什么收费范围内有什么证据，还缺什么，下一笔验证什么。
- 真正卡住的地方：根因句的白话版，引材料原话，再一句说它怎么让原问题答不死或答了也白答。没有查实的根因时写「材料里缺……，先补这个」。
- 我怎么看：上溯路径和第 5 步的传导句换成白话，按上游到下游排；独立缺口单列一条；走过的回边或并列只写查到的结论。
- 该怎么做：每条建议前带条件句；取证顺序根因层在前。
- 我还需要你回答：第 0 格和 V1 的未知项与问句，按末尾提问规则取。九类尺子外的原问题不放这里，照第 7 步答。
- 反思模式：步骤相同。提问层取当时拍的那个板对应的层；迹象先核事前迹象。材料按决定日怎么分，见产出模板页「反思模式」第 1 步。（推导）

## 做完的标志

1. 写得出「问在 Vx」，并引了用户原话。
2. 从提问层到根因层之间每一层，在全景表里都有状态。
3. 根因层有一条当场可核对的迹象，标了来源三色；没有查实的根因时，写了「材料里缺……，先补这个」。
4. 根因以下每个没站住的层有传导句，或标了独立缺口。
5. 原问题有根因句、条件句、反面句；属于九类尺子外的，给了回查结果和标明是经验的做法。
6. V1 或第 0 格有未知时，「我还需要你回答」有问句，下游四类判断按写明的假设带条件答；未知没有当成根因。

## 薄在哪

- 整页规则是推导。报告只有 438、178–180、218 三个锚点。
- 终点最弱。追到 V1 只能判写没写、能不能反驳；主约束是哪条、诊断对不对，报告没有判法（444、452）。
- 「未知不当根因，改用已查实的最上游缺口」「独立缺口」「V5 与 V6 并列写」三条是本页为防诊断落空或硬挂因果加的。
