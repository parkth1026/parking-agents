# 风险优先的实验选择与证据边界

以报告 B08 的观点为范围。以下是选定原书段落的原创摘要；没有宣称通读或完整收录全书。所引原文选段随技能分发。页码均指指定 raw 版本的页锚点，不默认等于纸书页码。

## 报告观点的补全与校准

| 报告条目 | 原书核对后的解释与条件 |
|---|---|
| B08.theory.01 · 三类商业假设 | 需求吸引力、实现可行性与经营可持续性对应不同假设。应将“材料能采购”和“运输后仍盈利”等复合句拆成可独立验证的命题。[^s1] |
| B08.theory.02 · 重要性 × 证据 | 重要性表示假设失败是否使模式失效；证据轴表示是否已有相关、可观察且近期的依据。先处理高重要性且缺证据的假设。[^s1] |
| B08.theory.03 · 测试卡与学习卡 | 测试卡事先写假设、测试、观察与门槛；学习卡区分实际观察、解释与下一步。实验次数不能代替证据强度。[^s3][^s4] |
| B08.theory.04 · 实验组合 | 选实验需结合假设类型、已有证据和决策时限。同一假设可用多个实验增加证据强度；不要由一次弱实验作重大决定。[^s2] |

## 方法提示

以下为编者结合原书与报告整理的应用步骤，不冒充作者逐字流程。方法依据：[^s1][^s2][^s3][^s4]

1. 写成具体对象、行为与条件明确的单一假设。
2. 标出已有证据和失败后果，选最需验证的一项。
3. 根据想观察的行为选实验，在执行前写出通过与不成立条件。
4. 记录观察与解释的差异；有支持后再选更强证据的实验，遇反证则调整或停止。

**预期产出：**针对当前决定的选择或验证方案；逐项说明事实、假设、观察结果和改变决定的条件。此产出格式是编者建议。

## 适用条件与误用边界

实验强度取决于实际设计、样本和行为。原书成本、时间和等级用于选择参考，不能替代本项目估计。

书中作者的机制解释与案例结果不能证明当前业务成立。应用时先核对角色、任务、资源、采购及交付条件。

## 代表案例与逻辑

### 1. Realtor.com 的人工报告

产品经理用站内信息手工拼成 PDF，为用户探索买卖住房时机。先交付结果，可学习客户需求，再决定哪些环节值得自动化。[^s5]

**迁移限制：**此例不证明自动化可靠、人工成本可规模化或客户已付费。

### 代表实验的选择提示

| 当前要学什么 | 可优先回查的实验 | 解释限制 |
|---|---|---|
| 过去的问题与原有替代 | Customer Interview、A Day in the Life | 陈述和观察不等于购买 |
| 信息或价值表达能否引发行动 | Simple Landing Page、Explainer Video | 点击不等于交付价值 |
| 指定任务能否完成 | Clickable Prototype、Single Feature MVP | 任务成功不等于经营成立 |
| 客户是否需要结果 | Concierge | 记录人工投入，另测自动化 |
| 明确条件下的购买推进 | Presale、Letter of Intent | 预售、意向与实际履约须区分 |

这些是原书实验库中的选择入口。选择表的证据解释是编者应用建议；44 种实验不在本页逐项重写。

### 把下一次实验写到能执行

原书要求假设可测试、精确且离散。测试卡与学习卡把计划和观察分开。[^s1][^s3][^s4]

编者建议使用以下字段，不把建议字段或门槛冒充作者的统一标准：

| 字段 | 要写清什么 |
|---|---|
| 输入 | 哪类用户、真实任务、已有替代、允许的数据与产品成熟度 |
| 单一假设 | 在什么条件下，谁会产生什么可观察行为 |
| 操作 | 谁提供什么方案；是否人工；价格与退出条件 |
| 观察 | 行为记录、任务结果、采购推进、交付投入分别记录 |
| 判据 | 结果出现时继续什么；不出现时调整哪条假设 |
| 解释限制 | 样本选择、特殊支持、测量误差及尚未覆盖的风险 |

例如人工报告有价值，只支持进一步检查需求与工作流程；自动化质量、成本和付费仍需匹配的实验。

## 决策追问

以下是编者应用提示：这次实验究竟要改变哪一条假设的判断？你观察到的是意见、行为、承诺，还是实际交付？
