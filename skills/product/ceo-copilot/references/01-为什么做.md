# V1 为什么做：处境、约束与目标

**这一层只回答**：做这件事是为了摆脱哪条约束，做成后必须贡献什么，被证明之前最多赔得起多少。

**多个角色时**：出钱的人、做事的人、有权说停的人不是同一个时，五条必问句逐个问。任一人答不上，或几个人的答案对不上（约束不同、「多少算够」口径不同、上限不同），本层按最弱的一个算没站住（推导；角色名单见 W03 1662，授权见 B03 328）。一个人做时不适用，只问当事人。

## 必问句

1. **事后版**：当初是为了摆脱哪条约束才做的？写成一句别人能反驳的话：主要受限于 X，而不是 Y。做到现在，哪些记录在案的事实支持它？出现过哪些对不上的事实？这条约束松了没有？
   - **事前版**：不做这件事，现在卡在哪一条上？卡的是生意、产品，还是你自己？写成一句别人能反驳的话：主要受限于 X，而不是 Y。靠哪几条事实成立？出现什么事实算你诊断错了？
   - 答不上来说明：答成「要增长」「要上某项技术」「行业在涨」，说明只有目标没有诊断，下游所有选择没有尺子。写不出会推翻它的事实，说明诊断只是立场。
   - 来源：G0 185；B04 444、453；W01 1623–1624；推演 1573（做得更快不等于摆脱原约束）；「X 而不是 Y」句式、「卡的是生意、产品还是你自己」为推导
2. **事后版**：开始前写下的「做成算什么」是什么：给谁什么价值、靠什么有收入、到多大、多久之内？低于哪条线即使卖得出去也不算数？哪些成果不记到这件事头上？已经收到的钱和客户，对着这条线到了哪里？
   - **事前版**：做成了算什么？对你（或公司）来说，它要到多大、多久之内才值得继续做？低于哪条线即使卖得出去也不算数？哪些成果即使做出来也不记到这件事头上？这条线对的是你现在打算用的收费方式吗？
   - 答不上来说明：答不出这条线，「够不够大」没有分母。给出的数是当场想的、只是覆盖自身开销的打平线、或只算在已否掉的收费方式上，说明「成没成」至今没有共同口径。不计入项答不出，顺带的好处会被当成成立的证明。
   - 来源：B00 245；B10 737；W01 1619、1625–1627；B01 271；评审第六问 2004；「你自己要它到多大」、打平线与收费方式两句为推导（依据 1603）
3. （换信息还是押注：第 0 格已答则引用，不重问。）**事后版**：刚过去这一轮，当初定的是花小钱换一条信息，还是押注去检验真有人用、换一家还成立？实际花的钱和用来考核的尺子，跟这个定位一致吗？
   - **事前版**：接下来这一轮，是花小钱换一条信息，还是押注去检验真有人用、换一家还成立？换信息的话，换哪一条？押注的话，前面哪几条已经有证据？
   - 答不上来说明：答不上，说明「继续投入」没有定性：上限没法定，考核尺子没法选，结果出来也不知道算不算数。常见后果是要么不动，要么不设上限。
   - 来源：T01 1087；T02 1097；B03 329；C01 1156；写成问句和「定性」的说法为推导
4. **事后版**：这一轮开始前，写下过最多投多少钱、多少人时、对外许多少承诺吗？写的是多少、哪天写的？已经许出去、收不回来的承诺有哪些？
   - **事前版**：在那条线被证明之前，这一轮最多投多少钱、多少人时、对外许多少承诺？哪些不可逆的事明确不碰？
   - 答不上来说明：答「看情况」「先做着」，说明赔付上限没定，之后继续与否只能凭已经投了多少来决定。
   - 来源：W02 1645–1646；T03 1105；B02 300；W16 1925；关卡总则 180；工作表总则 1611
5. **事后版**：开始前写下过什么情况就停、就调整、就把资源收回吗？原话是什么、哪天写的？结果出来之后改过没有？谁有权说停？
   - **事前版**：出现什么情况就停、就调整、就把资源收回？这条现在写下，还是打算发生了再议？谁有权说停？
   - 答不上来说明：事后再议的停止条件等于没有。没有人有权说停，等于默认继续。结果出来后改过标准，等于没有标准。
   - 来源：B00 245；W03 1662、1665；W16 1926；评审第五问 2004；B08 591

## 站住了长什么样

- 约束诊断写成了一句可反驳句，同一页上列有支持它的事实和会推翻它的事实。（B04 444；W01 1623–1624）
- 必须贡献的结果写明了价值、收入方式、量级、时间窗及理由，并写明哪些成果不计入；这条线不是只覆盖自身开销的打平线，且对着当前打算用的收费方式。（B00 245；W01 1625–1627；B10 737；分号后为推导，依据 1603）
- 这一轮已经定了是小额换信息还是押注检验采用与复制，考核用的尺子与它一致。（T01 1087；T02 1097；B03 329；「定性」的说法为推导）
- 本轮投入上限（现金、人时、对外承诺）和不可逆禁区有带日期、带负责人的记录。（W02 1645–1646；W16 1925；填写建议 1634）
- 停止、调整、资源回收的条件在看到结果之前已经写下，并指明由谁裁决。（B00 245；W03 1662、1665；W16 1926；B08 591）

## 没站住的信号

- 做这件事的理由只有趋势故事或「必须上某项技术」，说不清要摆脱什么约束。（G0 停止信号 185）
- 理由里只有想达到的数字（规模、份额、里程碑），没有「为什么现在达不到」。（C06 1214；C07 1224；B04 436）
- 诊断写不出会推翻它的事实，或只靠逻辑讲得通，没有客户、成本、竞争方面的事实。（B04 453；W01 1624）
- 说不出低于哪条线不算数；或给得出数，但它只是打平线，或只算在已否掉的收费方式上。（B00 245；B10 737；评审第六问 2004；后半句为推导）
- 说「继续投」却没说这一轮是换信息还是押注；投入没有上限；或继续的唯一理由是已经投了很多。（T01 1087；B02 300；B10 740；W16 1918；第一小句为推导）

## 上下游

- **依赖上游**：本层是地图最上游，不依赖别的层。它取第 0 格的三项：约束是谁的（生意、产品、当事人自己）、这次要拍的是哪个决定、现有最强证据到哪一步（决定问事前版还是事后版）。第 0 格没答，本层三个词没有主语（推导，锚点 22、147、185）。
- **回边与并列**：无。三条回边都不经过本层。V8「够不够大」拿本层的线当尺子，是正向依赖。本层是上溯的终点。
- **本层没站住时，下游这些问题不直接答**：
  - V2 选哪个方向：没有约束诊断和贡献线，排序没有尺子；可以帮着列候选，不给排序结论。（B04 445；1573）
  - V8 够不够大：线没定或只是打平线，就没有答案。（B10 737；评审第六问 2004）
  - V5 试点收不收钱、定多少：取决于这一轮是换信息还是押注，以及赔得起多少。（T01 1087；W02 1645；关联为推导）
  - V2、V7 破例接不接、边界划在哪：排除项要能保护主任务，主任务来自约束诊断。（B04 447）
  - 任何层的继续、加码、转向、停：没有事前写下的上限和停止条件，答案只会顺着已投入多少走。（W16 1918）
  - 不挡取证：事实调查可以并行先做，被挡住的是「下一笔投入值不值」这类决定。（178–180；T06 1139）

## 什么算证据

**算**

- 约束诊断要事实：自家记录里过去几个可比周期需求、赢单、价格、毛利、回款的变化（W01 1621），每新增一个客户多出的非标准工作（W01 1622），客户、成本、竞争方面的事实（B04 453）。
- 写明的反证：出现什么算诊断错了（W01 1624）。
- 每条分清事实、解释、假设，带日期和来源（填写建议 1634）。
- 从零开始时，约束的事实是当事人自己的：钱和时间能撑到何时，不做这个会去做什么（推导；T03 1105–1107）。
- 贡献线、本轮定性、投入上限、停止条件是当事人的决定，不需要外部证据；判定只看：写下了没有，有没有日期和负责人（1634），是不是看到结果之前写的（B08 591），时间窗有没有理由（W01 1626）。
- 诊断里涉及客户行为的部分，至少要有近期具体经历与原有替代（E1，211）才算有支撑（推导，报告未给关卡标梯级）。
- 五项缺一项，本层就没站住，不拿其他几项平均掉（218 用到本层，推导）。

**不算**

- 趋势故事或「必须上某项技术」。（185）
- 一张 S 曲线。（237、252）
- 别家做成了。（案例幻觉 1555；C01 不能推出 1158）
- 只是逻辑讲得通。（B04 453）
- 内部判断和网络类比，只支持「值得探索的假设」。（E0，210）
- 当场想出来的数；结果出来之后补写或改过的线和停止条件。（B08 591；前半为推导）
- 覆盖自身开销的打平数当成贡献线。（推导；1603 说它只是算术阈值）
- 已经投了多少。（B10 740；W16 1918）

## 这一层尺子外的问题

九类问题照产出模板页「不在诊断尺子里的问题：照答，标明是经验」办：本层能查的先查，做法前标明是一般经验，写出前提。

- 时机（为什么是现在、早了还是晚了）：只给经验。报告只有一个时点隐喻和一则寓言，自认不是预测器、不给启动年份（237、1158）。
- 团队与当事人：只给经验。本层只问约束是不是当事人自己的、他自己要它到多大；个人目标与意愿、团队匹配、合伙关系报告无题源（读者设定 22）。
- 融资与现金：只给经验。本层只问「最多赔得起多少」写没写；这个数怎么算、能撑多久怎么排、融资节奏报告无题源。
- 竞争动态：只给经验。约束诊断可以用竞争方面的事实（453），对手出招后怎么应对本层不判。
- 获客与增长引擎怎么建：只给经验。六方面拆瓶颈里有「获客」一项，只用来定位卡在哪，怎么建本层不判。
- 合规：交专业人员核验（218）。「不可逆禁区」里可能有合规项，本层只问写没写。
- 验证期之后的经营：只给经验。本层五问对已过验证期的人问得出口，但之后的经营问题报告止于 G9。
- 报告无题源：贡献线的依据从哪来、多条约束怎么排主次，见薄弱处，回答时标推导。
