4.2 七种力量：收益、屏障、证据必须同时出现 [S45] [S46] [S48]

下面前两列归纳框架，最后一列是针对你们的反证问题。仅仅拥有某项资源不等于拥有力量；还要判断收益最终归客户、供应商、渠道、人才，还是我方。

力量收益机制竞争屏障对你的核查问题
规模经济规模扩大使单位成本更低。小规模对手难达到相同成本。共享基础设施是否真能摊薄成本？新增客户是否反而增加大量服务？
网络经济更多相关参与者提高其他参与者价值。对手难以从零复制有效网络。一个新客户如何改善另一个客户的结果？贡献是否获合法授权？
反向定位新商业模式在某些方面更有吸引力。旧模式采用它可能损伤既有利润与结构。旧厂商是真的不愿跟，还是你只希望它不会跟？它能否成立独立业务？
转换成本既有客户迁移会损失时间、能力、数据连续性等。替换现有供应商的净收益不足。成本是否伴随客户持续受益？不要通过人为封锁制造不信任。
品牌客户因信任、认知或特定联想愿意选择或付溢价。对手难迅速复制长期形成的认知。谁信任你、因为什么结果、愿付多少？品牌不是一个视觉标识。
独占／稀缺资源控制别人难以获取的有价值资产。合法独占、稀缺性或其他获取障碍。专有数据、授权、接口或人才真正受谁控制？收益会不会流向供应方？
流程力量长期积累的协作流程带来更优成本或结果。流程难以被完整观察、理解和快速重建。是经过多次交付验证的系统能力，还是只有关键个人能救场？

方法之间有张力：按任务搭配，不混成万能模板

同一方法在错误阶段、错误证据水平下使用，可能比不用更危险。

看似冲突的主张应如何处理相关框架
从技术出发 vs 从客户出发用能力生成机会，用真实任务与购买证据筛选。能力不是需求的证明；客户诉求也不自动决定应当自建什么。B06、B07、T03
广泛探索 vs 集中突破候选阶段广泛；验证阶段有限并行；开发与进入市场阶段集中。以证据决定收敛，不以会议气氛决定。B02、B06、B12
长期战略 vs 快速试错战略规定问题范围、取舍和投入边界；实验修正具体假设。既不每次访谈就换战略，也不为维护战略拒绝反证。B04、B05、B08
早问价格 vs 妈妈测试先理解过去任务，再透明地做概念与价格验证。避免把假设性口头报价当订单；不要把“不推销”误解为永远不讨论钱。B09、B19
标准化 vs 完整产品可以有标准实施、配置、培训与伙伴支持；必须限制核心分叉、无界需求与不可预测服务成本。B12、B17
独立组织 vs 复用资源分离冲突的目标、流程与激励；共享真正有用的资产。由高层明确边界，不用“协同”掩盖资源争夺。B01、B15
最小实验 vs 可信交付实验可以缩小任务和范围，不能隐瞒真实成熟度、误差、数据用途或重大风险。对安全、授权、可追溯保留底线。B08、B20、B24
护城河 vs 持续客户价值有转换成本不等于应该制造锁定。竞争屏障要与客户净收益共同成立；Martin 对这点与 Helmer 存在不同侧重。B23；S48
宏观市场增长 vs 企业能够赚钱必须分析可达市场、预算、替代、价值链分配和自身成本。增长行业中也可能只有供应方或渠道拿到收益。B10、B21、T05
C 端转化提高 vs C 端真的受益更容易下单不必然意味着更好决策。要同时观察错误、后悔、退换、满意和任务正确性，避免将营销效率当消费者福利。本报告针对 B2B2C 的应用约束

六种常见“立项幻觉”

技术幻觉“已经无人闭环，所以一定有人购买。” → 缺少任务、购买和重复性交付证据。
市场幻觉“行业很大、正在增长，所以足够支撑我们。” → 缺少可达客户、预算和价值分配分析。
案例幻觉“某公司做成功了，所以我们也能。” → 可能忽略时间、渠道、成本、伙伴及样本偏差。
标准化幻觉“核心代码一样，就是标准产品。” → 售前、数据准备、实施和救援仍可能逐客户增长。
付费幻觉“客户付了试点费，市场就成立了。” → 可能来自试验预算、关系采购或不可重复的特价支持。
护城河幻觉“有 AI、有数据、有先发，就是壁垒。” → 缺少收益、竞争屏障、权利归属与持续时间的证据。

8.1 最小实验组合，不先开发“全能平台”

问题实验：寻找近期真实的选择、购买、拒绝和退换事件，保留无问题、旧方案足够好的反例。

任务对照：让符合任务条件的用户分别使用现有方法与候选方案；观察判断正确性、完成时间、帮助请求、不确定性理解，以及错误后果。样本和判断阈值根据基线、所需改善与风险设定，不虚构一个通用样本数。

知情商业实验：明确功能成熟度、输入限制、人员参与、报价、服务边界和退出安排；记录 B 是否真的推进，以及员工是否实际使用。不能用隐藏人工冒充全自动，不能隐瞒试点性质。

复制实验：第二家独立客户采用相同任务和标准范围，记录每个新增例外；再观察真实使用周期内的再次使用与续购，而不是用短期新鲜感替代长期价值。

退出条件：简单信息卡已经解决问题；消费者没有净改善；B 不愿为收益付费；关键输入无法合法取得；复核成本吃掉贡献；每家都需要重建核心流程。任一关键项成立，都应重新定位、缩小范围或停止。

第一，这一轮新增了什么证据？第二，出现了什么反证？第三，当前最危险的假设是什么？第四，下一笔投入具体购买哪一条证据？第五，什么条件下加码、返回或停止？第六，即使产品成立，它真的可能达到公司需要的经营贡献吗？

关键术语：避免团队各说各话

以下以本报告的使用口径解释。涉及统计、财务或法律口径时，应另行统一具体定义。

第二曲线
新增长机制的管理隐喻；本报告用它指有机会形成第二套可重复经营模式，而非第二个产品发布。
B2B2C
我方服务 B，B 参与把价值交给 C；需分别验证各端任务、激励、成本和价值流。
JTBD
特定情境下想取得的进展；不是人口画像，也不等于用户点名要的功能。
价值主张
面向特定客户与任务，说明比实际替代更有价值的理由。
商业模式
创造、交付和获得价值的整体结构；收费方式只是其中一部分。
滩头市场
优先集中的首个可服务细分市场，具有相似任务、购买方式与可复制条件。
MVP
为检验关键假设提供最低必要体验；范围可以小，诚信、安全和必要可靠性不能省略。
MVBP
最小可行业务产品；不只验证功能，也开始验证真实价值、使用和付费。
完整产品
客户获得结果所需的产品、接入、数据、培训、服务与伙伴条件的整体。
最小可行生态
必要参与者能够在有限范围内协同交付真实价值的最小闭环。
价值蓝图
把活动、参与者和依赖画出，识别共同创新和采用链障碍。
机会解决方案树
结果 → 用户机会 → 候选方案 → 假设测试的可追溯结构，不是功能路线图。
单位经济
围绕明确计价和交付单位，计算收入、成本、获客及持续价值；必须声明口径。
CAC / LTV
获客成本 / 客户生命周期价值。早期可作情景假设，不能用猜测续费率制造精确的 LTV。
探索组合 / 经营组合
前者管理未知和证据；后者管理稳定交付、效率和收益。项目可能迁移、调整或停止。
护城河 / Power
不仅存在收益，还需有竞争屏障；稀缺资源的收益也未必归我方。
