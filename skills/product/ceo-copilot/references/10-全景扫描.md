# 全景扫描

> 三条强制动作的第一条，治「说得片面」。括号里的数字是报告纯文本行号；标「推导」的不是报告原话。板、层状态四档、证据标尺两把、来源三色照共享词表用，本页不重新定义。

不管用户问的是哪一层，八层都过一遍，每层留下状态、证据、最要命的一条，填成一张全景表（推导）。本页只登记和汇总。哪层是根因归上溯根因；各层答案之间对不对得上归闭环检查。

## 步骤

开始前先定输出模式（决策模式、反思模式、缩略版），判法和各模式跳过哪几步见产出模板页「先定用哪种输出」。

### 第 1 步：走第 0 格

照 00 页做，本页不重抄。当事人不在场时走 00 页「当事人不在场时」。

完成条件：板、处境、约束归属各有一个答案或记「未知」；每个已知角色各有一个证据级别；两个条件包各写了「加载」或「不加载」；00 页的几个开关各有答案或「未知」。

### 第 2 步：列角色，定每层问哪一版

- 从第 0 格已知的信息列一份临时名单：掏钱的、能否决的、用的、日常操作的、带客的。有几档收入、几类客户也列上。正式名单在 V6 画全（06 页页首）；V6 补出新角色后，回 V3、V4、V5 对新角色补问（03 页页首）。
- 按 00 页「问事前版还是事后版」，分层分角色定问哪一版。

完成条件：名单上每个角色在 V2 到 V8 各标了「事前」或「事后」；只有一个角色时写明「掏钱的就是用的，只问一遍」。

### 第 3 步：逐层扫

顺序固定：V1、V2 初选、V3、V2 定取舍、V4、V5、V6、V7、V8。上游先扫，下游才有东西可引用。00 页按板列的重点层不改变这个顺序（推导）。每层做六件事：
1. 读扫描卡上这一层的三样：只回答什么、必问句、没站住的信号。条件包已加载的，加读 09 页该包里这一层的一节。
2. 拿每条必问句去材料里找答案。找到的记原话或行号。找不到的记「未知」，不替当事人补，也不停下来问用户（1611 允许写未知；缺口在末尾统一问，见产出模板）。多个角色时每个角色各找一遍。
3. 拿「没站住的信号」逐条对材料。命中的记信号原文和材料依据。
4. 判状态，见「状态怎么判」。
5. 标证据，见「证据标哪把尺」。
6. 写最要命的一条，见「全景表」填法。

三条回边各复核一次（在扫描里复核为推导；回边见 02 页页首、05 与 08 页「上下游」）：扫完 V3 再定 V2 定取舍；扫完 V7 回看 V5 的价还盖不盖得住成本清单；扫完 V8 守不守得住，回看它和 V2「靠什么赢」是不是同一件事。扫描中看到材料的结论句和正文对不上，记下两处行号，交闭环检查（推导）。逐问记录和全景表都是工作底稿，不原样进输出，怎么写给用户见「全景表」填法末条。

完成条件：每层每条必问句、每个角色都有一条记录，内容是材料依据或「未知」；每层的状态、证据、最要命的一条都已填；三条回边各写了「已复核，改了哪格」或「已复核，无改动」。

### 第 4 步：按需读层页

读层页全文只有三种情况：该层状态是没站住；是未知；被上溯根因定为根因。其余层只用扫描卡。读全文后做三件事：用必问句下的「答不上来说明」把缺口写具体；对照「条件项」看有没有该触发的；对照「什么算证据」复核证据级别。状态或级别有改动的，改表并写原因。「症状到根因」一栏留给上溯根因。

完成条件：每个没站住、未知的层都读过全文，三件事各有结果；部分站住和站住的层没读全文，最多读过「站住了长什么样」一节（见「状态怎么判」第 4 条）。

### 第 5 步：汇总

填全景表的表下四行，再逐条对「整页完成条件」。完成条件：那五条全部成立。

## 状态怎么判

四档的定义见共享词表。按下面顺序判，先命中哪条用哪条（顺序为推导）：
1. 命中任一「没站住的信号」：没站住。
2. 五条必问句在材料里全找不到答案：未知。
3. 找到了答案，没命中信号，但只有事前版的答案：部分站住。V1 的贡献线、投入上限、停止条件两版相同，不受这条限制（00 页）。
4. 找到了事后版的答案，没命中信号：拟判站住。这时读该层页「站住了长什么样」一节（扫描卡上没有这一节），每句都在材料里指得出依据才记站住；有一句指不出，记部分站住，写明是哪一句。

只找到一部分答案时，找到的部分照 1、3、4 判，找不到的逐条进缺口清单。上一问未知，下一问因此没有对象可问时，只记一次缺口（推导）。

多个角色、多档收入、多类客户：逐个判，本层取最弱一环。强弱顺序是没站住、未知、部分站住、站住（逐个问与取最弱见各层页页首；顺序为推导）。一个角色答得上，不能替另一个角色记成有证据（03 页页首）。V2、V6、V8 各分两行报：初选与定取舍、采用链与获客通路、够不够大与守不守得住。两行不互相抵，层的状态取较弱的一行（分两行见各页页首；取较弱为推导）。因回边没交回而定不了稿的格，没命中信号时统一记部分站住（依赖回边事实的那句站住句不成立），不记没站住，原词放「最要命的一条」：V2 定取舍待 V3 交回替代事实，写「待 V3」（02 页页首）；V5 待 V7 回填成本清单，写「待回填」（07 页「回边与并列」）；V2 取胜假说待 V8 守不守得住复核，写「待复核」，记在 V2 定取舍一行（08 页「本层没站住时」末条）。统一记这一档为推导；这类格怎么定根因见上溯根因页第 3、4 步。

## 证据标哪把尺

- 客户一侧的命题用 E0 到 E6（210–216）：V3、V4、V5、V6 全层；V2 里「客户拿什么比、凭哪一项选」；V7 的第二家和再次交付；V8 里能实测的部分。
- 自家的账和当事人的决定用四档：事实、线索、推断、未知（1802）。V1 全层；V2 的备选和不做清单；V7 的每客户成本清单；V8 倒推表里的每个数。
- 两把尺这样分是推导，报告没给对应。定级办法照 00 页第 3 件事。证据格写最弱一环的级别和它是谁的，例：「使用者 E0，掏钱的人 E3」。同一层不同命题分开标，不合成一个数（206）。

## 汇总规则

- 不打总分，不取平均，不拿「站住了几层」当结论（218）。
- 致命缺口一票否决，共七条。材料里已经发生下面任一件事，在表下登记致命缺口，别的层再好也不抵，裁决不出现「继续」（见闭环检查第 5 步；218；报告称退出条件，1589；换成通用说法为推导）：更简单的现成办法已经把问题解决了（V3、V4）；用的人用了没有净改善（V4）；掏钱的人明确不愿为这项收益付钱（V5）；关键输入或数据无法合法取得（V6）；必要的操作者不愿配合（V6）；人工复核的成本吃掉了贡献（V7）；每家客户都要重做核心交付（V7）。
- 判致命要有材料里发生过的事实。只是没查过的记未知，不记致命（推导）。合不合法由相应专业人员核验，这里只记材料怎么说（218 末句）。
- 七条清单只在本页写全，别的页都叫「致命缺口」并指到这里。本页只在表下登记有或无、哪层哪条；命中后对到哪个裁决归闭环检查第 5 步。本页不给整体结论；第 0 格或 V1 有未知时，下游哪些判断要按写明的假设带条件答，照上溯根因页第 6 步。

## 同一事实只问一次

每个事实记在最上游问到它的那一层。下游写「见 Vx」，再加一句本层拿它判什么，不重问、不重抄（推导）。归属依据在各层页「指针」一节。

| 事实 | 记在 | 引用它的层 |
|---|---|---|
| 客户不买你时用什么、代价多大 | V3 | V2 定取舍、V5、V8 守不守得住 |
| 这一轮是花小钱换信息，还是正式投入去检验 | 第 0 格（00 页第 2 件事的追问） | V1 第 3 问（已答则引用，不重问）、V5 |
| 必须贡献多少 | V1 | V5、V8 够不够大 |
| 角色名单 | V6（之前用第 2 步的临时名单） | V3、V4、V5、V7 |
| 每客户成本清单 | V7 | V5、V8 够不够大 |
| 靠什么赢 | V2 | V8 守不守得住 |

首单的特殊条件分两半：钱的性质记 V5，交付上的便利记 V7。同一层里两问问出同一件事，第二处写「同第 n 问」。完成条件：同一条材料依据只在一层展开，其余出现处都是指针。

## 类比与框架纪律

- 任何案例或类比只算 E0（210），不抬高任何一格的证据级别，不进全景表的依据栏。材料里用户自己引的也一样，例：「某公司做成了」「同行靠这个收了不少」。
- 每引一次，写成问用户的问句（例：「你的情况在时间、渠道、成本、伙伴上和它一样吗」），并紧跟一句它不能推出什么，写三样：还有哪些原因；哪些依赖和这件事不同（时间、渠道、成本、伙伴、样本偏差）；要什么新证据才用得上（1148；1555）。
- 案例只取用户材料或已读层页列出的报告案例条目，带行号。日常诊断不展开 Wiki 案例页；已有条目没有的细节和数字不凭记忆补。
- 用某个框架前核对两件事：这件事现在的阶段（第 0 格的板、该发散还是该收敛）；这一层的证据级别。拿它们对层页「题源」表的「误用边界」一栏，对不上就不用（1537）。框架只在读过全文的层里用，依据该层页内的题源与误用边界；知识页链接不触发 Wiki 读取，只用扫描卡的层不点名框架（推导）。

完成条件：输出里每个案例或类比后面都有一句「不能推出」；每个点名的框架都在对应层页的题源表里，并写了一句为什么这个阶段能用。

## 碰到九类尺子外的问题

九类清单、各类先查上游哪件事、经验部分前面那句说明，只在产出模板页「不在诊断尺子里的问题：照答，标明是经验」写全。板本身落在九类的，第 0 格已登记，照 00 页。扫描时只做登记：
- 某层碰到九类问题（用户问的，或材料的结论要靠它才成立）：在该层「尺子外」格写类别名。
- 整件事是面向个人消费者的产品、实体与服务类生意：各层按通用句照常判，「尺子外」格写类别名。整件事已过验证期：照 00 页处境表，V1 到 V8 只当回查清单用，各层只查眼下的问题是不是这一层当初没站住留下的。
- 「尺子外」不是第五档状态。状态格仍填四档之一，按能答的部分判，不拿经验部分的答案去改状态（推导）。

完成条件：用户问题和材料里的每个九类问题，都在某一层的「尺子外」格里出现；输出里对它先查了上游再给做法，做法前标明是一般经验，每条写了前提。

填法：
- 状态：四档之一。
- 证据：照「证据标哪把尺」。写最弱一环和它是谁的，再写问的是事前版还是事后版。
- 最要命的一条：一句话。没站住的，写命中的信号；命中多条时取一条，它不解决，本层「只回答什么」那句就答不出（推导），属于致命缺口的前面标「致命」。未知的，写最该先问的那条必问句。部分站住的，写不成立的那句站住句，或「只有事前版」。站住的，写依据最薄的那句站住句。
- 依据：按来源三色写。材料写原话或行号，报告写行号或条目编号，推导写「推导」。引用上游的写「见 Vx」。
- 尺子外：本层碰到的九类问题，写类别名，这部分只给经验；没有写「无」。
- 写给用户：全景表是内部工作底稿。全面诊断时，在「我怎么看」后面给一张八个方面的白话状态表（每格一句）；其他情况进「需要的话我还可以给你」。「尺子外」列的类别照产出模板页答，标明是经验。

表下四行：
- 致命缺口：有或无。有的写哪层、哪条、材料依据。
- 最上游一个没站住或未知的层：写层号，交上溯根因。
- 回边复核：改了哪格、为什么；没改写「无改动」。
- 缺口清单：每个未知项一行，写成要问当事人的原句，第 0 格和 V1 的排最前。哪几个进「我还需要你回答」（最多 3 个），见产出模板页「末尾提问规则」。

## 整页完成条件

1. 表里没有空格：十一行、每行六格都有内容。
2. 每个「站住」的依据格里有材料原话或行号。只有报告或推导撑着的，不记站住。

4. 读层页的范围符合第 4 步。
5. 表下四行都已填。

## 薄在哪

- 状态的判定顺序、只找到一部分答案时怎么判、四档的强弱顺序、两把证据标尺的分工，都是推导。报告只有「不能用评分平均掉致命缺口」（218）和「任一关键项成立」（1589）。
- 致命缺口七条是 218 与 1589 的合并。报告原话写在付钱与使用分离的语境（消费者、B、简单信息卡），换成通用说法和对到层都是推导。
- 扫描卡上没有「站住了长什么样」，所以拟判站住要另读层页一节。02 页的「待 V3」、07 页的「待回填」、08 页的「待复核」、06 页的「未证」不在四档里，本页统一记成部分站住，原词放进「最要命的一条」。
- 「未知」也触发读全文。材料很少时八页可能都要读。
