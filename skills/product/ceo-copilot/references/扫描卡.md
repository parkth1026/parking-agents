# 扫描卡

> 全景扫描时常驻的一张卡。下方各层的「只回答什么」、必问句两版和没站住的信号，仍由各层页摘出；修改这些摘录请改层页。先用下面的通用汇总口径区分整层状态与未知子问题，判法仍以第 0 格、全景扫描和对应层页为准。

## 汇总前先分清整层与子问题

1. 从材料里已经出现的角色、收入安排和客户类别逐个登记，不凭缺少细节增补一个未知角色。按第 0 格决定每条必问句用事前版还是事后版，再记录该问已有的材料原话和仍未知的子问题。已有的角色、行动、收费或交付安排是材料答案；尚未查实的金额、本人回应或后续结果单列未知，不能抹去已有答案。
2. 先按材料事实核对没站住的信号。信息未提供，不等于当事人已经答不上来，也不等于失败已经发生；命中信号时必须能指出对应原话或发生过的事实。没有这类依据，就保留未知子问题。
3. 对同一角色、收入安排或客户类别，只有该层五条必问句在材料里全无答案，才记未知。已有部分事前答案且没有命中失败信号，找到的部分记部分站住；其余问题逐项留在缺口清单，不把整层改成未知。找到事后答案时仍按全景扫描与层页的站住条件复核，未满足的部分不能升级为站住。
4. 多个角色、多档收入、多类客户分别判，再按全景扫描的既有顺序取最弱一环。若某个必要角色确实全无答案，指明是哪个角色及哪些必问句都缺；不借另一个角色的事实替它补齐，也不因为同一角色的一条问题未知，就把这个角色整层记成未知。分两行和回边待交回的规则保持全景扫描原口径。
5. 每个候选层分别留下整层状态、已知材料事实、未知子问题和候选原因。部分站住仍可按既有扫描与路由规则成为可能根因候选；候选成员不等于已查实根因，定根因仍需材料原话与层页信号相互印证。这些是内部记录，不原样写进给用户的回答。

登记已知事实时，同步注明它实际支持的对象、动作或交付责任、计费与重复使用安排、收入或客户入口归属，以及适用范围。把拟建议的对象和做法逐项对到这些记录；改变对象、责任或复用范围的部分仍是待证条件。只查到一个安排、一次回应或一种结果，不能直接写成另一条交易、长期使用或可重复交付已经成立。

本节只具体化全景扫描的状态判法与逐问记录，不增加报告之外的知识，也不替代各层必问句和信号。

## V1 为什么做：处境、约束与目标

**只回答**：做这件事是为了摆脱哪条约束，做成后必须贡献什么，被证明之前最多赔得起多少。

**必问**

1. 当初是为了摆脱哪条约束才做的？写成一句别人能反驳的话：主要受限于 X，而不是 Y。做到现在，哪些记录在案的事实支持它？出现过哪些对不上的事实？这条约束松了没有？
   - 还没发生时问：不做这件事，现在卡在哪一条上？卡的是生意、产品，还是你自己？写成一句别人能反驳的话：主要受限于 X，而不是 Y。靠哪几条事实成立？出现什么事实算你诊断错了？
2. 开始前写下的「做成算什么」是什么：给谁什么价值、靠什么有收入、到多大、多久之内？低于哪条线即使卖得出去也不算数？哪些成果不记到这件事头上？已经收到的钱和客户，对着这条线到了哪里？
   - 还没发生时问：做成了算什么？对你（或公司）来说，它要到多大、多久之内才值得继续做？低于哪条线即使卖得出去也不算数？哪些成果即使做出来也不记到这件事头上？这条线对的是你现在打算用的收费方式吗？
3. （换信息还是押注：第 0 格已答则引用，不重问。）刚过去这一轮，当初定的是花小钱换一条信息，还是押注去检验真有人用、换一家还成立？实际花的钱和用来考核的尺子，跟这个定位一致吗？
   - 还没发生时问：接下来这一轮，是花小钱换一条信息，还是押注去检验真有人用、换一家还成立？换信息的话，换哪一条？押注的话，前面哪几条已经有证据？
4. 这一轮开始前，写下过最多投多少钱、多少人时、对外许多少承诺吗？写的是多少、哪天写的？已经许出去、收不回来的承诺有哪些？
   - 还没发生时问：在那条线被证明之前，这一轮最多投多少钱、多少人时、对外许多少承诺？哪些不可逆的事明确不碰？
5. 开始前写下过什么情况就停、就调整、就把资源收回吗？原话是什么、哪天写的？结果出来之后改过没有？谁有权说停？
   - 还没发生时问：出现什么情况就停、就调整、就把资源收回？这条现在写下，还是打算发生了再议？谁有权说停？

**没站住的信号**

- 做这件事的理由只有趋势故事或「必须上某项技术」，说不清要摆脱什么约束。（G0 停止信号 185）
- 理由里只有想达到的数字（规模、份额、里程碑），没有「为什么现在达不到」。（C06 1214；C07 1224；B04 436）
- 诊断写不出会推翻它的事实，或只靠逻辑讲得通，没有客户、成本、竞争方面的事实。（B04 453；W01 1624）
- 说不出低于哪条线不算数；或给得出数，但它只是打平线，或只算在已否掉的收费方式上。（B00 245；B10 737；评审第六问 2004；后半句为推导）
- 说「继续投」却没说这一轮是换信息还是押注；投入没有上限；或继续的唯一理由是已经投了很多。（T01 1087；B02 300；B10 740；W16 1918；第一小句为推导）

## V2 做哪个：机会与取舍

**只回答**：为什么是这个机会而不是别的，靠什么赢，不做什么。本层过两次：初选只到候选与比较；定取舍要等 V3 交回「客户不买你时用什么」后，才定比较对象和不做清单。

**必问**

1. 除了现在这个方向，当时摆在桌上的还有哪几个？每一个输在哪一条上？
   - 还没发生时问：现在桌上有哪几个候选？你打算按哪几条比，凭什么认为这一个更好？
2. 把行业名和技术名拿掉，用一句话说：服务谁、在什么触发情境下、帮他完成什么、他在哪里会遇到你、替换掉他现在的什么做法？
   - 还没发生时问：同一句话按你的打算填。五格里哪几格核对过，哪几格是猜的？
3. 客户不买你时用的那个做法（取 V3 的结论，本层不重问），你比它好在哪一点？这一点客户自己能检查吗？另一种赢法你为什么没选？
   - 还没发生时问：你打算让客户拿你替换掉什么？凭什么认为他会这样比？你打算好在哪一点，他怎么自己检查？
4. 你拿来衡量成功的核心指标，是客户的结果还是你自己的成本？已有的客户是凭这一项选你的吗？
   - 还没发生时问：你拿来衡量成功的核心指标，是客户的结果还是你自己的成本？凭什么认为客户会拿这一项来选？现有做法在这一项上已经到哪了？
5. 你明确不做的是什么：哪类客户、哪种任务？最近一次真的放弃或拒绝的是什么（一个客户、一个请求、一笔生意），它保护了什么？
   - 还没发生时问：你打算不做什么：哪类客户、哪种任务？第一个不在范围内却找上门的，你拒吗，凭什么拒得掉？

**没站住的信号**

- 机会只来自一个人的偏好，或只来自第一个找上门的客户，没有写下来的备选。（187；484）
- 问「靠什么赢」，答的是目标数字、行业名或能力名词。（191；436。目标当诊断的幻觉归 V1）
- 候选机会每一条都是「低挑战、高潜力」，通常是把获客、采用、数据或完整成本藏起来了。（509）
- 比较对象是自己挑的对标或同类产品的宣传材料；或核心指标是自己的成本与能力参数，客户并不拿它来选。（881、1480、1035；后半句为推导）
- 声称聚焦，但不做清单为空，来的客户都收；或差异化四格只填了「增加」和「创造」。（447；520、1036；G3 191）
- 把几类客户或几个场景并排写，它们的输入、入口、付钱人各不相同，却没选主攻。（02 页症状表第 2 行；报告 472、970；推导；1576、1684）

## V3 谁的什么任务：真实需求

**只回答**：谁在什么情境下要完成什么，现在怎么凑合，凑合的代价是什么。本层只证「问题存在、旧做法有代价」，不证「用了你的解法他真的变好」，那是 V4 的事。

**必问**

1. 最近一次有人真的碰到这件事是什么时候？什么触发的？这段经历是他自己讲的、你看到的，还是别人替他说的？
   - 还没发生时问：还没接触过当事人时：你认为谁最近碰到过这件事？依据是你亲身经历、亲眼见过，还是推想？打算先找谁核实？
2. 那一次他实际怎么处理的？用了什么，花了多少时间、钱或人手，出了岔子怎么补？
   - 还没发生时问：你认为他现在怎么处理、花多少？这个数是查到的、看到的，还是你估的？
3. 没有你的产品，他下一次怎么办：继续人工、拖着、干脆不办，还是用另一类东西？旧做法哪一点不够好？既然不够好，他为什么到今天还没换？
   - 还没发生时问：你列的替代清单是问来的、看来的，还是自己想的？清单里有没有「拖着」和「不办」？你凭什么认为他愿意换？
4. 把产品名和功能名都拿掉，用一句话说：谁，在什么情境下，要把什么事推进到什么状态？这件事同一个人多久碰到一次？他认为怎样算做成？
   - 还没发生时问：一句话任务同事后版。频度和做成标准是当事人讲的，还是你估的？凭什么这么估？
5. 你见过的反例是谁：碰到同样情境却觉得旧办法够用的人，或者看完之后没要的人？原因记下来了吗？
   - 还没发生时问：你打算去找哪些可能觉得旧办法够用的人？事先写下：听到什么事实会改变你的判断？

**没站住的信号**

- 得到的只有泛泛赞美（「不错」「应该有人用」「肯定会买」），追不到实例、花费或优先级。（G2 停止信号 189；B19 641、650；D01 1512）
- 声称「没有替代」，却没核对过人工、表格、拖延、不办这些做法是否已经够用。（B07 563；B16 539）
- 需求是从技术用途直接推出来的，当事人一侧没有任何一条经历；或拿别人在这个品类的采购记录当成当事人有这个任务的证明。（G1 停止信号 187；1541；1553；后半句为推导）
- 更简单的现成办法已经把问题解决了。（1589 退出条件第一项）
- 频度和做成标准说不出，或只有团队的估数。（G2 189；判为没站住是推导）

## V4 解法成立吗：做得出，用了真变好

**只回答**：你的解法在不是自己挑的真实输入上做得出来吗；用的人用了之后，那件事真的比旧做法好了吗

**必问**

1. 拿一批不是你们自己挑的、用的人真会给的输入跑过吗？出了什么结果？哪些输入你们明说不接？
   - 还没发生时问：打算接哪些输入、明说不接哪些？手里有没有真实输入的样本（不是自己造的）？凭什么认为真实输入就长这样？
2. 最近一次出错或给不出结果时，用的人看到了什么？谁发现的，谁兜的底？
   - 还没发生时问：它总会在某些输入上出错。到时用的人会看到什么，打算由谁兜底？错了没被发现，后果落在谁身上？
3. 同一件事，让用的人用旧做法做一遍、用你的做一遍，再加一个更简单的办法，结果差在哪、差多少？是按他自己的做成标准量的吗？
   - 还没发生时问：打算拿什么和什么比、看哪个结果、基线从哪来？如果更简单的办法就够了，你打算怎么发现？
4. 从拿到输入到用的人拿到结果，哪些步骤其实是你们的人在做（准备、修、复核、救场）？用的人知道吗？
   - 还没发生时问：哪些环节打算先由人顶着？对用的人怎么说？人撤掉以后结果还成立，凭什么这么认为？
5. 你们的人不在场时，用的人自己从头做完过吗？开始前要他备好什么，中途在哪卡住、在哪求助？
   - 还没发生时问：打算让谁、在什么条件下自己走一遍？他要先备好什么，凭什么认为他备得出？

**没站住的信号**

- 只有演示或自己挑的样例，没有代表性输入测试（G6 停止信号 197）
- 答「都能支持」，写不出不接的输入；或默认输入总是齐全、合格（B06 500；W13 1863；G6 停止信号 197）
- 更简单的办法已经把事办了，或用的人没有净改善（退出条件 1589；由「简单信息卡」「消费者」通用化，推导）
- 把内部跑通当成用的人有效；「更好」量的是自己的指标，不是用的人的结果（B20 678；B24 943；B18 620；后半句推导）
- 有不告知的人工在顶着，对外称全自动（B08 592；1587）

## V5 谁付钱：购买与收费

**只回答**：谁掏钱，这笔钱从他现在哪项开支或哪种凑合里换出来，按什么单位收，价格证据到哪一步。

**必问**

1. 这笔钱最后是谁掏的？有没有另一个人能否决这笔支出？你和掏钱的人本人谈过钱吗？
   - 还没发生时问：打算让谁掏钱？有没有另一个人能否决？凭什么认为是他：接触过他本人，还是只接触过用的人？
2. 这笔钱是从他原来哪项开支或哪种凑合里换出来的？你的价是照那笔开支和他要的结果推的，还是照我方成本加的？
   - 还没发生时问：他现在为这件事花着什么钱、付着什么凑合的代价（取 V3 的替代清单）？哪一项他自己能停掉、把钱挪给你？打算定的价相对那一项是省、平还是多花？
3. 按什么单位收、多久收一次？付钱的人算得清下一期要付多少吗，对得上账吗？用得多的时候，他是觉得值还是开始限制使用？
   - 还没发生时问：打算按什么单位收、多久收一次？比过不止一种单位吗？按这个单位，他用得越多是越觉得值，还是越想少用？
4. 最近一次让掏钱的人看到写明的范围和价格是什么时候？他接下来做了什么？没推进的，原因是什么？
   - 还没发生时问：打算什么时候、用什么方式让掏钱的人第一次看到写明的范围和价格？在那之前，你凭什么认为他会付？
5. 已经收到的钱，是在什么特殊条件下收到的（试验性的钱、熟人、折扣、额外人工）？条件到期后，同一个客户还要不要，他做了什么？
   - 还没发生时问：第一笔钱打算在什么条件下收（免费、特价、熟人）？条件到期后，凭什么认为同一个客户会按正式条件继续要？

**没站住的信号**

- 把「应该会买」「肯定会买」计入了订单或收入。（G4 停止信号 193；B19 650；B09 711）
- 价格只由我方某一项成本决定，没对照掏钱的人的替代开支和他要的结果。（G4 停止信号 193，原话是模型调用成本，通用化为推导；B09 699）
- 只有用的人的好评，从没让掏钱的人看到过价。（B09 709；B19 650）
- 把试点费或首单当成正式购买的证明，说不出钱的性质；或用免费、特价试点推正式价格。（E3「尚不能证明」213；付费幻觉 1557；G7 停止信号 199；十步推演 1578）
- 掏钱的人明确表示不愿为这项收益付钱。（退出条件 1589）

## V6 从买下到用上：采用与获客

**只回答**：从买下到用上并持续用，中间要谁动手，谁没有理由动；客户从哪来，能不能重复来。

**必问**

1. 已经买下的客户里，从决定要到第一次真正用上、再到一直用，每一步是谁动的手？逐个点名：谁拍板、谁日常操作、谁能叫停、哪几步是我方替他做的。
   - 还没发生时问：你预计从他决定要到用上、再到一直用，要经过哪几步，每步谁动手？谁拍板、谁日常操作、谁能叫停？名单上哪些人你接触过，哪些是推断的？
2. 名单上每个人：实际多做了什么、得到了什么、担心什么？谁到现在没动，或者只有付出没有所得？
   - 还没发生时问：名单上每个人：要多做什么、放弃什么旧做法、能得到什么？你凭什么认为他会动：他已经做过有成本的事，还是你推断的？
3. 用上之前，哪些事等了别人先做完（对方准备数据或环境、第三方改接口、拿授权、平台放行）？等了谁、多久？这些事当初写的是已验证，还是以后再接？
   - 还没发生时问：用上之前，哪些事必须等别人先做完？每一项你去确认过、试过，还是默认齐备？哪几项可以去掉、换人或延后？
4. 已有的客户各是怎么来的：谁带来、经哪条通路、是不是靠创始人或私人关系？同一条通路带来过第二个吗？
   - 还没发生时问：第一批客户你打算从哪来：具体谁带来、经哪条通路？这条通路在谁手里，他凭什么愿意带？到现在有没有一次不靠你本人关系的接触？
5. 用上之后，这件事靠谁持续做什么才不断（更新资料、维护、再次打开）？这个人现在还在做吗，他凭什么一直做？
   - 还没发生时问：用上之后要谁持续做什么才不断？这个人是谁，他一直做下去得到什么？这一段你问过他吗？

**没站住的信号**

- 关键依赖全部标为「后续接入」。（G5 195）
- 要多干活的人没有回报：操作的人只有成本没有动力。（G5 195；C18 1360）
- 拿「整体对大家都有好处」当每个人都会动的理由。（C18 1358）
- 必要的操作者不愿配合，或关键输入无法合法取得。这两条是致命缺口，不被其他优点平均掉。（218；1589）
- 客户全是创始人或私人关系带来的，却按「通路已通」往下算；或说不出下一个客户从哪来。（G8 201「靠关系或创始人救场」；B12 819；W14 1882；后半句为推导）

## V7 换一家还成立吗：复制

**只回答**：换一个客户、换一个人来做，还成立吗；每多一个客户，我方多干多少活？

**必问**

1. 从上一个客户成交到他拿到结果，你们逐项干了哪些活，各花多少人时或钱？哪几项只有某一个人做得了？
   - 还没发生时问：打算每接一个客户要干哪些活？逐项列出来，各估多少、凭什么这么估？哪几项只有你或某一个人做得了？
2. 第一家（或第一批）给过你们哪些下一家不会给的交付便利：现成的数据、对出错的容忍、他们自己出的人手？
   - 还没发生时问：打算找的第一家，会给你哪些别人不会给的便利（数据、容错、人手）？去掉这些，你这边要多干什么？
3. 第二家是谁？它和第一家在输入、入口、付钱人上哪里一样？给它交付时多出了哪些第一家没有的活？
   - 还没发生时问：打算找谁做第二家？它和第一家在输入、入口、付钱人上哪里一样、哪里不一样？不一样的地方你要多干什么？
4. 标准范围内明说不支持哪些输入（格式、质量、规模、情境）？最近一次客户拿来范围外的，你们接了还是拒了？
   - 还没发生时问：打算明说不支持哪些输入？客户拿来范围外的，打算接还是拒，谁说了算？
5. 给同一个客户做第二次交付（或进入第二个使用周期）时，特殊工作比第一次少了哪些、新冒出哪些？
   - 还没发生时问：你估计哪些活只在第一次发生，哪些每次都要重来？凭什么？

**没站住的信号**

- 每接一个客户要干的活列不出，或清单里实施、支持、重做几行是空的或是零（W12 1839–1840；B10 738；判法为推导）
- 后一家的特殊工作清单不比前一家短，服务量随客户数同步增长（标准化幻觉 1556；W01 1622；W14 1886；4.2 规模经济核查 1022）
- 每家都要重建核心流程或重做核心交付（退出条件 1589；不能平均掉的致命缺口 218）
- 靠关系或某一个人救场，却对外称可复制（G8 停止信号 201，原话是「创始人救场却声称标准化」，通用化为推导）
- 答「都能支持」、没有不支持清单；或第二家只说得出「同一个行业」（W13 1863；B12 826；B21 855）

## V8 够不够大；守不守得住

**只回答**：做成之后够不够大；别人或更便宜的通用能力跟上来之后还剩什么。

**必问**

1. 〔够不够大〕这件事要到多大才算数？（尺子取 V1 的贡献线。）按它倒推，要多少客户、多大客单、多高留存、多大的销售和交付能力？这几个数哪些是实测，哪些是假设？
   - 还没发生时问：你打算用哪条线判够不够大？按它倒推的每个数各凭什么这么填？哪个数最没把握、一变账就不成立？
2. 〔够不够大〕倒推出来的客户数，在你现在够得着、对方买得起的范围里数得出来吗？是自下而上一个个数出来的，还是总量乘一个比例？
   - 还没发生时问：你打算先卖给哪一批？这一批里现在点得出来、够得着、买得起的有多少？首个切口和远期市场分开写了吗？
3. 〔够不够大〕客户多起来之后，每个客户的贡献和交付质量是变好还是变差？最近一批和前一批，用同一来源、同一版本、同一时间窗比过吗？价格降、成本升、回款变慢各算一遍，账还成立吗？
   - 还没发生时问：客户数成倍增加时，哪些成本跟着客户数涨，哪些会被摊薄？凭什么这么认为？价格降、成本升、回款变慢三种情形各算过吗？
4. 〔守不守得住〕假定你的核心能力明天就被对手或更便宜的通用能力拿到，现在的客户为什么还选你？答案要落到结果可靠性、数据权利、渠道、流程、成本里的具体一项。
   - 还没发生时问：V2 写下的「靠什么赢」，在别人也有同样能力之后还剩哪一项？凭什么这么认为？
5. 〔守不守得住〕剩下的这一项：好处怎么测？对手是不能跟还是不愿跟，证据是什么？多出来的钱最后落在客户、供应方、渠道、关键人才还是你手里？客户随时能走的话，他还留下吗？
   - 还没发生时问：你打算靠的这一项：好处准备怎么测？凭什么认为对手不能或不愿跟？相关的数据、渠道、关键供给的权利现在在谁手里？没有锁定时客户凭什么留下？

**没站住的信号**

- 【够不够大】规模论据只有注册数和合同数，没有贡献、现金、续用的数据；或预测收益依赖未经证明的低成本、高续费和无竞争。（G9 停止信号 203）
- 【够不够大】够大的理由是「行业很大、在增长」，拿不出可达客户、预算和价值分配分析。（市场幻觉 1554；张力表 1549；B21 854）
- 【够不够大】客户越多，每客户贡献或交付质量越差；或新增客户反而增加大量服务。（4.2 规模经济 1022；G9 继续理由的反面 203）
- 【守不守得住】优势论据是资源名称（有某项技术、有数据、先做的），说不出收益、屏障、权利归属和持续时间。（护城河幻觉 1558；W15 1899；4.2 1018）
- 【守不守得住】「对手不会跟」拿不出不能或不愿的证据；或客户留下靠的是导出困难、合同绑定。（4.2 反向定位 1024；B13 358；B23 912；张力表 1548）
