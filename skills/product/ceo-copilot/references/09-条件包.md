# 跨层条件包

> 由第 0 格一次判定是否加载。各层页里只留一句指针。

## 包一：付钱的人和用的人不是同一个

**触发**：第 0 格问「谁掏钱、谁批准、谁每天动手、谁最后用上」，答案里出现不止一个人或角色时加载（企业买给自己的人用、企业买来交给自己的客户用、使用者免费由另一方付钱）；四个位置是同一个人时不加载。来源：W08 1758；术语 2013；触发句的通用化为推导。

**核心判定**：四条同时成立才算站住，缺任何一条整体不站，不取平均（150；218）：①用的人有真实任务收益（查 V3、V4）；②付钱的人有购买并推动采用的动机（查 V5、V6）；③我方能以可控成本重复交付（查 V7）；④可达市场与贡献够得上 V1 定的那条线（查 V8；原文是「公司的新增长目标」，换成 V1 贡献线为推导）。配套三条：同一次小范围真实运行里同时看到付钱方的支付或承诺、使用者的任务结果、我方的服务成本（G7 199；B11 769），由闭环检查执行；一方的好处不能替代另一方的好处（W06 1718），两者只有验证出因果联系才能连成一句（1569）；role_rule：每层必问句对每个角色各问一遍，本层状态取最弱的那个角色（206、218；「取最弱」为推导）。

### 薄在哪

- 语境写死在「企业买来交给自己的客户用」：企业买给自己员工用、双边市场、个人之间付用分离（家长给孩子买）怎么画链，报告没给；本包的通用化都是推导。
- 净收益没有算法：W09 只有「哪一环净收益为负」一个字段（1782），时间、钱、风险怎么折到一起比没写；C18 明说没有数字（1362）。
- 「愿意行动」没有判定：G5 只写「必要伙伴愿意行动」（195），只能借 E3（213）和四类承诺（642），对应关系为推导。
- 否决者只被点名（766、1003），怎么识别、怎么处理没有。
- 两端的因果联系怎么验证：只有「后续验证中发现因果联系」一句（1569）和任务对照一段（1586），没有方法，也明说不给通用样本数。
- 多个付钱方时取最弱、每层按角色取最弱，这两条记法是推导；报告只有「不能平均掉致命缺口」（218）。
- 第四条依赖 V1 的贡献线，而这条线怎么定报告没有方法。
- 真正到机制级的多方采用案例缺位：C17–C19 都没有各环节得失的具体情节。
- 尺子外·获客与增长引擎怎么建：渠道怎么招、分成怎么定、入口方怎么谈，报告只有 415、819 两句，本包只查「入口方有没有理由动」。
- 尺子外·合规：数据授权、隐私、对使用者的责任，本包只问「权利归谁、是否默认已授权」，其余由相应专业人员核验（218）。
- 尺子外·面向个人消费者的产品：使用者是个人消费者时，他的留存、习惯、口碑、品牌没有题源，本包只查「他有没有真实任务收益」。
- 尺子外·竞争动态：入口方或付钱方自己下场做、对手抢入口之后怎么办，没有题源。
- 尺子外·验证期之后的经营：渠道冲突、分成重谈、大客户依赖，没有题源。

## 包二：有旧业务

**触发**：第 0 格问「现在有没有一门在收钱的生意」答有，并且新事与它共用人、钱、客户、渠道或代码中的任何一样，或新事的成果要和它合在一张账上汇报时加载；从零开始、没有在运营的生意时不加载。来源：147；G0 185；判定句为推导。

**核心判定**：报告没有现成的一句合取句，下面四条合在一起是推导，各条有来源。四条同时成立，有旧业务时的 V1 才算站住，缺一条即不站（不取平均是把 218 用到本包，为推导）：①旧业务卡在哪，写成了可反驳句，并有过去几个可比周期的事实和反证（G0 185；W01 1621–1624；B04 444）；②两类成果分开记：改进旧业务算一类，形成另一套可复制的购买与交付机制才算新生意，同一笔成果不记两头（B01 271；W01 1627；280）；③每项共享有所有者和边界，每项独立有对应责任（W03 1657），不能一边要求探索一边随时把人借回去（B00 246）；④考核和奖励与这一轮所处的阶段、与声称要做的事一致（B03 329；T02 1097；B04 446），比对由闭环检查执行。

### 第 0 格（全景扫描第一步）

多问：
- 现在有没有在收钱的生意？新事和它共用什么：人、钱、客户、渠道、代码？｜事前版：同事后版。
- 做事的人和批资源的人是同一个吗？新事做成会不会减少旧收入？这件事是不是被叫作第二曲线或新增长？｜事前版：同事后版。

多出来的信号：
- 答「协同」，但说不出共用的是哪几样（B01 273；张力表 1546）。
- 三问各开一组内容：共用资源开「共享与隔离」；做事与批资源分开开「孵化章程」；会吃旧收入开「自我替代」（分法为推导）。

### V1（G0 原版问法）

多问：
- 旧业务卡在哪：需求、获客、价格、交付成本、复用性、回款六方面，过去几个可比周期各变了什么？每新增一个客户多出哪些非标准工作？｜事前版：同事后版（旧业务的事实已经发生）。

- 逐项列：哪些共用（技术组件、数据经验、品牌信任、客户接触），哪些必须隔离（销售提成、定制承诺、交付排期、架构分支）？共用的每一项谁是所有者、成本归谁、排队谁优先、冲突找谁？｜事后版：上一次新事的人被借回旧项目，是谁决定的、走了哪条规则。｜事前版：被抽调规则写了吗，谁有权说不。

多出来的信号：
- 把旧业务降本记成新生意成立（B01 280、271）。
- 一边要求探索，一边随时把人借回旧项目；缩减不是一次明确的投资决定，而是各部门在日常排期里各抽一点（B00 246；C16 1336）。

- 叫它第二曲线，其实只是第二个产品发布，或还只是小额换信息的早期选项（术语 2012；T01 1087）。
