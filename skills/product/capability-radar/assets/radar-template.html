能力雷达 · 数据驱动
数据格式与使用说明

导入 JSON，或在“编辑数据”中修改后应用。能力名称直接显示在雷达上；点击能力可查看完整证据。导入只更新当前页面，不会修改原始文件。请导出 JSON 保存数据；“保存 HTML”会将当前数据嵌入新页面，重新打开或发送给老板时直接显示这一版。

字段作用
title / date / centerLabel图标题、数据日期和导出文件名前缀（不画在图上）
domains能力域数组；顺序决定扇区排列。省略时按首次出现的 group 排列
capabilities[].id / group / name稳定编号、能力域、完整能力名称
shortLabel图上最短说明。最多 20 个字符；省略时使用 name
status只能为“已具备”“确定能做到”“可能做到”；决定圈层
summary图上限制摘要，最多 32 个字符。省略时不自动摘要
proof / limits / input / output完整证据与限制，点击能力后查看
subtitle / note / source图内说明、证据边界和来源名称

支持 1–8 个能力域、1–24 项能力。文字保持水平。每张卡片整体落在自己的圈层和能力域内，圈层按需自动放大；边框颜色表示三档状态。程序检查标签碰撞；无法清晰排布时拒绝更新，保留上一版，不隐藏能力。

编辑能力数据

名称写明“能做什么”；summary 保留关键限制。状态只由数据决定。
