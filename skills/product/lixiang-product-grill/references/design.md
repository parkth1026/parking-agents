# design: lixiang-product-grill

## 意图与触发场景

把《李想·产品实战16讲》（同作者完整课程，自带案例弹药）的方法论变成一把固定尺子，以逐题访谈（拷问）的形式检验当前产品：每个维度先亮出李想的原文标准（逐字引文＋讲次），再引用用户已表达过的思考对照，只对缺口提问，追问带 wiki 弹药（案例链与推理过程），最终产出 14 维度符合度裁定（符合/部分符合/缺失/冲突）、层间断裂点与有理有据的推荐报告。

**触发模式：名字触发**——description 严格字款式（只写名字中英双语，剔除 name 后 ≤16 字符）：`lixiang-product-grill / 李想产品复盘`。用户点名技能名（英文或中文「李想产品复盘」）才触发；旧习惯短语「用李想方法论盘一下」与旧名 lixiang-ceo-grill 点名＝负例（trigger-evals 显式收录）。

**触发评测结论（2026-10-05，用户裁决 A）**：正例 7/7 全中（test/train trigger_rate 均 1.00），点名触发可靠；负例误触发实测 test 0.20——旧习惯短语（q08，语义上即明确的李想复盘请求）、旧名点名（q09/q10，路由器近似名匹配）、16 讲内容总结（q15，archive 内置于技能吸引内容请求）四题被探针一致路由到本技能，契约噪声口径单题重跑一次不翻转，description 字款式杠杆对意图路由无效。**用户裁定接受现状**：benchmark 如实记录 1.00/0.20，误触发 0 门槛改按残留风险在案处理——「旧短语不触发」仅在用户点名习惯侧成立，不在路由器侧成立；旧短语触发本技能得到的是 16 讲复盘（语义正确的服务，非事故）。

产出形态：对话内的逐题访谈 + 最终符合度报告（可选落盘）。

## 尺子架构（整尺更换）

前身 lixiang-ceo-grill 以李想创业公开课单篇提炼的「三层九模块」为尺，与用户日常产品决策（定价/体验/复盘/节奏）错位。本次整尺更换：14 维度逐字锚定 16 讲原文，旧九模块题库移除（git 历史留底），旧公开课文章仅附注保留（见 AC-7）。

三模块层序固定：产品战略（定位/品牌/文化/产品标准/团队标准）→ 从0到1（体验/用户/技术/定价）→ 从1到10（复盘/节奏/流程/门店/利润），禁止反向——李想的依赖方向是战略决定产品、产品验证进规模。

## wiki 运行时角色（与 ceo-copilot 相反）

ceo-copilot 的 wiki 是维护层（运行时不读）；本技能的 wiki 是**运行时弹药层**：每个维度复盘必读对应 S 页（sources/），取案例链与推理过程给追问加重量（门店市占 8 倍、成本 20%→5%、3% 入场券等）。**裁定唯一依据仍是题库标准句**，wiki 页不含裁定措辞（run-tests [wiki 结构] 组断言「合格线」「裁定」字样缺席——validate-wiki.mjs 无此维度，由本技能测试单拦）。增益方向经 output 三臂对照（with_skill / with_skill_no_refs / without_skill）首次测量。

## 设计取舍

| 决定 | 自由度 | 为什么没选别的 |
| --- | --- | --- |
| 固定题库（14 维度 × 六要素），按三模块固定顺序走 | 低（题库锁定在 question-bank.md，不许现场发明维度） | 方法论复盘的价值在「尺子固定」，现场生成问题会漂移成普通访谈 |
| 标准句逐字锚定 16 讲原文＋讲次（双跳 substring：题库 ⊂ S 页引文 ⊂ archive 原文） | 低（纪律锁定） | 逐字锚定防「转述漂移」——尺子一旦掺入转述，裁定依据不可复核 |
| wiki 运行时赋能：每维度读 S 页 | 低（协议锁定） | 用户裁定推翻 slim 方案：「用 wiki 不是为了省 token」；增益由三臂对照补偿验证 |
| 引用无限制：19 篇原文全文入仓（archive raw 层，字节同源） | 低 | 用户裁定个人仓无限制；残留风险（付费内容 git 历史永久化）在契约在案 |
| 角色＝方法论镜子：先逐字引用用户已表达过的思考对照标准，只对缺口提问 | 低（协议锁定） | 用户裁定 2026-09-23（沿袭前身）：核心是引用用户怎么思考，纯拷问姿态产出对抗不产出补全 |
| 一次只问一个问题，问完即停 | 低（协议锁定） | 一次一问是用户点名的形式；追问才逼得出具体答案 |
| 提问写在对话正文，不使用带选项面板的结构化提问工具 | 低 | 选项面板放不下原文标准、用户原话引用与对照结论；答案是开放论证，不是选择题 |
| 每条推荐必须有理有据：差距＋依据（16 讲原文＋用户证据）＋影响＋推荐强度与最小动作 | 低（格式锁定） | 推荐方向无依据等于没说 |
| 事实自己查（repo / wiki / web），判断才问用户；用户原话逐字进事实底座 | 高（文字指令） | 让用户复述文件里已有的东西是浪费复盘火力 |
| smart-skip 默认激进：材料已能对照的项先出示对照裁定请确认，只对覆盖不满的项发问 | 低 | 用户裁定（契约变化行 4）：不重走空流程 |
| 名字触发（严格字款式 description） | 低 | 用户裁定换点名习惯；旧短语与旧名＝负例，干净断裂无别名兼容 |
| 打包出口精确排除 references/archive/（精确路径匹配，不用全局目录名） | 低 | 分发版不含付费课程全文；全局目录名匹配会波及其他技能同名目录 |

## 验收条件

| 编号 | 条件 | 类型 |
| --- | --- | --- |
| AC-1 | 题库 14 维度：六要素齐全、标准句逐字＋讲次、三模块层序严格递增、文件头 TOC、每维度 S 页指针 | script |
| AC-2 | 原文存档（archive）：19 篇、讲次命名、溯源头三字段（来源仓/抓取日期/仅个人使用）、字节同源 | script |
| AC-3 | wiki 完整性：sources=19、concepts/cases 各 ≥12、断链 0、frontmatter 硬门、总分 ≥9.0（validate-wiki.mjs）；wiki 页不含裁定措辞 | script |
| AC-4 | 访谈协议要素：13 要素齐（一次一问/证据三级/裁定四档/层间依赖检查/拆开逐问/示例回合/引用你的思考/对话正文提问〔新措辞〕/合理答案判据/校准式认可/复述成/开场菜单倒序/smart-skip 激进） | script |
| AC-5 | 报告模板：14 维度×三模块矩阵、五断点、前三差距、推翻条件、「你是怎么思考这个产品的」节、推荐四要素 | script |
| AC-6 | 主观复盘质量（引用是否逐字、追问是否逼出具体证据、红旗是否点名）由人工评审，不做脚本断言 | manual |
| AC-7 | 附注护栏：旧文章头部非尺子声明＋退出运行时加载清单；黑名单三文件缺席断言（旧九模块名 9 词＋签名句 5 串，含 carve-out 降级） | script |
| AC-8 | 触发面：trigger-evals 题面锁（正例 ≥6、负例 ≥13 含旧短语与旧名点名、邻域题、exact_string）＋真跑 trigger_rate_on_should=1.0 且误触发 0 | script＋eval |
| AC-9 | 五件套：trigger-evals.json、output-evals.json、run-tests.mjs、trigger-benchmark.json、history.json 齐全；output 三臂真实链跑通（bank_epoch 2） | script＋eval |

## 黑名单降级记录（carve-out 执行）

强约束黑名单＝旧九模块名 9 词（行业趋势/行业问题/进攻方向/用户定位/时间节奏/目标要求/业务架构/在线系统/运营系统）＋签名句 5 串（认知决定战略，战略决定业务/量变带来质变/独一无二的资质/高保真映射/闭环），作用于 question-bank.md、SKILL.md、web-prompt.md 三文件，逐词逐串断言。

carve-out（2026-10-05 实测，grep 19 篇 archive）：

- 「目标要求」命中 11 讲 1 篇、「闭环」命中 01/06/12 讲 3 篇——16 讲原文本身使用这两个词，题库逐字引用不受限（12 讲节奏标准句合法含「最小的商业闭环」）。断言实现里这两个词**降级为长串组合**：「目标要求」→「模块 6：目标要求」「时间节奏、目标要求」两组合串；「闭环」→「每个运营环节必须形成闭环」「运营体系必须是闭环」（旧公开课签名句原文）两组合串。其余 12 词/串在 16 讲原文零命中，维持裸词/裸串断言。
- 降级决定随断言落地于 run-tests.mjs [附注护栏] 组。

## archive 选篇取舍

19 篇＝16 讲正课＋发刊词＋2 篇加餐。加餐消歧以 00-目录 说明节为准：「共 19 个正文文件：16 讲正课 + 发刊词 + 2 篇加餐（工具手册、产品奖学金）」——加餐 2 篇＝`学习之前，来领取工具手册（仅限已购用户）.md`（工具手册领取页）＋`产品奖学金任务开启，邀你来挑战.md`。未入选 4 项：`00-目录.md`（存档元数据页，非正文）、`《李想·产品实战16讲》工具手册.md` 与 `《李想·产品实战16讲》工具大地图.md`（PDF 附件的视觉转录件，非课程原文逐字稿——逐字锚定以 16 讲正文为准）、源目录 pdf 原件（与转录件重复）。全清单与逐篇溯源见 `references/archive/README.md`。
