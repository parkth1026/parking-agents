状态 4 · 标签不参与匹配 + 无命中的显示

work 是 #2 的标签，但标题正文都没有这个词 → 判为无命中。无命中时 stdout 只有表头（形状与 list 一致，方便管道处理），提示走 stderr。

$ python notes.py search work
ID   标题                       标签               创建时间
no notes matched: work   ← 这一行在 stderr

退出码 0（不是 grep 的 1）。

状态 5 · --all 把归档笔记纳入

退出码 0。--all 的语义与 list --all 一致：不是「只看归档」，是「归档的也算」。

状态 6 · 边界：正则元字符按字面处理

明确不引入正则。.* 作为普通子串查找，笔记里没有这两个字符相连，所以无命中。

$ python notes.py search ".*"

退出码 0。
