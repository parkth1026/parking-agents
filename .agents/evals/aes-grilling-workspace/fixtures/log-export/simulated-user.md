# 模拟用户画像(测试专用,是回答访谈问题的唯一依据)

角色:运维工程师,定期把服务日志导出给数据分析同事。原话是"导出功能太难用了,帮我改进一下"。

## "难用"的真实含义(用户心里清楚,但不会主动一次说全,问到才答)

- 最痛的点:每次都导出全部日志,又慢文件又大。想要按日期范围过滤:`--from` / `--to`,含当天,格式 YYYY-MM-DD。
- 第二痛:输出路径写死成 export.csv。想要 `--output` 指定路径;**不传时必须保持现在的默认路径和文件名**,别的脚本依赖它。
- 编码保持 UTF-8 不变;CSV 列名和列顺序不能动,下游是按列位置解析的。
- 无法解析的日志行:保持跳过,但希望结束时把跳过行数统计打到 stderr。
- 明确不在本次范围:压缩、自动上传、按日志级别过滤(以后再说)。

## 决策风格

配合但有主见。对推荐项大多接受;**在验收标准逐条裁决阶段一定会动手:至少改写一条 AC 的措辞,并主动补充或删除一条**(如果访谈方没问到"跳过行统计",就在这里补)。回答歧义问题时一次答完。
