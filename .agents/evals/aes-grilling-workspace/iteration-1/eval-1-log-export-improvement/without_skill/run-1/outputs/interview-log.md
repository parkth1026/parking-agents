## 第 2 轮 —— 助手提问

明白了,范围很清晰:加 `--from`/`--to` 日期过滤 + `--output`,默认行为完全不变,跳过行数打到 stderr。还剩几个边界情况,以及一份验收标准草案请你逐条裁决。

**边界情况**
1. `--from`/`--to` 可以只传其中一个吗?(只传 `--from` 表示"从该日期起全部"?)
2. 日期格式非法(比如 `2026/08/01`)时怎么处理?我建议:打印错误到 stderr,非零退出码退出,并且不写/不覆盖输出文件。可以吗?
3. `--from` 晚于 `--to` 时怎么办?报错退出,还是导出空文件(只有表头)?
4. 跳过行数为 0 时,stderr 还要打印统计吗?被日期过滤掉的行算不算"跳过"?(我的理解:不算,"跳过"只指无法解析的行。)
5. 现在结束时 stdout 会打印 `exported N rows -> 路径`,这个要保留吗?

**验收标准草案(请逐条裁决:通过 / 改措辞 / 删除,也欢迎补充)**
- AC1:不带任何参数运行时,行为与现有脚本完全一致——读取脚本同目录 `logs/*.log`,输出到脚本同目录 `export.csv`,UTF-8 无 BOM,总是覆盖,表头与列顺序为 `timestamp,level,message` 不变。
- AC2:`--from YYYY-MM-DD` 只导出时间戳不早于该日期的行(含当天)。
- AC3:`--to YYYY-MM-DD` 只导出时间戳不晚于该日期的行(含当天)。
- AC4:`--from` 与 `--to` 可单独或同时使用;同时使用时导出两端闭区间内的行。
- AC5:`--output PATH` 将 CSV 写到指定路径;不传时默认路径与文件名不变。
- AC6:脚本结束时,将无法解析而被跳过的行数打印到 stderr。
- AC7:日期参数格式非法时,打印错误信息并以非零退出码退出,不写出/不覆盖输出文件。
- AC8:仍为单文件脚本,仅用 Python 标准库;`--help` 能显示用法说明。
- 范围外(本次不做):按级别过滤、压缩、自动上传、GUI、配置文件、日志目录参数化。
