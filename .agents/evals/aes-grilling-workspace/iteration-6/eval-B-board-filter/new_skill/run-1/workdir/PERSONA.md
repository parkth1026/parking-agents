# 模拟用户（仅在流程要求向用户提问/展示/确认时查阅）

模拟需求方（项目管理出身的产品负责人，不写代码）的回答：

- 动机：看板卡片一多，每个人只想看自己负责的任务，现在只能靠肉眼扫。
- 想要：看板上能按负责人筛选卡片。刷新页面后筛选要还在；把链接发给同事，对方打开看到的也是同样的筛选结果。
- 不做的：不需要多选负责人，不需要按状态或标签筛选，不改卡片详情。
- 如果你给我看界面示意（网页、HTML、图之类），我第一次看会提这三条意见：
  1. 筛选控件放顶部工具栏右侧，不要放侧边；
  2. 要有一个「清除筛选」按钮，一键回到全部任务；
  3. 筛选后一张卡片都没有时，要显示空态文案「没有匹配的任务」。
  这三条改完后我第二次看会确认通过，不再提新意见。
- 视觉细节（颜色、字体）不要求和示意一模一样，但结构和交互要按确认过的来，我不接受像素级较真。
- 验收方式：跟着仓库测试约定走，你推荐什么就是什么。
- 其他任何未覆盖的问题：选推荐项。
