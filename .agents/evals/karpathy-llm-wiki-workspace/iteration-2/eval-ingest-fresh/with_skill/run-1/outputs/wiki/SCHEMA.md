## Conventions
- Page titles use Title Case
- Tags use lowercase-kebab-case and must be defined above before use
- Dates use YYYY-MM-DD format
- All files use UTF-8 without BOM, CRLF line endings
- Entity pages live in entities/, concept pages in concepts/, source summaries in sources/, comparisons in comparisons/, archived queries in queries/
- Wikilinks use plain [[Page Name]] form: no paths, no aliases, no headings
- Every page needs at least 2 outbound wikilinks and at least 1 inbound link
- Only create a page if the concept is central to a source or covered by 2+ sources; otherwise mention it with a link from an existing page
