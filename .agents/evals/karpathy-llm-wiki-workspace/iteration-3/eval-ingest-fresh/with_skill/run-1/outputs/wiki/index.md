## Concepts

- [[Large Language Model]] — neural network trained on internet-scale text to predict the next token; the wiki's core object
- [[Pretraining]] — stage 1 of training: next-token prediction over internet-scale corpora produces a base model
- [[Fine-tuning]] — stage 2 of training: small high-quality datasets (SFT, RLHF) turn a base model into an assistant
- [[Emergent Capabilities]] — abilities (arithmetic, multilingual translation, reasoning) that appear only as models scale
- [[Tool Use]] — LLMs run in a loop calling browsers, calculators, and code interpreters
- [[System Prompt]] — custom instructions that steer an assistant's behavior across a conversation
- [[Jailbreaking]] — adversarial prompts that bypass a model's safety guidelines
- [[Prompt Injection]] — instructions planted in data the model reads, hijacking tool-using LLMs
- [[LLM OS]] — Karpathy's vision of LLMs as the kernel/CPU of a new kind of computer
