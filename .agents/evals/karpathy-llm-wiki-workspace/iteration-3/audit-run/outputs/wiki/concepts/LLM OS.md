# LLM OS

Karpathy's metaphor for the future platform: an LLM as the CPU of a new kind of computer.

## How It Works
The model (kernel) coordinates peripherals — browsers, tools, file systems — via [[Tool Use]], with context window as RAM and [[Next-Token Prediction]] as the instruction loop.

## Significance
Popularized by [[Andrej Karpathy]] in the [[Karpathy Intro to LLMs Talk]] as the organizing picture for where agentic AI is heading.
