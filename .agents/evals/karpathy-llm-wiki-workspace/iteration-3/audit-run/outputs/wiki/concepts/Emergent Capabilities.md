# Emergent Capabilities

Abilities (in-context learning, multi-step reasoning) that appear abruptly once models cross a scale threshold, rather than improving smoothly.

## How It Works
[[Next-Token Prediction]] trained at [[Pretraining]] scale yields qualitatively new behavior no small run exhibits; the [[Karpathy Intro to LLMs Talk]] cites this as why capability jumps surprise observers.
