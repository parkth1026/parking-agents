# Karpathy Intro to LLMs Talk

> Author: Andrej Karpathy | Year: 2023 | Type: Talk

## Key Takeaways
- An LLM is fundamentally a next-token predictor trained on internet-scale text — see [[Next-Token Prediction]]
- Training happens in two stages: large-scale [[Pretraining]], then targeted [[Fine-Tuning]]
- Capabilities such as in-context learning appear abruptly with scale — [[Emergent Capabilities]]
- Assistants gain reach through [[Tool Use]] and behavior steering via [[System Prompts]]
- The same interfaces create attack surface: jailbreaks and [[Prompt Injection]]
- Karpathy's long-term picture is an operating-system-like agent — [[LLM OS]]
