# Attention Mechanism

> Stub reconstructed 2026-08-18: the wiki log records this page as created during the 2026-08-10 ingest, but the file was missing. Expand with content from the original source.

## Core Idea
Attention computes weighted relationships between elements of a sequence, letting each token draw on relevant context regardless of distance.

## Role In Transformers
Stacked self-attention layers built on this mechanism let the [[Transformer]] process all tokens in parallel, replacing recurrence.
