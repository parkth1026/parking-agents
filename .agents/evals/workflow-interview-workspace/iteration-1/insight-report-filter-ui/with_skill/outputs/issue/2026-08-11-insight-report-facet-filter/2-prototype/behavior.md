## 不变清单

- 报告生成命令、全部既有 CLI 参数（`--data-path`/`--output-path`/`--title`/`--facets-path`/`--narratives-path`/`--turns-path`）与控制台输出逐字节不变；只有输出 HTML 文件的内容变化。
- 报告仍是零外部依赖单文件：新增的下拉框逻辑全部是内联 CSS/JS，不引入任何第三方库、不发起网络请求。
- 每个 `sec-*` 区块自身的 DOM 结构、`id`、内部内容排布保持原样；筛选是叠加在外面的一层显隐控制，不改造区块内部实现。
- 左侧既有的 `nav-toc` 抽屉锚点导航（点击跳到 `#sec-*`）继续保留、继续可用，两者不互斥——用 nav-toc 跳转到一个当前被隐藏的区块时，浏览器锚点跳转本身不会自动取消 `hidden`，这属于 Agent-owned 实现细节（可以让锚点跳转顺带触发一次筛选切换），不改变本对照表已锁定的可观察行为，因此不再单独发起一轮确认。
- 未被选中的 facet 内容依旧完整保留在 DOM 里（不是从数据源层面裁剪或不生成），只是视觉与"直接可见性"上被隐藏。
- `generate-quant-report.js`、`generate-qual-report.js` 两个兄弟报告脚本本次不动，继续保持整页排列的旧行为。
- 已经生成在磁盘上的历史报告文件不会被这次代码改动追溯修改；只有重新运行生成命令产出的新报告才带有筛选功能。
