# design: log-line-counter

## 意图与触发场景

为日志或纯文本文件生成可复现的 Markdown 行数报告。用户要求统计总行数、空行数、非空行数，或给出 `.log`/`.txt` 路径并要求 Markdown 汇总时触发。

## 设计取舍

- 用零依赖 Node 脚本锁定计数与输出格式，因为行尾和末尾换行语义需要确定性。
- 同时支持 LF、CRLF、CR，因为日志可能来自不同操作系统。
- 把空行定义为零字符行；仅含空格或制表符的行保留为非空行，避免隐式修改原文语义。
- 用严格 UTF-8 解码拒绝损坏文本，因为替换字符会掩盖输入问题。
- CLI 同时支持 stdout 和显式输出文件，以适配对话返回和产物落盘两种用法。

## 验收条件

| 编号 | 条件 | 类型 |
| --- | --- | --- |
| AC-1 | 对有效 UTF-8 输入准确输出总行数、空行数、非空行数，且三者满足总行数等于空行数加非空行数 | script |
| AC-2 | LF、CRLF、CR 及混合行尾按同一物理行语义计数，末尾行分隔符不额外增加一行 | script |
| AC-3 | Markdown 使用固定标题和三行指标表，可写文件或输出到 stdout | script |
| AC-4 | 空文件输出三项均为 0；空字符串行与仅含空白字符的行按已声明语义区分 | script |
| AC-5 | 输入缺失、不可读或不是有效 UTF-8 时非零退出且不声称成功 | script |
