# design: ue-log-analysis

## 意图与触发场景
UE 打包版/编辑器运行日志（`Saved/Logs/*.log`、`-ABSLOG` 产物）没有结构化体检工具：
帧号、时间戳、错误、空窗这些判活信号散落在几十万行文本里，肉眼 grep 效率低且易漏。
本技能把「判活 → 定位卡点 → 错误分组 → 噪声聚合」的确定性部分交给脚本，领域知识与
分析工作流放 references，agent 只负责根因综合。

触发场景：
1. 用户给出 UE 运行日志文件/目录，反馈"卡住/崩溃/GPU 占用归零/掉帧/黑屏/打包后异常"
2. 用户要求分析 UE 日志时间线、帧率走势、错误分布
3. 多份日志需要判断是否同因复现

不适用：Jenkins 构建日志（编译/链接错误）→ 用 `ue-error-solver`；纯通用文本错误频次
统计（无 UE 帧号特征）→ `log-error-summary` 亦可。

## 设计取舍
| 决定 | 为什么没选别的 |
| --- | --- |
| 脚本只解析、不解读：输出结构化事实（帧停滞/空窗/错误分组），根因综合交给 agent（按 method.md 走） | 根因依赖工程上下文，锁进脚本会过拟合；与 log-error-summary「只统计不解读」同口径 |
| 帧号是第一判活信号，脚本围绕它设计 | UE 特有信号（`[N]`=游戏线程当前帧），通用日志工具不认识；帧 0/停滞/增长三态直接区分"未出帧、卡死、存活" |
| 错误口径复刻 log-error-summary（error 字样大小写不敏感、数字/引号归一、签名 ≤80 字符） | 同一份日志两个技能计数可对账；不 import 对方——技能独立分发，无跨技能运行时依赖 |
| 多行消息续行（无时间戳前缀）挂到最近带前缀行参与 noise 聚类 | ensure/callstack 续行刷屏会污染聚类，又不能直接丢（属于错误块的一部分） |
| 时间用当日内偏移毫秒，跨天按秒顺延 | 引日历库不值当；UE 单进程跨天日志罕见 |
| 多日志同因判定分层：错误谱一致仅为候选，存活份作反例排除共同病灶，致死候选=卡死份独有模式 | iteration-1 评测实证：「错误谱一致→同因复现」的老规则在人写报告与基线 run 上系统性给出误导判定（把全份共有的性能债 PROJ 列为修复第一优先，而存活份 PROJ 更重却出帧）；求异法推理原本靠 agent 临场发挥，不可复现 |
| 零 npm 依赖，`.mjs` + Node 内置模块 | 仓库族级标准（Windows Git Bash + Node v24） |

## 验收条件
| 编号 | 条件 | 类型 |
| --- | --- | --- |
| AC-1 | `frames` 输出帧 0 行数、最大帧、存活判断；识别帧停滞段（时间走、帧号不走 ≥2s）与 FPS 骤降段（降至前期 40% 以下且持续 >2s） | script |
| AC-2 | `gaps` 检出相邻行间隔超阈值（默认 3000ms，`--min-ms` 可调）的空窗，输出时长与前后各 3 行上下文 | script |
| AC-3 | `errors` 按 log-error-summary 同口径归并错误，按次数降序，带首次/末次出现时间与帧号 | script |
| AC-4 | `noise` 把去除时间戳/帧号并归一后出现 ≥N 次（默认 10，`--min-count` 可调）的模式聚类，按次数降序 | script |
| AC-5 | `timeline` 输出里程碑（引擎启动、LoadMap/Browse、首帧、退出/终止形态）并标注空窗 | script |
| AC-6 | `summary` 一键运行全部子命令产出 markdown 体检报告；各子命令均支持 `--json` | script |
| AC-7 | 退出码：参数/文件错误 exit 2；正常分析（含"未发现问题"）exit 0 | script |
| AC-8 | fixtures 回归：stall（帧 0 卡死+噪声刷屏）、run-freeze（出帧→骤降→空窗→心跳终止）、crash（Fatal 崩溃结尾）三类形态特征均被对应子命令捕获 | script |
| AC-9 | 多日志同因判定（method.md 分层规则）：错误谱一致仅为候选不作同因结论；存在出帧存活份时以其为反例排除共同病灶为致死根因；致死候选=仅卡死份独有模式；报告分"共享缺陷/致死机制"两档结论，修复优先级跟致死机制走 | method |
| AC-10 | 报告时间线节必须包含 gaps 空窗表（起止时间戳+时长+空窗前最后 3 行）：脚本已算出的空窗不进报告等于没算（iteration-2 实证三臂无一采纳 gaps 输出） | method |
