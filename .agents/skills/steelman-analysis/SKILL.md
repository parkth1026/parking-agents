# 双向钢人分析（steelman）

在给出任何判断之前，先把问题本身放到放大镜下。本技能是两回合协议：第一回合分析并提问，第二回合裁决。纪律只有两条：**第一回合不给答案**，**只问一个问题**。

## 第一回合：分析回合（构成对用户消息的完整回复）

按序完成四步，输出使用固定骨架——标签固定，内容自由：

```
**重述**：…
**支持方最强论证**：…
**反对方最强论证**：…
**crux 与关键变量**：…
**一个问题**：…
```

**1. 重述** —— 用最有力的方式重构用户真正想解决的问题：显式目标、隐含约束、当前想法是什么。不是复述原话，是升级后的版本；对拿不准的地方标注「我的理解是……，若不对请纠正」。重述错了后面全错，这一步就是在暴露理解偏差。

**2. 双向钢人** —— 支持方与反对方各给一条最强论证：

- 每条论证绑定用户给出的具体上下文（团队、规模、约束、时间窗口），通用 pro/con 清单不合格。
- 合格线：把这条论证拿给持该立场的人看，对方会说「对，我会这么说」。禁止稻草人，禁止「双方各有道理」式的假平衡收尾。
- 双方强度对等——给一方三条论据、另一方一句带过，是用钢人的形式做偏向性输出。

**3. crux 与关键变量** —— crux（分歧核心）是一个可判真假的命题：若它成立 → 一方胜；不成立 → 另一方胜。双方都会认账的命题才是 crux；价值偏好（「如果你更看重 X 那就 X」）不是。关键变量列出哪些可观测的事实一旦确定，结论就会翻转，并各自标注指向哪一方。

**4. 一个问题** —— 只问一个问题：回答它最能改变判断的那个。直指 crux、一次回复可答、不是伪装的多问。然后停——不预告结论，不暗示倾向。第一回合到此结束，即使用户的问题看起来有显然的答案。

## 第二回合：裁决回合（用户回答之后）

- **判断**：立场先行，一句话说清，不和稀泥。「方向对，但范围要砍半」是合格立场；「各有优劣，看你取舍」不是。
- **理由**：说明用户的回答落在 crux 的哪一侧、为什么因此倒向该方。回答没定住 crux 时直说，并给此时最稳妥的一步（通常是缩小赌注：先试点、先收集某个变量）。
- **下一步**：2~4 步可执行动作，带先后顺序与验证点。

除非真的被卡住，不再发问；不重跑完整协议。

## 边界情况

- 用户要求立即执行或直接给答案 → 照办，一句话注明跳过了协议。
- 用户一条消息里有多个决策 → 聚焦最主要的那个，其余列入「暂缓」并说明。
- 裁决后用户又抛出重大新信息 → 可做一次增量钢人（更新 crux + 再问一个问题），最多一轮，不无限循环。
- 事实问答、小改动确认这类轻量请求 → 不套协议，直接回答。
