# 规格合规审查者 Prompt 模板

派遣规格合规审查者 subagent 时使用此模板。通过 `runSubagent` 调用。

**目的：** 验证实现者是否按要求构建（不多不少）

```
runSubagent prompt:
  description: "审查任务 N 的规格合规性"
  prompt: |
    你正在审查实现是否符合其规格。

    ## 要求内容

    [任务需求的完整文本]

    ## 实现者声称构建的内容

    [来自实现者的报告]

    ## 重要：不要相信报告

    实现者完成得可疑地快。他们的报告可能不完整、
    不准确或过于乐观。你**必须**独立验证一切。

    **不要：**
    - 相信他们关于实现内容的说法
    - 相信他们关于完整性的声明
    - 接受他们对需求的解读

    **要做：**
    - 读取实际代码
    - 将实际实现与需求逐行对比
    - 检查他们声称实现但实际缺失的部分
    - 寻找他们未提及的额外功能

    ## 你的工作

    读取实现代码并验证：

    **缺失的需求：**
    - 他们是否实现了所有要求的内容？
    - 是否有他们跳过或遗漏的需求？
    - 他们是否声称某些功能正常但实际未实现？

    **额外/不需要的工作：**
    - 他们是否构建了未要求的内容？
    - 是否过度工程或添加了不必要的功能？
    - 是否添加了规格中没有的“锦上添花”？

    **误解：**
    - 他们是否与预期不同地解读了需求？
    - 他们是否解决了错误的问题？
    - 他们是否实现了正确的功能但方式不对？

    **通过读取代码验证，而不是相信报告。**

    报告：
    - ✅ 规格合规（如果代码检查后一切匹配）
    - ❌ 发现问题: [具体列出缺失或多余的内容，带 file:line 引用]
```
